# 去 AI 味润色工作流

"AI 味"指的是一类可以被识别的写作惯性：形容词堆叠、情绪靠直说、段尾总结升华、句式整齐划一。读者未必说得出原因，但会觉得"假"。润色的原则是：**只换表达，不改情节、不增删信息点、不改变人物的立场与结局。**

## 一、先找出这些症状

逐段通读，标出以下几类问题：

1. **情绪直说**：如"他感到无比愤怒""她的心中充满了悲伤"。情绪被告知而不是被看见。
2. **空泛形容**：一句话里叠两三个抽象形容词，例如"深邃而神秘的目光""震撼人心的力量"，删掉后意思不变。
3. **段尾升华**：在场景结尾加一句总结或感慨，例如"这一刻，他终于明白了成长的意义"。
4. **套路比喻**：如"像潮水一般涌来""如同一把利剑"，反复出现且与具体场景无关。
5. **句式同构**：连续多句都是"主语 + 动作 + 形容"的同一节奏，或频繁使用"不仅……更……""仿佛……又仿佛……"。
6. **万能连接词**：开头频繁出现"然而""与此同时""就在这时""不由得"。
7. **人物说话像旁白**：对白里用书面语解释设定，或者每个人的说话方式都一样。

## 二、逐类替换

- 情绪直说 → 改为一个可观察的细节：手上的动作、说话的停顿、一个与情绪相关的小决定。例如"他很愤怒"可以改为"他把茶杯放下时磕出了一道裂纹"。只选一个细节，不要连写三个。
- 空泛形容 → 保留最准确的一个，或者换成具体的感官信息（颜色、声音、温度、距离）。
- 段尾升华 → 直接删除，让场景停在动作或对白上。读者能自己得出结论。
- 套路比喻 → 删掉，或换成与人物身份、所处环境相关的比喻。一个乡下少年不会想到"像精密的仪器"。
- 句式同构 → 调整长短：在长句之间插入短句，或把两个短句合并；适当用对白打断叙述。
- 万能连接词 → 大多可以直接删除，靠段落和动作本身完成转折。
- 对白 → 给每个人一个说话习惯（简短、绕弯、爱反问、带口头禅），把解释设定的长对白拆短，或改成动作展示。

## 三、需要保留的东西

- 情节事实、人物名称、设定名词、时间顺序全部保持不变。
- 作者有意为之的风格（例如古风的文白夹杂、刻意的排比）不要抹平；判断依据是它是否只出现在关键位置。
- 篇幅可以比原文略短，但不要少于原文的八成，也不要为了"去味"而新增情节。

## 四、自查

改完后对照原文检查：信息点是否一个不少；每段是否至少有一处具体细节；全文是否还残留"无比""仿佛""终于明白"这类高频词；人物的对白能否不看名字就分辨出是谁说的。

输出时只给出润色后的正文，不附加修改说明。
