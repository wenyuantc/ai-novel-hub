# 全书搜索与批量修订

## 1. 适用范围

作品工作区查找、预览、批量写入、批次撤销，以及阅读页按搜索命中定位。正文取已保存的有序场景投影。作者区块正文独立于章节正文。普通协作及管理权限沿用作品的人工读写能力。

## 2. 接口与持久化

所有端点的前缀为 `/api/v1/projects/{pid}/book-search`。

| 接口 | 输入与输出 |
| --- | --- |
| `POST /query` | `query`，可选成对的 `start_chapter_id/end_chapter_id`、`page/page_size/snapshot`。返回 `items,total,page,page_size,snapshot` |
| `POST /preview` | 在搜索条件上增加 `replacement`。每个命中返回原文两侧片段、章标签、章版本、正文指纹和码点区间。可替换项含 `scene_id/token`，受限项含 `unavailable_reason`，标记影响见 `warning` |
| `POST /apply` | `request_id,query,replacement`、原范围、勾选的 `hits`。每项含 `chapter_id,chapter_no,chapter_title,scene_id,revision,start,end,token`。返回批次摘要 |
| `GET /batches` | `page,page_size` 分页读取历史，仅返回展示字段 |
| `POST /batches/{id}/undo` | 成功返回同一批次，状态为 `undone` |

`0060` 创建 `revision_batches` 和 `revision_batch_scenes`。后者按场景保存原富文档与原始命中偏移，通过批次内 `chapter_slot` 区分同章号、同名且已经删除的多个章节。删章不会连带删除整次批改记录。

## 3. 跨层契约

- 原词 1–512 个 Unicode 码点，替换文本最多 2048 个，空替换表示删除。按字面区分大小写、从左到右取互不重叠的匹配。范围含起止两端，同号章节按 ID 区分。每页最多 100 项，每次提交最多 1000 处。
- 阅读链接带 `mention_from=book-search` 和半开区间、章正文哈希。阅读接口同一响应提供 `content_hash`，在指纹及区间有效时渲染并聚焦命中。普通词、补充平面字符及富文本无需词典或额外的提及请求。
- 预览签名由服务端生成，绑定账号、作品、范围、章景、版本和具体替换。写入在人工编辑屏障内复核勾选结果，按照章 ID 顺序加锁。同景多项的位置均相对原稿，组合替换须保留预览时确认的格式、区块和标记语义。预览阶段不写入。
- 修订或撤销均在一个事务中更新所有目标场景、章节投影、修订号、历史、审计和批次状态。撤销成功时修订号继续推进。预览后的并发编辑与修订后的编辑分开检测，后者即使把正文改回相同字面也会阻止整批撤销。
- 同账号、同作品的相同应用请求可用原 UUID 重试；同一批次重复撤销返回已撤销状态。作品备份的可选版本历史不携带请求 UUID、原操作者和载荷摘要。导入后的章景关联及撤销资格须经重映射与重放核对。见[备份契约](./project-transfer.md)。

## 4. 错误行为

| 条件 | 结果 |
| --- | --- |
| 空搜索词、范围只给一端、续页无快照、重复命中或超限 | 422，前端保留可更正的输入 |
| 范围端点已删除、翻页期间范围内章节或顺序已变 | 409，提示重选范围或重查 |
| 跨场景、分隔符、无法安全映射的格式或作者区块 | 能搜索与定位，预览显示不可勾选的原因 |
| 选中章已变更、正在生成、属于在跑的批量生成范围，或撤销目标已删除 | 整批停止，冲突响应含 `conflicts[]` 的原章号、章名、原因 |
| 同一申请 UUID 对应另一组选择 | 409，保留原批次 |
| 成功响应在网络中丢失 | 前端保留原申请供重试，读者可重新打开修订历史核对 |

## 5. 验收样例

第 2、5 章各有地名，第 5 章另有一段保留旧称的引文。从预览排除引文后应用，应只替换两处。在批次历史中撤销，恢复两章。另开一轮，在第 5 章后续追加一句，撤销应列出第 5 章，原批次仍显示已应用。

## 6. 回归入口

`backend/tests/test_book_search.py` 覆盖范围、分页、身份、Unicode 和边界。`test_batch_revision.py` 覆盖写锁、幂等、失败回滚、旧自动保存、删章重建及富文档往返。`test_batch_revision_migration.py`、`test_batch_revision_transfer.py` 覆盖降级保护、备份选项和失效身份。前端回归在 `components/bookSearch/`、`components/reader/SearchHitContent.test.ts`、`api/bookSearch.test.ts` 和 `pages/project/BookSearchPage.test.ts`。

## 7. 实现约束

逐章调用会自行提交的保存接口，会在第二章失败时留下半批改稿。事务实现应先准备全部章景计划，调用事务内的富文档写入和章节投影函数，最后统一提交。同样，撤销若仅比较原文字面，会覆盖一次改后改回的编辑；应核对实际应用后的单调修订号、章景身份及作品归属。
