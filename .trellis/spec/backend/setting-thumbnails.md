# 设定缩略图

## 场景：本地图片、系列共享及独立快照

### 1. 范围 / 触发条件

修改角色、世界观（含地点）、组织或职业的缩略图，以及系列采用、Agent 撤销、设定卡或单书备份时，核对本合同。图片用于人工辨认，图片二进制不进入 AI 提示词、提及索引或剧情事件；生图提示词使用设定文本时另遵守下方 AI 生成合同。

### 2. 签名

```text
GET/PUT/DELETE /api/v1/projects/{project_id}/settings/{kind}/{entity_id}/thumbnail
GET/PUT/DELETE /api/v1/series/{sid}/entries/{eid}/thumbnail
ThumbnailMeta = {version, mime_type, width, height}
```

PUT 使用 multipart `file` 和 `expected_version`；无图时版本为空串。DELETE 使用 `expected_version` 查询参数。系列写入还需 `expected_revision`，并返回图片元数据和新系列修订号。角色、世界观的人工作品响应另含 `thumbnail_editable`，不以是否已有图片推断写权限。

### 3. 契约

- `setting_image_codec.py` 只接受实际解码为 JPEG／PNG／WebP 的单帧图，输入≤10 MiB、边长≤8192、像素≤16,000,000；应用 EXIF 方向后生成最长边≤512、无 EXIF／ICC／XMP 的 WebP，标准图≤512 KiB。验证导入标准图后保留原 bytes，避免反复有损编码；解码在线程限额内执行，上传前鉴权，落库时重新鉴权。
- 迁移 `0056` 将不可变 `setting_image_resources` 与当前 `setting_thumbnail_bindings` 分开。同书／同系列复合外键约束主体与资源归属。换图和移除只改变绑定，旧资源供撤销保留至所属作品／系列永久删除；已有资源时拒绝有损降级。
- 书内 GET 按当前主体和绑定解析，先做权限与最终有效性核验再返回 bytes 或 304；ETag 为当前资源版本，`Cache-Control: private, no-cache`，任何 URL 查询参数都不是授权。不得用旧版本读取历史图；列表批量读取元数据，不把 bytes 带入实体 JSON。
- 本地图片写入需作品内容编辑权和活跃作品屏障，并在锁内比较图片版本。解码前取得原协作邀请身份，写锁内核对；图片 GET 和角色／世界观人工投影在最终快照中核对同一邀请身份。撤权并重新邀请后，旧请求不能借新授权写入或返回旧图片／304。系列共享角色／世界观的书内图片只读；仅书内权限的协作者可以查看已采用条目的图，但不能读取系列库或修改共享图。前端严格依据 `thumbnail_editable`，不能根据因隐私被遮蔽的 origin 或非空图片推断可写性。
- 系列图片由系列入口维护，按系列 → 排序作品的既有锁序推进 revision。提升复制当前本地图至系列；采用读取共享权威图；移回本书复制为新资源；取消采用或退出不留下副本。读请求在最终复验时确认主体、采用关系和图片版本，避免并发删除或换图后返回旧图。
- 向导覆盖角色／世界观／职业前必须将图片绑定复合外键纳入固定级联图，并核验绑定主体、作品与资源归属；非法跨作品或异常绑定整笔拒绝。主体被合法替换时绑定级联删除，旧资源保留供已记录的效果撤销，未知新级联仍拒绝。
- 图片更新只合并元数据，不覆盖未保存的文本草稿。响应按 actor、权限、作品／系列、条目与请求代次失效，缓存更新不能用未授权的旧请求覆盖当前状态。
- 单书备份 v11 只保存本书当前有效图片及主体引用，不含系列 ID、资源 UUID 或旧图；总备份上限仍为 100 MiB。恢复对图片和引用先校验，再为新书创建独立资源并在同事务绑定；v1–v10 继续可读。备份生成使用受限暂存并在发送前确认大小和一致性，传输期间继续校验身份与作品状态及回收代次；作品回收后恢复不能使旧快照重新有效。
- 设定卡 v7 为原有角色／组织／职业类型增加可选图片，紧凑 JSON 上限为 16 MiB；明确选择的图只写入新建／重命名新建条目，跳过角色／组织或复用职业不修改已有图，无图片或未选时也不清除目标图。世界观不新增卡片协议。Agent effects v7 只记录本地 binding 小行，资源二进制不进入效果或公开变更；旧效果不能清掉后来新增的图片，系列提升后不能把旧私图恢复覆盖共享图。

### 4. 校验与错误矩阵

| 条件 | 结果 |
| --- | --- |
| 无权访问、主体不存在或读取期间主体／绑定失效 | 404，不返回历史图或 304 |
| 单书编辑者尝试修改系列共享图 | 拒绝写入，不修改共享资源 |
| 图片格式伪造、损坏、动画、尺寸／字节超限 | 400，保留原图片 |
| 旧图片版本 | 409 `thumbnail_changed`，保留原图片和文本草稿 |
| 系列修订过期 | 409 `stale_revision` |
| 备份或卡片超限、引用错误、图片非法 | 整体拒绝，不留下部分资源或绑定 |

### 5. Good / Base / Bad

- Good：作者在系列库更换共享图，已采用的作品重新读取时展示同一图片；单书协作者只能看已采用条目。
- Base：旧作品无图时仍正常显示占位；旧备份可恢复为无图作品，旧卡片导入不清除目标已有图片。
- Bad：信任浏览器传来的资源 UUID 或 origin 决定读写权限；将整张图片放进 Agent effects 或用先删后写替换图片。

### 6. 必需测试

- 实际图像：合法三格式、透明、方向、动画、像素／字节上限、损坏、伪造类型及标准图元数据，部署镜像具备 WebP 编解码能力。
- SQLite 与真实 PostgreSQL：迁移复合外键及降级、读写 CAS、删除／撤权／回收竞争、共享图替换和采用关系变化；验证最终 GET 不返回旧图。
- 备份、设定卡与 Agent effects：新旧版本、明确图片选择、同事务回滚、导出大小与临时文件清理、资源复制、删除与撤销及系列提升后的保护。
- 前端：四类列表／详情、共享和单书权限、有图／无图、上传失败保留原图、草稿和账号切换、桌面及 375px 交互。

### 7. 错误写法 vs 正确写法

```python
# 错误：根据旧 URL 或前端来源信息直接读取历史资源。
image = await db.get(SettingImageResource, requested_version)

# 正确：按已授权主体解析当前资源，服务内再次检查当前有效性。
image = await setting_image_service.get_book_image(db, actor_id, project_id, kind, entity_id)
```

## 场景：设定缩略图 AI 生成与确认

### 1. 范围 / 触发条件

修改四类作品本地设定或系列共享角色／世界观的生图入口、图片模型、提示词投影、发送门禁和预览确认时，核对本合同。已有系列采用条目只能在系列库修改共享图，不能由单书入口绕过。

### 2. 签名

```text
GET  {thumbnail}/ai/prompt
  -> {prompt: string, prompt_token: string}
POST {thumbnail}/ai/generate
  {prompt: string, prompt_token: string, config_id?: int,
   expected_version: string, expected_revision?: int}
  -> {image_base64: string, mime_type: "image/webp", model_source: "actor" | "owner", preview_token: string}
POST {thumbnail}/ai/apply
  {image_base64: string, preview_token: string}
  -> ThumbnailMeta | {thumbnail: ThumbnailMeta, revision: int}
```

`{thumbnail}` 是上节作品或系列图片路径；系列生成必须提供 `expected_revision`。提示词非空、去首尾空白后最多 2000 字符；配置 ID 为正整数。生成请求体不超过 64 KiB，确认请求体不超过 768 KiB，标准图 base64 长度最多 699052。生成和确认分别使用来源与预览凭据，不能互换。

### 3. 契约

- 预制提示词只投影已保存的当前目标和 AI 可见字段，不自动发送未保存草稿、原图片、关联条目或引用型自定义字段。`manual_only` 可由显式生图选择，`never` 拒绝，隐藏字段不自动进入；自由编辑的文本由用户自行检查，不能声称服务端能识别其中手工粘贴的隐藏内容。提示词、凭据、原始设定和模型密钥不写日志。
- 预制提示词由个人提示词模板 `setting.thumbnail`（模板页「设定生成 → 设定图片」，变量 `subject`／`fields`）渲染，作品和系列均按**真实发起人**读取启用的覆盖并展开其本人的组件，无覆盖时使用系统默认；协作者使用作者授权模型时也不借用作者模板。system／user 段合并为单个文本，合并后为空或超过 2000 字返回 400，不截断自定义内容。模板只提供弹窗初始文本：弹窗内修改仅用于本次生成，不回写模板；保存模板后须重新打开弹窗才生效，来源凭据不绑定模板版本。详见[提示词模板契约](./prompts-styles.md)。
- 作品同时要求内容编辑权和 `ai.use`，本人图片模型优先，只有作品既有授权允许时回退作者配置；仅管理员人工能力不授予 AI 能力。系列独立校验作者或已接受 editor，生图只使用实际操作者的本人图片模型，不能借任一成员作品的权限或作者模型。
- 提示词来源和预览使用有用途区分、服务端加密认证的短期凭据；分别绑定原 actor／会话、邀请轮次、主体、设定来源／可见性版本，预览另绑定模型配置实例、图片原版本、标准图摘要及系列 revision。不能信任客户端自报原身份、配置或图片摘要，也不能将作者模型细节暴露给协作者。
- 作品作者和协作者均须在每次真实 Provider 发送、条件回退和下载时校验构建提示词时的可见性与原实体来源，系列使用独立的认证、系列父行及模型锁序；返回提示词和预览前再验证原授权。发送屏障覆盖实际物理请求至响应头，异常／取消释放；敏感 ASGI 响应受有界输出时间保护。不能用单次预检或虚构的系列 `project_id` 代替真实发送门禁。
- Provider 结果使用已有单帧、格式／尺寸／像素和 10 MiB 输入限制并规范化为最长边 512、最多 512 KiB、无元数据的 WebP，生成只返回预览，不写图片。确认时重新校验凭据、标准图实际字节、权限和配置，沿用相同资源写入、图片版本 CAS 及系列 revision；不能将旧预览借撤权重邀后的新邀请保存。普通人工上传仍保持原合同。
- 确认响应未知时重新读取当前图片并让用户核对，不自动重放；页面更新只合并图片及系列 revision，不覆盖文本草稿。作用域、身份、授权代次、条目或请求代次变化时丢弃迟到响应。现有版本只比较当前图片，无法识别单书无图→有图→无图的全部历史；无状态凭据不承诺全局严格一次性。

### 4. 校验与错误矩阵

| 条件 | 结果 |
| --- | --- |
| 未授权、纯管理员人工权限、单书共享图或系列非成员 | 拒绝请求，不调用图片 Provider |
| 个人模板渲染后为空、超过 2000 字或引用的组件不存在 | 400 中文提示检查或缩短模板／设定；不返回无法提交的提示词 |
| `never`、隐藏字段／来源或 AI 策略已变化 | 禁用目标或返回冲突；不按新策略静默重放旧提示词 |
| 凭据过期／篡改、跨身份／主体、原邀请或模型变化 | 拒绝发送、回包或确认；原图不变 |
| 图片无效、MIME 不符、超限或标准图摘要变化 | 拒绝预览或确认；原图不变 |
| 图片版本或系列 revision 过期 | 409，保留文字草稿，重新读取后显式核对 |
| Provider 出错、超时或取消 | 保留原图；不静默重复生成，已发请求可能计费 |

### 5. Good / Base / Bad

- Good：系列 editor 使用自己的图片模型，预览、确认后共享图在已采用作品中显示。
- Base：无图条目生成后取消，仍保持无图；原有上传、删除和旧备份行为不变。
- Bad：从人工 DTO 拼接隐藏字段、随机使用某本书的模型授权，或将预览直接走普通 PUT 并用重邀后的权限确认。

### 6. 必需测试

- 四类及系列角色／地点、可编辑提示词、`never` / `manual_only`、隐藏字段、无图／有图、预览与确认字节一致、篡改与过期凭据。
- 实际 HTTP 和隔离 PostgreSQL 双连接覆盖作者／viewer／editor／纯管理员、系列 editor、原邀请撤权重邀、配置／来源／策略变化、发送和回包竞争、慢客户端与取消释放、图片及系列 CAS。
- 前端覆盖模型来源与费用提示、未保存文字草稿、失败／取消、写结果未知、账号及主体切换、迟到响应；桌面和 375px 真实浏览器分别验证。

### 7. 错误写法 vs 正确写法

```python
# 错误：用当前权限和普通上传接口确认旧预览，无法识别撤权后重新邀请。
await setting_image_service.put_book_image(db, actor, project_id, kind, entity_id, preview_bytes, mime, version)

# 正确：AI 确认校验服务端预览凭据、原身份、来源、模型及图像摘要，再在锁内写入。
await project_thumbnail_ai.apply(db, actor, project_id, kind, entity_id, body, cipher, allow_private=False)
```
