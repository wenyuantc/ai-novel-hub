# 站内通知

## 业务事件与接收人

| 事件 | 接收人 | 身份和生命周期 |
| --- | --- | --- |
| 作品或系列邀请 | 被邀请人 | 以待处理邀请 UUID 定位；接受、拒绝、撤回后退出收件箱。 |
| 后台任务成功或失败 | 任务发起人 | 按稳定任务 UUID 去重；显式重试有独立身份。打开时再次核对任务 ID 和 UUID。 |
| 一致性检查成功 | 发起人与作者，按人去重 | 仅在确认同一任务的成功运行后投递。零问题也有概要，打开时按作品 ID 和运行 ID 读取。检查失败走普通任务失败通知。 |
| 预算达到预警比例或额度 | 账号费用承担人或作品作者 | 账号按调用开始时所在的北京时间自然月计算；作品按币种累计。一次结算跨两档只通知最高一档。 |

收件、事件去重与业务写入共用事务。四类偏好默认开启。关闭期间发生的事件在重新开启后仍保持原投递决定。不同接收人的已读状态互相独立。

## 读取与跳转

用户身份来自登录会话。列表、未读数、标记已读及打开操作均检查接收人和当前来源权限。协作者通知绑定原授权轮次，重新邀请后不能读到上一轮次的数据。查询先检查可见性再分页或计数，过期目标与不存在的通知统一返回 404。

工作台打开通知时使用服务端返回的目标类型构造应用内路由。目标业务接口独立检查当前权限。按运行 ID 打开检查概要只读取对应运行，不暴露其他人的任务详情。切换身份或发现授权变化时丢弃旧响应。

收件项对外使用 UUID。分页游标同时保存上一页末条的 UTC 微秒时间和内部序号，即使删除该条也能继续翻页。邀请跳转携带作用域和邀请 UUID，任务跳转携带任务 ID 和任务 UUID。预算深链的读取及修改都复验配置 UUID，检查深链的概要查询同时复验收件 UUID、作品和运行。这些身份用于防止旧地址在数据库恢复或资源重建后指向另一条数据。

## 迁移与备份

升级时从现有预算开支建立起点，已有邀请和已完成任务不产生未读。单书导入保留独立作品身份，个人收件、偏好与费用状态不随书迁移。回退含真实收件或偏好的实例前必须保留数据。
