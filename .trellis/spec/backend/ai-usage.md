# AI 用量与费用管理

## 1. 范围与触发条件

适用于 Provider 调用计量、模型配置定价、作品与账号预算、批量费用预估和管理员全站读取。修改模型出站、费用归属、协作撤权、项目清理或角色目录时，检查本契约。

## 2. 签名与存储

- `0061` 新增 `ai_usage_calls`、`ai_model_prices`、`ai_usage_budgets`、`ai_usage_tracking`，并同步超管内置角色的 `ai_usage.read`。角色自定义权限和其他内置角色延续原授权。应用回退需使用兼容新权限目录的版本。降级检查用量、定价、预算和自定义角色授权，保护现存数据。
- `0062` 新增模型 `off_peak` 规则、用量 `pending_price_schedule` 和 `price_period`。迁移前的固定价和金额原样保留。分时计价需要支持 0062 的后端版本，滚动升级时先升级实例再启用分时价。存在分时配置、冻结规则或分时调用记录时，迁移拒绝丢失这些信息的降级。
- `ai_usage_recording.meter_provider(...)` 以服务端确定的使用者、费用承担方、模型、任务和作用域包装 Provider。`observe_model_usage` 绑定单个模型操作的计量观察器。`reserve_call`、`mark_call_sent`、`finish_call` 通过同一个 UUID 更新一次尝试。
- `GET /api/v1/ai-usage`、`/api/v1/projects/{id}/ai-usage`、`/api/v1/projects/{id}/chapters/{chapter_id}/ai-usage`、`/api/v1/admin/ai-usage` 返回 `UsagePage {items, total, page, page_size, tracking_since, summary}`。支持作用域、任务、模型、状态和时间范围筛选，管理员可筛发起账号与承担账号。
- `GET/PUT /api/v1/ai-configs/{id}/price` 使用 `ModelPriceOut {version, price, provider, model, model_type}`。更新提交 `{expected_version, price}`，`price: null` 清除配置。账号及作品的 `/ai-usage/budgets` 支持 GET，各币种子路径支持 PUT `{limit, threshold_percent}` 或显式 `null` 清除。
- `price.off_peak` 包含 `timezone`、首条时段的本地 `start/end`（`HH:MM`）、可选 `additional_windows: [{start, end}]` 和各时段共享的空闲档单价。省略整个 `off_peak` 时沿用既有规则，显式传 `null` 恢复固定价。省略 `additional_windows` 时保留已有附加区间，传 `[]` 清除附加区间。单条规则保持原 JSON 结构及版本指纹，每条附加区间进入版本指纹及待发送快照。用量明细和批量预览返回 `price_period: fixed | peak | off_peak | null`，预览另有 `price_timezone`。
- 多时段复用现有 JSON 字段。滚动发布时，所有后端实例支持附加时段后再启用该配置。回退到只支持单时段的应用版本前，将各模型改回至多一条空闲时段，并等待多时段价格快照所对应的调用收尾。模型定价或待发送快照仍含附加时段时，迁移 `0063` 拒绝降至 `0062`。
- 迁移 `0063` 为文本模型固定价、高峰价和空闲价增加可选 `cached_input_per_million`。模型表存储 `cached_input_price_nano`，空闲价和待发送快照 JSON 在配置命中价时写入同名字段。调用表保存 `cached_input_tokens` 和该次选定的 `price_cached_input_nano`。同币种更新省略命中价时沿用原值，显式 `null` 清除。明细返回 `cached_input_tokens` 及可见的 `cached_input_per_million`，汇总返回已知的命中量。
- `POST /api/v1/projects/{id}/batch-generate/preview` 返回 `BatchPreview.cost`，其中 `steps` 记录正文生成与分析的预计次数、用量及费用，`budgets` 返回对应币种的预计进度。

## 3. 契约

- 一次可观测的模型尝试使用一个 UUID。正文、逐场景调用、分析、重试、图片、向量分批、智能体轮次及无作品的模型请求按各自的执行归属计量。批量生成重试标记为 `chapter.generate.retry`。预检、应用内部缓存直接返回、仅关键词检索、模型列表和图片文件下载不产生额外调用记录。供应商提示词缓存命中量记在该次模型调用内。Gemini 采用可选 aiohttp 传输时，仍记录操作及其返回用量，独立的 SDK 内部重试依赖传输钩子的可观测性。
- 计量只含元数据。发送观察、权限租约和业务内容保存各自收尾。需要延期写入时先保留安全的归属及价格快照，待原业务事务释放后提交。计量失败不重发模型。遇到状态未知，保留记录和金额缺口。超时遗留的待确认记录由维护任务更新为中断。
- 用量按分项记录提供方返回、估算或未知，显式的 `0` 为已知值。调用快照以整数保存纳货币单位（`10^-9`），文本和向量按每百万 token、图片按张计价，金额以十进制字符串传输。定价与模型配置实例及模型信息匹配，换价只影响后续调用。
- `input_tokens` 是含命中的总输入。只有当供应商返回可信命中量且本次档位设有命中价时，费用才拆成未命中输入、命中输入和输出三项后统一舍入。无可用命中量时保留未知，按普通输入价估算。Claude 缓存写入量计入普通输入，缓存读取量计入命中。已配置命中价时，批量预览返回 `assumes_uncached_input` 以提示按普通输入价估算。
- 分时收费使用同一币种，默认 `Asia/Shanghai`。每天可设置多个空闲区间，每段含开始分钟、不含结束分钟，结束早于开始时跨零点。本地时间命中任一条时使用空闲档，其余时间使用高峰档。每次尝试预留时冻结两档单价与全部时段，收尾按该次记录的 UTC 发送时刻选择档位。缺少可观察的发送时刻时以该次尝试的记录时间作为回退，不能确认发送的尝试保持费用未知。收尾只保留命中档位与单价。批量预估按预览时刻调用同一选档函数，代付协作者的投影隐藏价格、档位、时区与预算。
- 账号费用按承担方、以 `Asia/Shanghai` 月界换算成 UTC 半开区间查询。作品预算是该作者承担费用的全书累计。同一作者授权调用可影响两个预算，全站金额只累计一次。删除项目、章或任务时保留已计量的费用并清空相应链接。单书备份继续保存既有生成日志的语义，计量表及预算不进入该格式。
- 个人接口只投影本人发起或承担的调用，查询条件、分页和汇总使用投影后的模型、金额与作品信息。协作者可看本人触发的用量和费用承担提示，作者的模型身份、单价与预算属于作者的费用视图。已失去作品访问资格时，本人历史的作品链接隐藏。管理员明细使用专门的只读权限和字段白名单。
- 预估重用批量范围、活动场景字数分配、模型选择和自动分析开关。正文步骤按场景估计，分析按章估计。提醒用于界面展示。任务预览、个人及全站页对切换身份和变更作用域后的迟到响应使用原会话、作品作用域和请求代次校验。

## 4. 校验与错误矩阵

| 条件 | 行为 |
| --- | --- |
| 缺少模型用量、价格或可确认的发送状态 | 保留调用状态和缺口，费用为空，合计包含已计价部分 |
| 调价时模型身份或价格版本已变化 | `409`，刷新并重新核对模型和价格 |
| 空闲时段两端相同、时钟格式或时区非法、区间重叠 | 请求校验错误，保留已有配置 |
| 分时定价已启用，旧请求省略 `off_peak` 且变更币种 | `400`，要求显式提供对应新币种的时段费率或恢复固定价 |
| 访问他人定价、作品预算或无权读取的个人作用域 | 按资源契约 `404` |
| 缺少 `ai_usage.read` 访问全站入口 | 后端 `403`，前端隐藏对应导航 |
| 时间范围、金额、币种或阈值非法 | 请求校验错误，保留已有配置 |
| 预估使用作者授权模型 | `author_paid`，仅返回可查看的步骤，不返回作者计价或预算数据 |

## 5. 正例、基准与反例

- 正例：协作者用本人文本模型生成正文，费用计入其账号。随后使用作者授权的向量模型，向量费用计入作者账号和当前作品。每次真实调用各有一条明细。
- 基准：未配置单价的老模型仍可调用，页面显示已拿到的用量和未计价次数。旧生成日志保留原入口及权限。
- 反例：把任务最终结果当费用数据源，重试消耗及已发送但取消的调用会丢失。把作者费用在聚合后过滤，会从汇总或筛选命中数泄露费用。

## 6. 必需测试

- `test_model_provider_usage.py`、`test_ai_usage_recording.py`、`test_ai_usage_entrypoints.py` 检查实际适配器用量、独立尝试、受控发送、取消、用量缺失、延期写入及不同业务来源。
- `test_ai_usage_storage.py`、`test_ai_usage_migration.py` 检查定价历史、终态幂等、SQLite 与 PostgreSQL 存储、删除保留、单书排除和现有管理员迁移。
- `test_ai_usage_api.py` 验证双预算、跨月、按币种统计、个人投影及全站权限。`test_batch_generate.py` 与 `test_collaboration_batch_entry_e4g2.py` 验证多场景、分析开关、预算投影和作者授权预估的可见字段。
- 分时价专项须验证 0061 数据升级、跨零点后的临界分钟、准备与发送跨档、重试独立档位、调用期间改价、旧客户端保存语义、预估和代付字段投影。
- 多时段专项须验证首条及附加区间、相邻边界、跨零点重叠、旧单段读写、旧请求省略附加字段、删除后再次报价，以及未结算的旧快照仍可读。
- 缓存价专项须验证 0062 数据升级、显式零值与未知、三类适配器的总量和命中量、SDK 重试隔离、高峰和空闲选价、历史价格快照、批量预估及代付价格投影。
- 前端权限、请求代次与接口字段用 Vitest 验证。使用隔离数据库和本地模型替身验证单价更改、批量预览、成功与失败调用明细及窄屏全站筛选。

## 7. 错误写法与正确写法

- 错误：读取 `GenerationLog` 中最新模型名再联表取当前单价，并按发起人汇总费用。
- 正确：从发送时的可信模型配置绑定写入独立 `AiUsageCall`，使用调用中保存的定价快照，按 `payer_id` 汇总账号金额，按 `project_id` 与 `author_paid` 汇总作品预算。
