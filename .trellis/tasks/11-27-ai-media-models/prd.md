# 图片参考图与视频模型接入（核心能力）

> 父任务：`11-27-admin-plugin-packages`。决定编号 D1–D15、共同需求 R1–R7 见父任务 `prd.md`。
> 技术设计见同目录 `design.md`，实施计划见 `implement.md`。

## Goal

把模型能力从「文本 + 简单文生图」扩展到短剧需要的程度：生图可指定尺寸并带参考图；新增视频模型并能可靠地等到结果。
它是核心能力，不属于任何插件。

## 依赖

依赖 `11-27-media-storage`（生成的图片与视频落到媒体存储，参考素材经它签发外部地址）。
先于 `11-27-short-drama-media`、`11-27-drama-canvas`。

## Requirements

- G1 生图可指定尺寸 / 画幅，并可附带一张或多张参考图；不支持参考图的模型给出明确提示而不是静默忽略。
- G2 「模型配置」新增视频类别，第一批四家厂商（D14）：火山引擎 Seedance、OpenAI 兼容视频接口、MiniMax、阿里云百炼 Wan。
- G3 视频生成是后台任务：提交 → 等待 → 取回结果并存入媒体存储。任务有进度或阶段提示，可取消。
- G4 等待期间应用重启或切换实例后，继续等待同一个外部任务，不重复提交、不重复扣费；参考项目重启即判失败，这一点不照搬。
- G5 有超时与失败原因：厂商明确失败、超时、内容审核拒绝等都要让用户看得懂。
- G6 参考素材的传法按厂商要求：图片可内联，视频 / 音频用媒体存储签发的外部地址。
- G7 图片与视频的调用同样计入 AI 用量与费用、受预算约束、遵守协作授权规则。
- G8 用户自填的接口地址沿用现有的内网地址防护规则。
- G9 「模型配置」页可以对视频模型做一次连通性测试。
- G10 README 增加视频模型配置说明与四家厂商的注意事项。

## Acceptance Criteria

- [ ] 用支持参考图的图片模型，带一张参考图和指定画幅生成，得到符合画幅的图片并存入媒体存储；换用不支持参考图的模型时得到明确提示。
- [ ] 四家视频厂商各自用真实密钥跑通一次「文本 + 参考图 → 视频」，结果可在界面播放。（需要用户提供四家的测试密钥）
- [ ] 视频任务等待期间重启后端进程，任务继续并最终成功，厂商侧只产生一个任务。
- [ ] 取消一个等待中的视频任务，任务以「已取消」结束，不再占用并发名额。
- [ ] 厂商返回失败时，任务失败并显示可读原因；超过超时时间的任务被判超时。
- [ ] 图片与视频调用出现在个人与作品的 AI 用量页；超出预算时被拒绝；协作者按现有规则受限。
- [ ] 把接口地址填成内网地址，在未放开内网的部署下被拒绝。
- [ ] 现有文本、图片（封面、设定缩略图）、向量模型的功能与测试不变。

## 已核实的现状（代码证据，详见 `11-27-short-drama-plugin/research/reference-media-infra-and-gap.md` A.1–A.3、A.6、B.8、B.9）

- `generate_image` 只有 `prompt, model` 两个参数，尺寸写死，没有图生图，仅 OpenAI 兼容与 Gemini 两家
  （`backend/app/ai/providers/base.py:68`、`openai_compat.py:173`、`gemini.py:247`）。
- 现有生图都在 HTTP 请求内同步完成，不走任务引擎。
- 模型配置属于每个用户自己（`ai_configs.user_id`），用 `model_type` 区分类别（`backend/app/models/entities.py:165`、`:184`）；没有视频类别。
- 模型调用统一经过调度、用量与费用记录、协作授权三层（`backend/app/services/ai_dispatch.py:715`、
  `ai_usage_recording.py:255`、`collaboration_ai_guard.py:202`）。
- 参考项目的四家视频适配器全部是「提交任务 → 服务端每 10 秒轮询 → 下载落盘」，没有回调；
  轮询只在进程内存里，重启后进行中的任务统一判失败；没有并发控制和取消。

## Out of Scope

- 语音与音乐模型。
- 把现有的封面、设定缩略图生图改走新流程。

## 细节取值

用户已定（2026-11-27）：

- 视频模型密钥由作者自己配置（D16）。

默认取值（未单独征询，评审时可改）：

- 本期不增加火山引擎的图片模型，只做四家视频与现有两家图片的参考图能力。
- 视频按生成时长（秒）计价，单价由作者在现有「模型单价」里维护；未设单价时只记用量不计费用。
- 单个视频任务等待上限 30 分钟，可由部署者调整。
- 四家厂商的真实密钥验收放在本子任务最后一步，需要用户届时提供测试密钥与少量额度。
