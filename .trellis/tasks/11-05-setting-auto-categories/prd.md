父任务：`11-05-custom-setting-fields-categories`。承担父 R3，以及分类相关 R4、R7、R8。作者为条目添加整理标签，并用标签或共享下拉字段规则自动组织设定。

用户已确认自动归类；四类字段按章回溯来自先行字段子任务。2026-11-05 用户在最终摘要后回复“开始”，已批准完整方案；字段前置门禁已通过，本任务已经实施并完成完整自动化检查。

## 依赖

必须先完成 `11-05-typed-setting-fields` 的字段定义／选项、稳定条目身份、批量时点投影、v4 数据合同及对应检查；分类不能自建求值器或修改其已冻结的 v4 含义。迁移按先后执行，父子链接不代表依赖自动满足。

## 需求

| 编号 | 要求 |
| --- | --- |
| C1 | 为角色、世界观各子类型、组织、职业维护作品内当前整理标签，复用已有详情，支持只读查看。 |
| C2 | 创建、改名、排序、编辑和删除自定义分类，选择适用类型、标签／下拉选项条件，以及任一／全部匹配；同条目可同时命中多个分类。 |
| C3 | 成员自动计算并随条目变化更新；默认当前，可选择已有／计划章节的章初／章末，下拉按该位置有效值判断。 |
| C4 | 当前标签和规则本身不做剧情回溯；界面说明混合口径，空下拉不匹配，删除分类不改条目。 |
| C5 | 统一目录支持类型／名称筛选和分页；结果跳转现有详情并保持时点，不由前端逐行调用字段 effective。 |
| C6 | 规则使用稳定字段／选项身份，重命名不失效；归属／权限／并发及定义删除保护一致，失败不丢草稿或部分保存。 |
| C7 | v5 完整备份保留标签、分类及规则并映射 ID，兼容旧 v1–v4；卡片 v5 保留所含条目的标签但不携带作品分类规则，v1–v4 卡片继续导入。 |

## 验收标准

- [x] C-AC1：同标签跨类型条目自动出现在适用分类中；加标签后加入、移除后退出，删除分类后条目保留。
- [x] C-AC2：同条目可同时命中多类；ANY 和 ALL 对两条条件给出可预测差异，空规则不能保存。
- [x] C-AC3：第 20 章章末“阵营”改变，5／20 章章初和21章成员正确不同；当前标签在三种视图均按当前整理元数据显示并有说明。
- [x] C-AC4：同名不同ID字段／选项不误匹配，停用选项的历史值仍可归类；修改名称后规则仍生效。
- [x] C-AC5：分页计数先按完整规则求值后分页；快速切换作品／分类／时点不串列表，详情深链保留选择时点，查询无写副作用。
- [x] C-AC6：跨作品字段／选项／条目不能用于规则；只读用户不能编辑，两页竞争仅一个有效版本成功并保留失败草稿。
- [x] C-AC7：0035 升至0036、project v5 往返与 v1–v4 升级均正确；卡片 v5 标签不丢，旧卡片无标签默认为空。
- [ ] C-AC8：API／UI与真实浏览器验收通过，并移交父任务完整范围检查；此子任务单独完成不直接勾选父待办。
