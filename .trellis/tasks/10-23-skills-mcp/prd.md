# Skill 与 MCP 插件（P2-12 skills-mcp）

## Goal

对应差距清单 C5、C6：
- **Skill**：可复用的写作工作流与参考资料，例如"长篇续写规范""去 AI 味润色""拆章分析"。用户可以自建，管理员可以发布全局 Skill，智能体和生成任务都能使用。
- **MCP 插件**：接入用户自己的远程 MCP 服务（例如资料检索、词典、外部知识库），作为项目智能体的扩展工具。

相比 MuMu 的改进：
- Skill 区分用户级和管理员级。MuMu 任何登录用户都能改删全局 Skill，并直接写服务器磁盘。
- Skill 按需加载，不再把全部参考资料无条件拼进 system prompt。
- MCP 只在智能体中按用户启用，不再默认注入所有生成调用（MuMu 的 `auto_mcp=True` 会干扰 JSON 输出）。
- 地址经过 SSRF 防护，鉴权头加密存储且不回显。
- MCP 工具结果按不可信数据隔离，写类工具需要确认。
- 工具名改为不会拆错的命名空间，MuMu 按第一个 `_` 拆分插件名。

## 已确认的可复用能力

- 项目智能体（P2-11）：工具注册表（`app/services/agent/tools`）、kind 分级与提案确认、不可信包装与 8000 字截断、锁定的 `safety_rules`、`agent.system` 模板。
- 提示词模板注册表与覆盖、写作风格。
- `app/ai/endpoint_guard.py`：SSRF 校验与连接时拦截；`ALLOW_PRIVATE_AI_ENDPOINTS` 开关。
- Fernet 加密存储（AI 配置的 API key）、`api_key_masked` 回显约定。
- 管理员能力：`/admin/*`、`require_admin`。

## Requirements

- R1 Skill 的形态与用法（已确认）
  - **存储与权限**：
    - 存在数据库，分为用户私有和管理员全局两级。
    - 全局 Skill 只有管理员能增删改，普通用户只读，可以复制为自己的副本再修改。
  - **内容**：
    - 名称、说明、分类、触发词、工作流正文和多篇参考资料。
    - 支持以 SKILL.md 格式（frontmatter 加正文，连同 references 一起打包）导入导出。
  - **智能体中按需加载**：
    - 系统提示词只列出可用 Skill 的名称和说明，模型用 `load_skill` 工具读取正文，参考资料再按篇读取。
    - 用户可以输入 `/触发词`，或在输入框中选择 Skill，强制启用。
  - **生成任务**：章节生成、重写、润色和批量生成可以选一个 Skill 作为补充指令。
  - **不做独立的 Skill 对话页**：项目智能体已覆盖这个用途。
  - **内置 Skill**：4 个自己编写的全局 Skill，即长篇续写、去 AI 味润色、章节诊断、伏笔检查，不复制 MuMu 的内容。
- R2 MCP 接入与安全（已确认）
  - **连接方式**：只支持远程 Streamable HTTP 和旧版 SSE，不支持 stdio。
  - **归属**：插件按用户私有；管理员可以通过配置全局关闭 MCP。
  - **添加方式**：
    - 可以粘贴标准的 `mcpServers` JSON，也可以填表单（名称、地址、请求头）。
    - 请求头加密存储，只显示掩码，接口不返回原文。
  - **SSRF 防护**：保存和连接时都校验地址，不跟随重定向，沿用内网地址开关。
  - **连接管理**：使用官方 `mcp` SDK。每轮对话按需建立连接，这一轮结束即关闭，不做进程内连接池。
  - **工具列表**：在测试或刷新时存库，智能体使用缓存的列表。
  - **限额**：单次调用超时 30 秒；每个用户最多 10 个插件；每轮最多暴露 30 个 MCP 工具。
  - **使用范围**：MCP 只在项目智能体中使用，不注入生成任务。
- R3 工具暴露、确认与管理界面（已确认）
  - **命名**：
    - MCP 工具名为 `mcp__插件标识__工具名`，插件标识只能用小写字母、数字和连字符。
    - 服务端按映射表还原插件和工具，不靠拆分字符串。
  - **启用范围**：每个工具可以单独启用或停用；智能体会话中可以选择本会话启用哪些插件。
  - **确认**：
    - MCP 调用默认一律需要确认，提案卡片显示插件、工具和完整参数。
    - 用户可以把单个工具标为免确认。
    - `readOnlyHint` 只作为提示，不自动免确认。
  - **不可撤销**：MCP 调用属于外部操作，不能撤销，不参与"自动执行小修改"。
  - **结果处理**：按不可信数据包装并截断，只保留文本内容。
  - **界面**：
    - 顶栏新增"Skill"和"MCP 插件"两个页面，管理员在 Skill 页管理全局 Skill。
    - 插件页可以测试连接、刷新工具、查看工具参数，并手动调用工具试用。

## Acceptance Criteria

### Skill
- [ ] 用户可以增删改自己的 Skill，包括正文和多篇参考资料；普通用户不能修改全局 Skill（返回 403），但可以复制为自己的副本；管理员可以增删改全局 Skill。
- [ ] 跨用户访问 Skill 返回 404；智能体和生成任务都不能使用其他用户的私有 Skill。
- [ ] SKILL.md 和 zip 包（SKILL.md 加 references/*.md）可以导入导出，往返后内容一致；非法包被拒绝，包括路径穿越、超出大小或数量、frontmatter 缺失。
- [ ] 内置 4 个全局 Skill，内容为自行编写。
- [ ] 智能体的系统提示词只列出 Skill 的名称和说明；`load_skill` 读取正文，参考资料按篇分页读取；用户用 `/触发词` 或选择器强制启用时，正文注入本轮系统提示词，且排在安全规则之后，不能覆盖安全规则。
- [ ] 章节生成、续写、重写、润色、按建议重写和批量生成可以选一个 Skill：任务创建时快照 Skill 内容，之后编辑 Skill 不影响重试；生成记录中能看到使用的 Skill。

### MCP
- [ ] 可以用表单或粘贴 `mcpServers` JSON 添加 Streamable HTTP 和 SSE 插件，stdio 被拒绝；每个用户最多 10 个插件；请求头加密存储，任何接口、事件、日志和生成记录中都不出现原文。
- [ ] 内网地址在保存和连接时都被拦截（除非开启内网开关），不跟随重定向；管理员关闭 MCP 后，相关接口和智能体工具都不可用。
- [ ] 测试和刷新时拉取工具列表并存库；每个工具可以单独启用、停用或标为免确认；手动试用调用返回文本结果。
- [ ] 智能体每轮最多暴露 30 个 MCP 工具，工具名符合 `mcp__标识__工具`，且不超过 64 个字符；还原时只认本轮映射表，传入未启用的插件、其他用户的插件或已停用的工具都返回"工具不存在"。
- [ ] 默认每次调用都生成提案，卡片显示插件、工具、参数，并注明不可撤销；确认时插件或工具已停用、或参数 schema 已变化，返回 409；免确认工具直接调用；MCP 提案不参与自动执行；参数先按 inputSchema 校验。
- [ ] MCP 结果包装为不可信数据，只保留文本，二进制内容替换为说明，并按智能体规则截断；单次调用 30 秒超时，超时或连接失败作为工具错误返回给模型，不会让这一轮失败。
- [ ] 一轮对话里同一插件只建立一次连接，暂停或结束时关闭。

### 通用
- [ ] 前端：Skill 页（我的 / 全局、编辑器、导入导出、复制）；MCP 插件页（添加、测试、刷新、工具开关、参数查看、试用）；智能体面板的 Skill 选择器和 `/` 补全、会话插件选择、外部调用提案卡片；生成界面的 Skill 选择。没有页面级横向溢出，不写死颜色。
- [ ] 后端和前端的全量测试、lint 和构建都通过。

## Out of Scope

- stdio 类型的 MCP，即在服务器上启动本地进程。安全风险高，MuMu 也没有真正支持。
- Skill 市场与社区分享，由 prompt-workshop 负责。
- MCP 的 resources、prompts、sampling 能力，以及 OAuth 授权流程。鉴权只支持静态请求头。
- 在生成任务中使用 MCP。
