# 故事内时间线验收

## 两份倒叙样稿

从实际一致性检查发给测试提供方的 system 和 user 消息中取出两组样稿，分别交给两个独立、未提供预期答案的 Codex 模型会话。两组都是第一章雾月十日彻底熔毁唯一的佩剑，第三章有当场持剑和回忆当年持剑两条引句。

| 第三章当场持剑的日期 | 模型试读结果 |
| --- | --- |
| 雾月三日 | 返回空问题列表。 |
| 雾月十二日 | 提出佩剑已熔毁却再次持用的潜在矛盾，引用熔剑和当场持剑两条事实。回忆当年持剑的引句未列入证据。 |

这次试读使用 Codex 会话可用的模型，覆盖两份样稿。应用内提供方的调用、问题入库和检查中途改日期使用可控模型验证。未调用作者账号配置的商业模型。

## 整库恢复

以现有原生备份样书增加「星历」、章节默认雾月十日、场景单独雾月三日，并留一个场景沿用本章日期。经 SQLite 快照恢复及 PostgreSQL 16 的 pg_dump / pg_restore 分别恢复到独立数据库。恢复后以查看者读取，完整分页响应与快照前相同，三条记录日期、来源和顺序一致。两种数据库各通过一次。
