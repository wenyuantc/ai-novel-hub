# 开发文档：/developers 增加插件开发指南

> 父任务：`11-27-admin-plugin-packages`。决定编号 D1–D15、共同需求 R1–R7 见父任务 `prd.md`。
> 技术设计见同目录 `design.md`，实施计划见 `implement.md`。

## Goal

在公开的 `/developers` 页面增加完整的功能插件开发指南，让在本仓库内开发的人知道如何写一个内置功能插件（D15）。

## 依赖

依赖 `11-27-plugin-framework` 与 `11-27-short-drama-plugin`：文档内容必须与落定后的真实契约一致，并以短剧插件为例，因此排在这两者之后。

## Requirements

- W1 `/developers` 页面在现有开放 API 指南之外，新增「功能插件开发」一组章节，目录里可直接跳转。
- W2 内容覆盖：插件是什么与不是什么（内置模块、管理员启停、不支持运行时安装）；目录结构；清单字段；
  各个接入点（后端接口、后台任务、前端页面与导航、作品备份规则）；启停行为与数据保留；发布前检查清单。
- W3 给出一个可以照着做的最小插件示例，并以短剧插件作为完整示例走读。
- W4 文档中的字段名、路径、命令与代码一致；代码变更导致不一致时有测试能发现。
- W5 页面保持公开、无需登录；现有开放 API 指南的内容与锚点不变。
- W6 说明「功能插件」与「MCP 插件」的区别，避免混淆（D4）。

## Acceptance Criteria

- [ ] 未登录访问 `/developers` 能看到「功能插件开发」章节，目录跳转正常，窄屏下可读。
- [ ] 按最小示例的步骤操作，可以新增一个插件并在管理后台「功能插件」页看到它，启用后其页面可访问。
- [ ] 文档列出的清单字段与接入点与框架代码一一对应；改动清单字段而不更新文档时有测试失败。
- [ ] 现有开放 API 指南的章节、示例与链接无变化。

## 已核实的现状（代码证据）

- `/developers` 是无需登录的公开路由（`frontend/src/router.tsx:24`）。
- 页面内容是静态组件，集中在 `frontend/src/components/developerDocs/`（共 6 个文件、约 450 行），
  章节目录由 `content.ts` 的 `DOC_SECTIONS` 定义，页面骨架在 `frontend/src/pages/DeveloperDocsPage.tsx`。
- 现有内容全部是平台开放 API 的客户开发指南（快速开始、鉴权、分页、错误、接口参考）。

## Out of Scope

- 管理员如何启用插件、配置媒体存储与视频模型的部署说明（按项目惯例写在 README，由对应子任务负责）。
- 第三方插件的分发与安装说明（本期不支持）。
