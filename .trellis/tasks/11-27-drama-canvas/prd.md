# 短剧插件：无限创作画布

> 父任务：`11-27-admin-plugin-packages`。决定编号 D1–D15、共同需求 R1–R7 见父任务 `prd.md`。
> 规划深度：本文件现在只定需求与验收；`design.md`、`implement.md` 在轮到本子任务、其依赖已落地时再写，届时重新走一次评审。

## Goal

提供一块可以自由摆放文本、图片、视频节点的画布：节点可随意增删、拖动、连线，
连线表示把上游内容作为下游生成的参考（D10）。画布属于某一部剧，是分步流水线之外的自由试验空间（D11）。

## 依赖

依赖 `11-27-plugin-framework`、`11-27-media-storage`、`11-27-ai-media-models`、`11-27-short-drama-plugin`、`11-27-short-drama-media`
（画布要引用剧里的资产与分镜，并把成果存回去）。

## Requirements

- C1 每部剧有画布；画布可平移、缩放，节点数量不设界面上的固定格子。
- C2 三种节点：文本、图片、视频。可新增、删除、拖动、复制；文本节点可直接编辑，图片 / 视频节点可上传。
- C3 连线：从上游节点连到下游节点，表示下游生成时把上游内容作为参考。文本可作为提示词来源，图片可作为参考图。
- C4 生成：在图片节点上用连入的文本与图片生成图片；在视频节点上用连入的文本与图片生成视频；文本节点可用连入的文本让 AI 改写或扩写。
  生成是后台任务，节点上显示状态，可取消；完成后结果留在节点里，重新生成保留历史结果可切换。
- C5 引用流水线素材（D11）：可把本剧的角色造型图、场景图、道具图、分镜（含其提示词与视频）拖入画布成为节点。
- C6 存回流水线（D11）：可把图片节点的结果存为某个角色造型 / 场景 / 道具的图片，把视频节点的结果存为某条分镜的一个视频版本。
- C7 画布内容自动保存；两处同时编辑同一画布时不会互相静默覆盖。
- C8 权限、用量、预算、媒体存储、停用行为与短剧其他部分一致（R5、D5）。
- C9 画布随短剧数据进入作品备份（R4）。

## Acceptance Criteria

- [ ] 在一部剧的画布上新增文本、图片、视频节点，拖动摆放，刷新后位置与内容仍在。
- [ ] 把文本节点连到图片节点并生成，得到图片；再加一个图片节点作为参考连入，重新生成，两次结果都可切换查看。
- [ ] 把文本和图片节点连到视频节点并生成，节点显示进行中状态，完成后可播放；生成中可取消。
- [ ] 把本剧的一张角色造型图和一条分镜拖入画布成为节点，节点内容与来源一致。
- [ ] 把画布里生成的图片存为某角色造型的图片，在资产页可见；把生成的视频存为某分镜的版本，在视频制作页可见并可选定。
- [ ] 两个浏览器窗口同时编辑同一画布，后保存的一方得到冲突提示且本地内容不丢。
- [ ] 查看者可以浏览画布但不能编辑或生成。
- [ ] 一百个节点的画布拖动与缩放不卡顿。
- [ ] 含画布的作品导出备份再导入后，节点、连线、位置和引用关系还原。

## Out of Scope

- 多人实时协同编辑（同时在线的光标、实时同步）。
- 画布模板、节点分组、流程一键重跑整张图。
- 在画布里直接拼接成片（成片仍在分步界面导出）。
