# 短剧插件（无限创作画布）：实施计划

> 需求 `prd.md`（C1–C9），设计 `design.md`。依赖前五个子任务均已完成。
> 按顺序执行；每一步先写测试再写实现。中途只跑受影响测试加哨兵，全量门禁留到最后一步。

## 开始前复核

- [ ] 短剧两个子任务的实际表与接口：资产图表、分镜视频版本表的列名与数量上限、选定规则、任务受理入口、作品备份规则文件。
      与本设计第 7、10 节不一致处先改设计。
- [ ] 核心能力的实际接口：媒体存储的 `copy` 与派生文件、`ImageOptions`、外部任务驱动器、框架清单的 `upload_limits`。
- [ ] `@xyflow/react` 当前版本的节点自定义、仅渲染可见元素、受控与非受控用法：查阅该版本文档，并读现有的
      `frontend/src/components/relations/RelationGraph.tsx` 了解项目里的用法。
- [ ] 迁移链尾与本子任务的迁移编号。

## 步骤

### 1. 数据模型与迁移

- [ ] 四张表、约束与索引；迁移含降级；整库备份表目录更新。
- [ ] 迁移往返测试。

### 2. 画布与操作批次

- [ ] `services/canvas.py`：画布增改删、整图读取、`ops` 批量执行（七种操作）、修订号、数量上限。
- [ ] 连线校验：允许的类型组合、自连、重复、成环、引用节点不可作下游。
- [ ] 测试 `tests/test_drama_canvas_ops.py`：每种操作；一批内部分操作非法时整批回滚；修订过期 409 且响应带当前画布；
      各种非法连线；三百节点上限；删除节点带走其连线；查看者不可写；他剧的画布不可访问。

验证：`cd backend && uv run pytest tests/test_drama_canvas_ops.py -q`

### 3. 引用节点

- [ ] `services/canvas_refs.py`：四类来源的解析、读取时附带源头当前内容、来源已删除的表示、同剧校验。
- [ ] 测试：拖入造型后在资产页换选定图，画布读取到新图；来源删除后节点标记为已删除且不能作为输入；引用他剧素材被拒；引用节点的内容不可改。

### 4. 生成

- [ ] `services/canvas_run.py` 的输入汇集（纯函数为主：排序、拼接、截断）；`drama.canvas` 处理器的三种节点；结果行与外部任务行。
- [ ] 测试（假模型与假视频厂商）：文本拼接顺序；参考图超上限的截断与提示；上游未就绪被拒并指出节点；三种节点各自成功；
      重新生成保留旧结果并可切换；同一节点并发生成被拒、不同节点可同时进行；取消；失败原因；每节点十个结果上限；用量记录；
      生成完成不改变画布修订号。

回滚点：处理器单独提交。

### 5. 上传与存回

- [ ] 上传接口与清单里的体积上限登记；`promote` 接口（复制媒体对象并在目标表新增行）。
- [ ] 测试：上传的类型与大小校验；图片存回后在资产图列表可见且未被自动选定；视频存回后成为该分镜的新版本；目标达到上限时被拒；
      存回后删除画布结果不影响已存回的图片。

### 6. 备份规则

- [ ] 作品备份规则：三张结构表导出、结果表只导出文本结果、引用的重映射。
- [ ] 测试：含画布的作品导出再导入后节点、连线、位置、引用关系还原；媒体节点为空且页面可正常打开；旧版本备份仍可导入。

### 7. 前端：画布基础

- [ ] 画布列表（剧详情页的标签）与画布页；三种节点组件；增删、拖动、连线、平移缩放、小地图、多选删除。
- [ ] 操作队列、防抖成批提交、409 后的重放与兜底选择。
- [ ] 测试（Vitest，针对纯逻辑）：操作队列的合并（连续移动只留最后一次）；重放时无效操作被挑出；前端的成环与类型校验与服务端规则一致
      （同一组用例数据两边共用）。

### 8. 前端：生成、引用与存回

- [ ] 节点上的生成、取消、历史切换、上传、存回；素材侧栏与拖入；引用标记与「来源已删除」；视频节点点击后才加载播放器。
- [ ] 测试：节点状态随任务输出更新；查看者的控件隐藏且节点不可拖动；存回对话框的目标选择。

### 9. 性能与走查

- [ ] 构造一百个节点的画布，在浏览器里拖动与缩放并录制性能，确认无明显掉帧；记录到 `research/verification.md`。
      达不到时按顺序排查：节点组件的重渲染、是否订阅了整图状态、缩略图是否用了派生小图。
- [ ] 浏览器走查：文本连图片生成；加参考图重新生成并切换历史；文本加图片连视频生成与取消；拖入剧内素材；存回资产与分镜；
      两个窗口同时编辑触发冲突且本地内容不丢；管理员停用插件后页面显示未启用。

### 10. 文档与收口

- [ ] 规范与 README（见 `design.md` 第 12 节）。
- [ ] 逐条核对 `prd.md` 的验收标准并勾选。
- [ ] 全量门禁：
  - `cd backend && uv run ruff check . && uv run pytest -n 4 --dist loadfile --durations=20`
  - `cd frontend && npm run lint && npm run test && npm run build`

## 风险与对策

| 风险 | 对策 |
| --- | --- |
| 没有参考实现，交互细节容易返工 | 第 7 步完成后先给用户看一次可操作的基础画布，再做第 8 步 |
| 冲突重放逻辑出错导致丢内容 | 重放是纯函数并有专门测试；任何无法确定的情况都交给用户选择而不是自动丢弃 |
| 一百节点性能不达标 | 第 9 步专门验证并留出优化余地；设计上已避免整图状态订阅与视频自动加载 |
| 前后端的连线规则不一致 | 同一组用例数据驱动两边的测试 |
| 引用解析在来源表结构变化后失效 | 「开始前复核」核对来源表；解析集中在一个文件里 |
