# 作品笔记基础能力
## 目标与范围
父任务 ../11-05-mention-tracking/prd.md 的 R4；用户已选择四类来源全部实现并授权计划完成后直接实施。本子任务提供独立作品笔记的稳定身份与可用CRUD，作为提及索引来源。
## 要求
- 标题+纯文本正文的创建、列表/搜索/分页、查看、编辑、删除；刷新后仍存在。
- 写入权限沿人工作品内容；跨作品/无权404，回收站不可读写；revision CAS冲突保留草稿。
- 支持按id定位笔记；编辑与只读原文可复用，导航/切换时保护未保存内容。
- 项目备份包含原文，旧备份无笔记兼容；无自动AI注入。
## 验收
- [x] N1 CRUD/分页/搜索/空态/失败可重试。
- [x] N2 同版本并发写只有一个成功；另一个409且本地输入保留。
- [x] N3 读/写/管理权限与生命周期正确，跨项目id不泄漏。
- [x] N4 新旧项目备份兼容且笔记原文往返正确。
- [x] N5 笔记页可按id打开，不存在不会错误打开第一篇；离开/换笔记有草稿保护。
## 不在范围
收藏、固定、并排笔记工作台、富文本、笔记AI工具。提及高亮由兄弟任务集成。
## 依赖
不依赖兄弟实现；模型/API按父design固定，完成共享注册后通知兄弟。父AC4与全链路AC3由父任务最终验收。
