# 实施计划：设定 AI 可见策略

按单一任务分段实施。匹配、关联、投影、传输与备份共享同一交付合同；不能先发布一个看似已生效的「永不加入」开关，再补未接入的出口。分段门禁用于定位风险，不是允许部分发布的子任务。

## 0. 启动门禁与基线

- [x] 用户明确批准本轮最终规划后，才运行 `task.py start`。确认 PRD、设计、本计划、两个上下文清单齐全；原工作区无关改动不纳入。
- [x] 实施与核查按 Trellis 清单加载规范。从 [AI 出口](research/ai-paths.md) 建立仓库内入口清单：每个直接模型／向量调用都归为有设定数据（需门禁）或无设定数据（记录理由）。核查依赖锁定版本、测试专用 PostgreSQL schema 和本地真实浏览器。
- [x] 先用 FakeLLM／FakeEmbedder 固定升级前样本：主角和常驻、旧名单、整块世界观、章初时点、规划去重、人工三类提及及四来源权限。准备三套互不相同的标记：可发送值、受保护的结构化值／标签、作者原文重复字词；防止“全部删光”或全文替换也通过。

## 2. 匹配、资格与时点投影（AC1、AC2、AC3、AC7）

- [x] 扩展现有 matcher 与四来源词典，而不是复制 AI 专用短语引擎。用词典指纹隔离追踪、大小写和排除词缓存；保留 legacy 未配置算法与原索引规模。有多个候选、Unicode 折叠扩长、emoji、ASCII 边界、包含／部分交叠排除、被过滤长词后的合法短词回退、相邻命中、源变更和关闭重开用例。
- [x] 纯函数测试 4 档 × 4 种原因、关闭追踪、歧义、重叠原因、禁用来源和目标、单向一跳／环／独立入选、作用域和稳定顺序。检测用当前原始输入，不把规划／角色输出重新扫作触发。
- [x] 构造 AI 专用时点 DTO；逐类覆盖内建与四种共享／旧字段，原值／历史／选项和引用身份仍供人工查看。测试角色定位、阶段名、仅名单、关系另一端、成员／任职、字段摘要、伏笔等派生旁路。章节 5、20 章初／末、21 与未建章场景，旧模板锁定段、预算和去重均有正例。

## 3. 全入口接线及重发门禁（AC1、AC2、AC5、AC6）

- [x] 写作普通与规划保护段使用同一版本、同一资格；接生成、整章重写、局部改写、续写、批量和各 AI 预览。由选角／档案派生的检索词或向量输入也先经过投影；保留无设定润色、独立试写等原行为。
- [x] 接入分析（含自动）、向导、大纲、设定生成、关系生成／解析和显式任务主对象校验。用测试记录真实 messages 与 embedding payload；对每组入口证明允许内容仍在、隐藏内容及其结构化重复不在。
- [x] Agent 用同一回合的资格过滤目录、成员和关系、字段定义／选项、有效字段、时间线、分析／伏笔结构化结果、页面身份；过滤在搜索／分页前。覆盖查已知 ID、猜 ID、直接／确认／自动写回执、预览异常、缺回执补齐、作用域撤权。内部人工提案／效果资料不直接交给模型。
- [x] 所有受控模型 payload 绑定构建代次；传输钩子逐实际请求验戳，同 policy save 屏障。用受控双连接和本地 HTTP server 验证两种竞态顺序、响应体流未完仍能保存、超时／失败／取消／重试与重定向，含 SDK 异常包装。检查无项目范围的模型请求不被误拦，SSRF/凭据不变。
- [x] 实现会话 epoch、待确认与续跑失效、首轮安全重建；已有工具结果、摘要、旧输入快照、任务重试、第二轮、进程重启均用负例验证。暂停批量保留已完成章，已经执行过的动作不重做。若当前仍在收响应，不伪称撤回或隐藏人类历史。

## 4. 兼容格式与用户操作（AC2、AC3、AC4、AC5、AC6、AC7）

- [x] 完整备份 v6 注册和重映射所有策略、字段 flags、关联端点；严格校验跨作品、重复、自关联、不支持键和值、丢失必需记录，旧格式升级与 v6 缺数据分开。往返用真实章节时点与请求验证语义，不只比较 JSON。新版本卡片携带范围、包外映射、冲突预览、过期 CAS、复用不扩大可见性；依赖不完整整笔不写。

- [x] 前端实现复用「AI 与提及」、共享定义开关、旧／内建字段开关、有向目标选择和保留草稿。扩展九类标记、列表、热力图及深链；查看不改变人工内容或模型权限。旧会话提示新开，失败任务可理解地重建／重试。覆盖 409、网络失败重试、加载、只读、用户／项目切换、旧响应、权限撤回及键盘操作。
- [x] 在本地真实界面用普通作者和只读权限、桌面与 375px、亮暗主题、键盘验证。真实界面包含新旧条目、三种字段粒度、A→B→C、跨页目标、排除词生效、配置后旧会话可读不可续、旧版导入。不可自动化的场景逐项注明证据与阻碍，不把未验写为通过。
