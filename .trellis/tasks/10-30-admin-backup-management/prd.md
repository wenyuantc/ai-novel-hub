状态：`in_progress`，用户于 2026-11-02 回复“开始”，已批准最新完整规划并激活现有任务。优先级 P2。

## 目标与用户价值

让平台维护者按计划或手动创建可恢复的整库备份，掌握最近成功、可用副本与失败情况，减少手工备份遗漏；通过分项授权控制全站备份访问。

## 已确认需求

R1–R10 均由用户在 2026-11-02 确认；R11–R12 保留原草案的可靠性目标和项目现有集成约束。

- **R1 整库范围**：备份整个应用数据库，覆盖数据库内账号、角色权限、平台配置和全部作品。数据库之外的部署配置/加密主密钥单独保管；首期不新增作品 JSON 定时或批量备份。
- **R2 存储选择**：支持宿主机持久目录与 S3 兼容对象存储，各有独立开关，允许仅本地、仅 S3、同时启用。Docker 挂载本地目录，仅向该次执行启用的目的地保存。
- **R3 数据库类型**：同时支持 PostgreSQL 和文件 SQLite，分别验证真实整库备份与恢复。
- **R4 恢复入口**：提供备份下载和按数据库类型区分的命令行恢复指南。说明停服、核对目标、解密、配套原 ENCRYPTION_KEY、恢复后重启的条件；不提供后台执行整库覆盖恢复。
- **R5 分项授权**：查看记录、配置计划及连接参数、手动执行和文件下载分别授权，可委派给其他管理角色。授权分配仍由超管管理；内容管理员、审核员、普通用户和历史自定义角色不自动获得新备份权限。
- **R6 日计划与启停**：执行时间可配置，默认每天北京时间 03:00；定时有独立开关，关闭后仍可手动执行。初次配置未就绪时不自动运行。
- **R7 独立保留**：本地与 S3 分别配置保留份数，默认各保留最近 7 份成功备份。按各目的地实际成功产物独立清理，失败/中断不挤占成功名额。
- **R8 失败提醒**：后台醒目提示加 SMTP 邮件；接收人可配置。备份、各存储、清理及邮件结果分别展示，邮件失败不能改写真实备份结果或伪造已送达。
- **R9 后台连接配置**：有配置权限的管理员在后台管理 S3、SMTP 参数、敏感凭据及收件人，持久保存并对后续执行生效；凭据加密存储，读取不返回明文或密文，字段留空不误清原凭据。
- **R10 文件加密**：支持加密开关，默认开启。独立备份密码在后台设置并加密保存，管理员另行保管恢复用密码；记录和下载反映该次执行的实际格式。变更开关/密码只作用于新备份，旧加密文件仍使用原密码恢复。
- **R11 可靠性与可观察性**：保留计划、来源、执行状态、开始/结束时间、大小和安全错误摘要，重启后仍可核对；同一实例防并发/重复执行，清理失败、存储不可用和执行中断均有明确结果，部分成功不能误报全部成功。
- **R12 集成与安全**：接入既有角色、会话失效和管理员审计；管理写不绕过授权/提交边界。页面、下载地址、校验响应、邮件、审计及日志不泄露凭据。文件和对象操作限定于本实例拥有的备份，保留原个人作品备份、六项系统设置及 AI 任务语义。

## 验收标准

- [x] **AC1（R6、R11）**：计划按已保存时间触发，成功和失败均有独立执行记录；重启后计划及已记录结果可查。
- [x] **AC2（R8、R11）**：最近完整成功、可用副本和最近失败可区分；部分成功明确指出失败目的地，失败提醒不显示为成功。
- [x] **AC3（R7、R11）**：并发或重复触发、清理失败、存储不可用、服务关停和中断有明确结果；不留下仍执行却已释放的重复执行窗口。
- [x] **AC4（R1、R4）**：页面与恢复说明准确区分整库备份和作品 JSON 的覆盖范围，列出备份密码与原始加密配置的恢复条件。
- [x] **AC5（R5）**：四类动作逐项检查当前权限；普通用户和未获对应权限的管理角色不可访问，历史自定义角色无隐式新增授权。
- [x] **AC6（R2）**：覆盖仅本地、仅 S3、同时启用；关闭目的地不产生留存副本或误报失败，任一已启用目的地失败不能展示全部成功。
- [x] **AC7（R1、R3）**：在隔离 PostgreSQL 与文件 SQLite 分别执行真实备份和恢复，比较账号、角色权限、平台配置、作品及引用完整性，并验证配套原密钥能解密原凭据。
- [x] **AC8（R4）**：可鉴权下载实际产物，大文件下载流可用；按两种数据库的指南完成停服/核对/解密/恢复/重启，不存在后台整库覆盖恢复入口或接口。
- [x] **AC9（R5、R12）**：不同非超管角色权限组合通过直接 HTTP 正反验证；只有查看权限不能取文件，撤权后新请求受限且前端清除相关入口/数据/秘密草稿，旧响应不复活。
- [x] **AC10（R6）**：默认北京时间每天 03:00，改时间按新配置安排；定时开关不阻断手动，时间和开关重启后保留，不重复受理同一计划意图。
- [x] **AC11（R7）**：默认两处各 7 份，可分别配置并重启保留；不同份数真实独立清理，失败/中断不挤占成功名额，删除失败不得假报已删除。
- [x] **AC12（R8）**：真实 SMTP 捕获失败通知，覆盖备份失败、任一启用存储失败和清理异常；邮件仅含安全摘要，发送失败/未知独立可见，不反写备份结果。
- [x] **AC13（R9、R12）**：连接参数/收件人持久且按配置权限访问，版本冲突不静默覆盖，保存与审计原子；秘密不经 API、校验错误、审计、日志、邮件和界面回显泄露。
- [x] **AC14（R10）**：默认开启加密，独立密码加密保存且不回传；两种文件模式分别生成、保存、下载并真实恢复，加密产物只有正确密码可还原，错误密码/损坏文件被拒绝，旧产物保留实际格式。
