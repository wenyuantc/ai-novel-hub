# 实施与验收计划

需求对照 [PRD](./prd.md)，接口和数据边界见 [设计](./design.md)。实际交付与验证结果记录在文末。

## 实施顺序

1. **迁移与单书备份**（A1、A6）。以当前迁移头新建连载目标、章节条目、定稿、发布记录。补归属、索引、并发约束与迁移回退保护。同步模型注册、章节删除关联检查、单书备份版本与引用重映射。用旧作品、已发布后删掉的章及两平台样本验证往返。
2. **定稿与历史**（A1、A4）。从读者可见的章节投影获取稳定快照，接入权限、并发基线与现有草稿保存约定。通过 API 证明“确认 A → 保存 B → 预览仍是 A → 确认 B”以及普通历史清理不影响定稿。覆盖章节标题、可见排版变化、作者备注和空白正文。
3. **排期、发布和统计**（A2、A3、A5）。实现日更目标、章节计划日期、首次发布时间查询和库存折算。登记动作以确定的稿次追加记录。覆盖两个平台同时发布、请求重试、重定稿竞态、补录更早的实际时间、未设目标和月界。
4. **工作台与文件导出**（A1–A6）。接入作品导航，按“月历 → 当天清单 → 章节与定稿预览 → 登记”贯通操作。复用已有差异组件和导出渲染器。加入未保存提示、权限变化、切换章节后的晚到响应和移动布局检查。
5. **集成与全量验收**。核实新增路径对普通章节保存、现有多格式导出、旧单书备份、章节删除和管理员审计的影响。更新根 README、项目规范及第 18 项验收记录。只有真实验证通过的项目才在 TODOS 中勾选。

每步先运行对应定向回归，最后统一执行全量检查。工作树固定在 `codex/serialization-workbench`，执行前再次确认分支、迁移头与工作区状态。

## 验证方法

| 验证 | 命令或操作 |
| --- | --- |
| 规划交付 | 从独立工作树运行 `python3 .trellis/scripts/task.py validate 11-18-serialization-workbench` 并检查 PRD、设计、实施计划的引用。 |
| 后端定向 | 在 backend 目录运行 `uv run pytest -q -k 'serialization or chapter_versions or document_export or project_transfer or chapter_fk_guard'`。新增连载用例按 serialization 命名。 |
| 新旧数据库与并发 | 在隔离 SQLite、PostgreSQL 分别验升级、空表降级、有历史的保护与单书备份往返。在 PostgreSQL 用两个连接验证定稿与发布竞争、两个渠道并行登记、同次请求重放。核对实际结果和记录条数。 |
| 前端定向 | 在 frontend 目录运行 `npm test -- serialization`。覆盖完整天数与余章、无目标、北京跨日、表单稿次、权限与过期响应。 |
| 项目完整门禁 | 在 backend 运行 `uv run ruff check .`，默认 SQLite 用 `uv run pytest -n 4 --dist loadfile --durations=20`。启用项目专用 PostgreSQL 连接时按项目规范串行 `uv run pytest -n 0 --durations=20`。在 frontend 运行 `npm run lint`、`npm run build`、`npm test`。记录通过、跳过、预期失败及实际运行环境。 |
| 真实操作 | 在隔离作品完成 PRD 的 A1–A6。桌面和窄屏核对月历、计划日与实际日、稿次预览和差异。实际下载历史稿，打开文件确认是带原章名的 A。改成 B、重复登记、跨平台登记后重新加载核对存稿与记录。 |
| 最终复核 | Trellis 检查代理覆盖整个前后端变更。`git diff --check` 及新增文件的空白检查通过。汇总验收证据并依项目流程审阅提交方案。 |

## 失败与回退

- 迁移、备份、权限或并发专项出现偏差时，先修复再继续依赖该行为的步骤。两库分别记录结果。
- 预览和当前稿次冲突时，保留输入的渠道和时间，引导重新查看稿件。写入失败后，库存、发布记录与计划完成状态应一致。
- 实例已经有发布记录时，回退应用保留数据表。任何破坏性迁移按设计中的备份与降级保护处理。

## 实施记录

- 已实现 0064 迁移、工作台读写、稿件冻结与比对、作品导航与章节编辑器入口、可阅读附件和 v15 单书备份。
- 排期和定稿提交回传详情的场景 ID，在章锁内确认归属。SQLite 复用章节整数 ID 时，旧页面仍会收到冲突。生成期间允许读取上次冻结的待发稿。
- 源章删除后保留有发布记录的稿件。Agent 对无法从撤销快照还原的人工排期与定稿执行局部保护。读接口在另取一致性快照前归还鉴权连接，文档渲染过程也会释放连接。
