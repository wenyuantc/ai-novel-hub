# 短剧工作台浏览器验收

2026 年 11 月 28 日使用 Google Chrome 158.0.8127.37、正式前端、FastAPI 后端和临时 SQLite 数据库验收。作者、管理员、查看者、编辑者分别使用独立会话。所有小说正文和人物均为测试数据。浏览器请求经过 Vite 的实际 API 代理。四类 AI 任务通过正式的 OpenAI 兼容适配器向本机 HTTP 服务发送请求，由该服务按测试用例分片返回确定性内容和用量。真实模型推理另见同目录的 `live-model-verification.md`。

| 验收项 | 浏览器操作与观察 | 结果 |
| --- | --- | --- |
| 插件启停 | 管理员停用后，刷新已打开的工作台，作品导航隐藏「短剧」，直达页提示未启用，短剧读取接口返回 403。重新启用后可读原有剧本。 | 通过 |
| 建剧与正文快照 | 建剧时选择风格、画幅的默认值，在新建剧集中选取连续的《雨夜》《归舟》。核对快照等于两章正文以空行相连。随后通过章节 API 修改《雨夜》，刷新工作台，快照仍为原文。 | 通过 |
| 改写与取消 | 在剧本页直接发起 AI 改写，看到尚未结束的场景文本。中途取消后任务进入 cancelled，已保存剧本保持原值。再次改写后手动补写一句，失焦保存，刷新后仍在。 | 通过 |
| 资产与关联 | 提取得到角色阿禾、船衣造型、渡口场景、铜铃道具。卡片显示已关联小说角色阿禾，并补入「乌发，左眉有痣」。将短剧角色改为「剧中阿禾」，小说关联仍显示原名。 | 通过 |
| 图片提示词 | 点击造型的「生成图片提示词」后可在卡片查看生成内容。编辑造型提示词并失焦后，再从 API 读取即为修改后的文字。 | 通过 |
| 分镜 | 从剧本生成两条分镜，核对画面、景别、时长及引用。拖动手柄交换镜头顺序，逐条新增和删除可保存。「重新拆分镜」先弹出确认，取消后维持现有镜头。 | 通过 |
| 视频提示词 | 点击分镜的「生成视频提示词」并观察结果，再修改视频提示词，移动焦点后重新读取，内容为手改稿。 | 通过 |
| 409 冲突 | 输入新的集名，在另一请求先提交不同值，再让本地输入失焦。页面保留本地草稿，确认「覆盖保存」后服务端返回本地值。 | 通过 |
| 查看者与编辑者 | 查看者可读剧本与分镜，剧本文本框只读，页面隐藏 AI 和新增分镜按钮。无自有文本模型的编辑者初次进入显示配置提示，授予作者模型使用权限后，编辑者可在工作台生成并保存视频提示词。 | 通过 |
| 用量 | 打开作品 AI 用量页面，看到本地模型、任务类型、调用结果以及模型回传的输入和输出 token 数。 | 通过 |
| 文档导出 | 通过工作台的「导出文档」分别下载包含剧本及分镜表的 Markdown 和 DOCX。用文本和 Word 文档解析器分别读回，确认含手改台词及两条分镜标题。 | 通过 |
| 窄屏与主题 | 在 375 × 812 视口打开含两条分镜的工作台，浅色和暗色模式都能使用步骤栏、镜头列表及编辑器。两次测量的页面总宽均为 375 CSS 像素。 | 通过 |

本轮浏览器测试曾发现，配置了文本模型的作者直接打开工作台时，页面未请求模型配置，导致改写按钮缺失。修复后从新的浏览器会话直达同一工作台，观察到配置请求返回 200，改写任务返回 202，流式输出、取消、完成保存均可用。

另外在真实 Ollama 模型环境中创建独立短剧《灯下的约定》和剧集《旧信》。Chrome 工作台发起改写后收到 202，Qwen2.5-3B-Instruct 量化模型完成任务。重新打开剧本页，显示的 163 字剧本与后端保存的文本完全一致，含原文人物苏青，首行是「## S01 | 内景 · 书铺 | 傍晚」。
