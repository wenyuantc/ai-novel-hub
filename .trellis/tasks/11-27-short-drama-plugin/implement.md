## 风险与对策

| 风险 | 对策 |
| --- | --- |
| 任务处理器的协作与身份约定复杂，实现不全会留下越权或撤权后仍写入的漏洞 | 第 8 步先读后写；按现有处理器逐项对齐；测试覆盖有无授权两种情况 |
| 模型输出的 JSON 不稳定 | 容错解析 + 带错误信息重试一次 + 保留原始输出；提示词里给出严格的输出示例 |
| 长剧本导致分镜输出被截断 | 按场景分批并记断点；批次大小做成常量便于调整 |
| 作品备份的版本与重映射规则容易漏列 | 反射测试强制每张表有规则；往返测试比较逐表内容 |
| 工作台页面膨胀成巨型文件 | 一开始就按步骤拆组件；单文件超过约 400 行即再拆 |
| 提示词照搬后与本项目的输出格式要求不匹配 | 第 7 步用快照与解析测试钉住；浏览器走查用真实模型跑一遍 |
