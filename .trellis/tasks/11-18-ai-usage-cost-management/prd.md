# AI 用量与费用管理

## 目标

落实 [TODOS.md 第 17 项](../../../TODOS.md#17-ai-用量与费用管理)。作者能查明各类 AI 调用的消耗及费用估算，在启动批量生成前了解预计花费，并在接近或超过作品预算或账号预算时收到提醒。管理员能在管理后台查看全站用量与费用记录。

## 现状

- [生成日志](../../../backend/app/models/entities.py#L688)已有作品、章节、发起人、任务类型、模型归属及可空的输入和输出 token 字段。[智能体工具调用](../../../backend/app/services/agent/runner.py#L1011)已接收用量事件并写入日志。普通文本 [Provider 流接口](../../../backend/app/ai/providers/base.py#L50)只返回文本增量，正文生成和章节分析没有通过该接口接收 token 用量。
- [批量生成预览](../../../frontend/src/components/batch/BatchGenerateModal.tsx#L270)已展示待生成章节、预计耗时和是否自动分析。[批量执行](../../../backend/app/services/batch_service.py#L1428)包含生成尝试、失败重试和后续分析。
- 协作者优先使用本人模型。使用作者授权模型时由作者承担费用。章节日志按发起人读取，并对作者授权模型信息进行权限投影。[协作要求](../../../TODOS.md#11-作品级协作者邀请) · [协作执行规范](../../spec/backend/error-handling.md) · [章节日志](../../../backend/app/services/generation_log_service.py#L160)
- 管理员首页与全站任务监控各有独立入口和读权限，可沿用其页面导航和鉴权约定。[管理员首页规范](../../spec/backend/admin-dashboard.md) · [全站任务监控规范](../../spec/backend/admin-task-monitoring.md)

## 需求

1. 补齐文本、智能体工具轮次、图片和向量等模型调用的用量记录，覆盖正文生成、自动分析与重试。关联到可确定的作品、章节和任务，保留各次实际调用的消耗。
2. 支持按作品、模型、任务类型和时间范围查看 token 用量与估算费用，并查看章节的步骤明细和合计。
3. 模型配置所有者可配置单价。按业务返回的计量单位计价，文本可分别配置输入与输出 token 单价，向量可按输入 token 计，图片可按实际返回张数计。分别标明模型服务返回的用量、系统估算的用量和未知用量。缺少可用计量或单价的调用应明确提示费用无法计算。费用按定价币种分别汇总，调价按新调用生效。
4. 在提交批量生成前展示预计费用、覆盖的步骤和估算依据，注明因重试等不确定因素可能额外产生的费用。
5. 同时支持作品预算与账号预算，分别设置预算金额与提醒阈值。作者能查看两种预算各自的使用进度和提醒状态。在批量生成预览中，按当前用户可见权限显示适用预算及本批预计消耗。
   - 账号预算按自然月重置。自然月边界沿用项目统计的北京时间口径，每月 1 日 00:00 开始新的预算周期，已发生的调用仍可按原月份查询。费用按承担费用的模型配置账号归集，覆盖其跨作品消耗与无作品归属消耗。协作者使用作者授权模型时，费用计入作者账号预算。[项目统计时区](../../spec/backend/admin-dashboard.md#计数与时间)
   - 作品预算由作者设置，按全书累计，跨月延续已有进度，只归集该作品中由作者承担的费用。协作者使用作者授权模型时同时影响作品预算与作者账号预算。协作者使用本人模型时，费用只计入其本人账号预算。
   - 提醒在页面展示。个人视图按真实发起人和付费归属展示相应的用量或计费字段。协作者可查看本人调用的用量和自费金额。使用作者授权模型时，协作者可见费用承担方，作者的价格与预算详情仅对作者可见。作者可查看本人承担的费用，包括授权模型所产生的费用明细。个人视图遵守已有的调用内容与模型配置隔离。
6. 管理后台提供独立的「全站 AI 用量与费用」只读页面。有全站用量查看权限的管理员可查看本站各账号的所有已记录调用，包括无作品归属、失败、重试和用量未知的调用。页面提供全站汇总和分页明细，可按账号、作品、模型、任务类型和时间范围筛选。全站读权限只覆盖用量与费用字段，记录展示计量状态与计价结果，访问模型凭据、提示词和正文仍受原有权限约束。

## 验收标准

- [x] 生成一章并自动分析，期间一次生成尝试触发重试。明细可区分首次尝试、重试和分析，章节合计包含可计量的各次调用，同一次调用只汇总一次。
- [x] 筛选作品、模型、任务类型及时间范围后，汇总与筛选后的明细一致。缺少用量的调用显示为未知，存在合理估算时标注为估算。
- [x] 配置模型单价后，有对应计量数据的调用可显示估算费用。缺少单价或计量数据的调用显示不可计算，汇总可识别费用覆盖不全的情况。
- [x] 提交批量生成前，作者可看到预计费用及所含步骤。关闭自动分析时，预估不包含分析费用。
- [x] 同时配置账号和作品预算，两个额度分别计算和提醒。同一账号使用两部作品后，作品预算各自反映本书消耗，账号预算反映跨作品消耗。批量预估显示适用的预算进度影响，页面可区分达到提醒阈值和达到预算上限。
- [x] 在北京时间月末和次月 1 日 00:00 各记录一次同一作品的调用。新月的账号预算只计入新月调用，旧月记录仍可查询，作品预算累计包含两次调用。
- [x] 同一协作者分别用本人模型和作者授权模型发起调用。自费用量只增加协作者的账号预算进度。授权用量同时增加作者的账号预算进度和该作品的预算进度。作者可核对授权用量的价格与金额，协作者可查看自己的调用用量，无法从明细、筛选或批量预估读取作者的模型单价及预算金额。
- [x] 准备两个账号、两个作品以及至少一条无作品归属调用。具备全站用量查看权限的管理员可在独立页面查到全部记录，按账号等条件筛选时汇总和明细口径一致。普通账号或缺少对应权限的管理账号通过直接访问页面和接口均无法读取全站数据。
- [x] 向量调用和图片生成有独立的计量单位和状态。定价币种各自汇总，修改单价后已记录的费用保持原值。无可计价数据时明确展示覆盖缺口。
- [x] 旧生成日志仍可查阅。费用页面标明新计量记录的覆盖起点，作品备份导入的历史日志不产生本站的新调用费用或预算用量。

## 范围边界

- 费用为应用内依据用量和配置单价计算的估算值。本期涵盖记录、估算、查询与界面提醒。供应商账单同步、自动汇率换算、结算、自动扣费和超预算后的硬拦截属于独立需求。
- 旧生成日志按原入口和权限展示。全站费用汇总与预算进度从本功能开始计量的可信记录计算，并展示计量起点和数据覆盖缺口。

## 分时单价补充需求

在现有「模型单价」弹窗保留固定单价模式，增加可选的分时单价。每个模型配置可设置时区和每日空闲时段，允许跨零点，时段外使用高峰单价。时区默认北京时间。币种和计量单位沿用该模型配置，分别填写高峰价和空闲价。

- [x] 原有固定单价无需重新录入。开启分时定价后，配置页能保存并回显空闲时段、时区及两档单价。
- [x] 空闲时段含开始时刻、不含结束时刻，同一时刻作为两端时提示校验错误。跨零点配置在零点前后均选中正确档位。
- [x] 每次请求、续写和重试按自己的发送时刻选档。核对一个临界点前启动、结束于临界点后的请求，以及临界点后一次新的重试。历史明细保存命中档位和实际采用的单价，后续改价或改时段时仍可核对原金额。
- [x] 批量预览展示预估采用的档位和时区，提示排队或跨时段时实际金额可能变化。个人和作品预算继续汇总各次调用已经记录的金额。使用作者授权模型的协作者沿用费用可见性规则。

分时规则每天重复，支持每日多个空闲时段。按星期设置留待独立需求。

## 缓存命中输入单价补充需求

文本模型的固定价、高峰价与空闲价均可配置可选的「每百万缓存命中输入 tokens」单价。输入总量保持原统计口径。供应商返回命中量时，从总输入中扣除该部分，按请求发送时所选档位的命中价计算。未配置命中价时沿用同档普通输入价。缺少有效命中量时，费用按普通输入价估算并标注命中量未知。批量预估按普通输入价推算，因为发送前无法确认命中量。调用明细保留已知命中量及该次采用的单价，沿用费用可见性规则。

- [x] 固定价和高峰／空闲两档都可设置、保存、回显、清除命中价，并接受零价。老配置和历史金额保留。
- [x] 用可控供应商响应验证命中量、未命中量和输出量分别计价，且输入汇总不重复计数。缺失、显式零和无效命中量可区分。换价后，以请求当时冻结的单价复查历史费用。
- [x] 批量预估说明采用普通输入价，作者授权模型的命中单价只向原有权限允许的读者展示。

## 多个空闲时段补充需求

- [x] 分时定价弹窗可添加、删除及编辑每日空闲时段，启用时至少保留一条。旧单时段配置直接回显为一条。
- [x] 各空闲区间可跨零点，共用同一空闲价和时区。区间含开始分钟、不含结束分钟。拒绝空区间和重叠，允许相邻。其余时间用高峰价。
- [x] 实际调用、独立重试和批量预估命中任一空闲时段时使用空闲价。修改时段后，已入账费用与旧的待发送价格快照可继续读取。
