# AI 用量与费用管理实施计划

按以下顺序交付一个 Trellis 任务。计量、用户预算和全站视图共用一套记录及汇总，阶段验收通过后再接入下游页面。

## 1. 调用清单与存储

- [x] 从 `generate_stream`、`chat_tools_stream`、`generate_image` 和 `embed` 的实际调用点建立覆盖矩阵。记录事务边界、发起人、付费归属、作品／章节／任务来源、业务请求与 SDK 重试策略。覆盖正文、分析、智能体、向导、灵感、一致性、图片、检索索引与联机测试。
- [x] 新增用量、模型单价、预算表、筛选索引和迁移。验证旧数据库升级、SQLite `create_all` 与迁移形状一致、PostgreSQL 往返及历史记录兼容。
- [x] 验证删号、删模型、删章、任务清理、回收站彻底删除和单书导入产生的外键、计量保留和身份隔离行为。更新整库备份结构检查。

**验收**　旧作品和原日志入口可用。导入记录无需计费。迁移前后可按验证数据库中的已知种子数据核对完整性。

## 2. Provider 观测与业务接入

- [x] 实现单次调用的用量接收、稳定尝试 ID、失败与取消收尾。为支持的适配器接收真实用量，并适配缺失、部分返回和提供方兼容差异。OpenAI 兼容文本流若需要显式请求用量，加入不支持选项时的定向兼容测试，每次重发单独观测。
- [x] 先贯通正文、自动分析与批量重试。覆盖拿到上游用量但内容保存失败、取消、撤权、任务重试或数据库写重试的流程。之后接入工具轮次、向量、图片和无作品调用。验证图片下载与缓存命中产生零额外用量记录。
- [x] 保存已发出调用的计量元数据，检查异步取消与恢复、SQLite 写竞争、PostgreSQL 锁序、计量写入失败后的缺口处理和任务状态一致性。通过面向真实 Provider 请求路径的本地假上游检查发送次数与记录对应关系。

**验收**　从实际章节生成入口走完一次生成失败重发和分析，能核对每次请求的记录及计量状态。受控预检、撤权拒绝与请求缓存保持原有语义。

## 3. 计价、预算与个人界面

- [x] 实现配置所有者的单价维护、调用时价格版本、按币种汇总和费用缺口计数。覆盖精度、输入限制、零价、修改价格、旧模型配置失效和跨币种。
- [x] 实现过滤、分页、个人归属投影、章节明细和账号／作品预算。调用执行人与费用承担人分别测试。按北京时间验证跨月边界，覆盖以自费模型及作者授权模型执行的情况。
- [x] 在模型配置入口加入价格设置，在个人和作品界面提供用量与预算入口。按可见权限显示金额、阈值提醒及未计价记录。
- [x] 扩展批量生成预估与弹窗，结合真实模型选择、当前章节范围和分析开关。覆盖模型切换、预算阈值、暂时无法估算、范围或身份变化后的旧请求。测试预览期间零模型调用。

**验收**　作者承担的调用同时进入相应的账号与作品预算，协作者自费仅计个人账号预算；同一调用在费用汇总中计一次。批量预览所列步骤与将要执行的步骤可对照核验。

## 4. 管理后台

- [x] 注册独立全站用量读权限，接入内置超管和现有角色授权模型。后端列表、汇总均校验该动作，前端路由、侧栏、菜单与当前登录会话同步。
- [x] 实现「全站 AI 用量与费用」的筛选、分页、汇总和明细。验证跨用户、无作品、失败和未知记录。检查不同筛选组合的总量和明细一致，接口字段限于用量与费用元数据。
- [x] 以普通用户、仅有其他管理权限的账号和有全站用量权限的管理员验证入口和 API；浏览器验证撤权或退出登录后旧响应失效。

**验收**　授权管理员可查看全部已计量记录并定位具体调用。普通用户和无专门权限的管理账号无法访问全站数据。

## 5. 发布前验证

- [x] 优先运行变更模块的用量、迁移、生成日志、Provider、批量、协作、RBAC 和备份测试。列出新增的调用点及其覆盖证据，将集成验证与单元验证对应到 PRD 验收条目。
- [x] 后端完整门禁，在 `backend/` 执行 `uv run ruff check .` 与 `uv run pytest -n 4 --dist loadfile --durations=20`。隔离 PostgreSQL 按项目配置使用 `-n 0`，覆盖迁移、条件更新、预算／全站筛选一致性和锁相关用例。
- [x] 前端完整门禁，在 `frontend/` 执行 `npm run lint`、`npm run build` 与 `npm test`。使用本地假上游和隔离数据库预演模型配置、章节费用、批量预估、双层预算、协作金额投影及管理员全站明细。
- [x] 按项目规范更新根目录 README 和对应 Trellis 契约，总结统计覆盖起点与回退策略。核对 `TODOS.md` 第 17 项及实际覆盖范围后更新完成状态。

应用回退需保留计量表和历史记录，使用兼容 `ai_usage.read` 的权限目录。对计量范围、费用汇总、管理员字段或受控发送边界进行变更时，重新执行相关端到端验收。
