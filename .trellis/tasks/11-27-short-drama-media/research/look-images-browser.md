# 角色造型生图浏览器验收

2026 年 11 月 28 日，使用独立 Chrome 会话、临时 SQLite、本地媒体目录、正式前后端和 OpenAI 兼容的本地受控 HTTP 图像服务验收。测试作者只配置图片模型。图片服务根据实际收到的生成或编辑请求返回不同色块，便于核对选中版本、参考图像素和落库结果。该测试验证功能链路，不评估商业模型的画质。

| 场景 | 操作及观察 |
| --- | --- |
| 素材库首次生图 | 在《岸上的信使》的剧级素材库找到角色苏淮的默认造型，点击「生成图片」。请求返回 202，后台任务成功。服务收到模型名、1536 × 864 的请求尺寸、剧风格和造型的图片提示词。正式媒体接口返回可解码的 160 × 90 测试缩略图。刷新后图片仍显示在同一张造型卡上。 |
| 第二套造型使用默认图作参考 | 在同一素材库点击「红衫」造型的「生成图片」。实际发到本机服务的是图片编辑请求，multipart 内含一张 160 × 90 的 JPEG。源图首像素 RGB 为 (43, 123, 170)，参考 JPEG 解码为 (42, 123, 170)，符合 JPEG 编码误差。请求同时包含红衫提示词和同一角色相貌要求。任务成功后新图和默认图分别显示，两者在刷新后均可查看。数据库的第二张图记录了第一张的引用。 |
| 工作台重新生成与版本管理 | 从集工作台进入「资产」，重新生成默认造型，历史中同时保留两版。点击「选用」后回读服务端确认选定版本切换，删除未选用版本后，仅保留当前版本。红衫的已生成图片仍可打开。 |
| 查看者和匿名访问 | 查看者可以在集工作台读取两张缩略图，页面隐藏生成和选用按钮。查看者提交同一条生成请求得到 403。匿名直达两张媒体缩略图分别得到 404。 |
| 停用与恢复 | 管理员停用短剧后，作者刷新工作台时看到未启用提示，旧缩略图直达请求被拒。重新启用后，红衫造型的图片仍可在原工作台读取。 |
