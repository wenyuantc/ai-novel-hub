# 剧本步骤内模型选择的阶段验收

此记录对应首次在剧本步骤内选择文本模型的实现。后续需求将文本、图片和视频统一移至剧集顶部，这份记录仅保留当时的请求与模型调用证据。

2026 年 11 月 28 日，在隔离 Chrome、临时 SQLite 和真实前后端中检查剧本页。使用两个测试文本配置，让本机 OpenAI 兼容 HTTP 服务记录实际请求的模型名。每次均核对浏览器请求和任务终态。

| 操作 | 浏览器与模型服务的实际结果 |
| --- | --- |
| 作者仅有图片模型时进入剧本页 | 页面提示改写需要文本模型，保留配置入口和手写文本框，隐藏 AI 改写按钮。 |
| 添加默认、备选两套文本配置后，选择「备选剧本模型」并改写 | 浏览器提交 `{"ai_config_id":3,"kind":"drama.rewrite"}`。模型服务收到 `browser-choice-text`，任务成功。 |
| 点选择器的清除按钮，再次改写 | 浏览器提交 `{"kind":"drama.rewrite"}`。模型服务收到默认配置 2 的 `browser-default-text`，任务成功。 |
| 查看者打开同一剧集的剧本页 | 已保存的剧本可读，文本框只读，模型选择器及 AI 改写按钮均隐藏。 |
