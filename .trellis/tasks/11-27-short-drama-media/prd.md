# 短剧插件：资产生图、分镜生视频与成片导出

> 父任务：`11-27-admin-plugin-packages`。决定编号 D1–D15、共同需求 R1–R7 见父任务 `prd.md`。
> 规划深度：本文件现在只定需求与验收；`design.md`、`implement.md` 在轮到本子任务、其依赖已落地时再写，届时重新走一次评审。

## Goal

在短剧文本流水线之上完成制作环节：为角色造型、场景、道具生成图片，为每个分镜生成视频，最后拼接导出成片。

## 依赖

依赖 `11-27-media-storage`、`11-27-ai-media-models`、`11-27-short-drama-plugin`。

## Requirements

对齐参考项目（D9）：

- P1 资产图：可为每个角色造型、场景、道具用其图片提示词生成图片，也可上传图片；可重新生成并在多张结果中选定一张。
- P2 造型一致性：同一角色的后续造型可以把已选定的造型图作为参考图生成。
- P3 可从关联的小说设定缩略图带入作为初始参考（D12）。
- P4 分镜视频：用该分镜的视频提示词，加上它引用的角色造型图、场景图、道具图作为参考，生成视频；生成前可看到将要使用的参考图。
- P5 同一分镜可多次生成，保留各次结果作为版本，可选定其中一个用于成片。
- P6 可批量为多条分镜生成视频；有整集的进度视图，能看到每条分镜的状态（未生成、生成中、完成、失败及原因）。
- P7 导出成片：勾选分镜（按顺序）拼接为一个视频文件，可预览和下载；可标记该集已完成。
- P8 图片与视频文件存入媒体存储，访问遵守作品的归属与协作权限；计入用量、受预算约束。
- P9 运行环境自带 FFmpeg；本机开发缺少 FFmpeg 时给出明确提示。
- P10 短剧的媒体随短剧数据一起处理：删除分镜版本即删文件；作品彻底删除即清空；插件停用时不可访问但保留（D5）。

## Acceptance Criteria

- [ ] 为一个角色造型生成图片并选定；为第二套造型以第一套为参考生成，结果存入媒体存储并显示缩略图。
- [ ] 上传一张场景图代替生成。
- [ ] 对一条引用了角色与场景的分镜生成视频，生成前界面列出将使用的参考图；完成后可在页面内播放。
- [ ] 对同一分镜再次生成，得到第二个版本；切换选定版本后，成片使用新选定的版本。
- [ ] 批量生成五条分镜，进度视图逐条更新；其中一条失败时显示原因，其余不受影响，可单独重试。
- [ ] 勾选分镜导出成片，得到按顺序拼接的视频文件，时长约等于各分镜之和，可下载。
- [ ] 查看者可以播放不可生成；生成调用出现在 AI 用量页；超出预算被拒绝。
- [ ] 容器镜像里可直接导出成片；本机无 FFmpeg 时导出给出明确提示。
- [ ] 删除一个视频版本后对应文件不再存在；插件停用后媒体地址不可访问，重新启用后恢复。

## 已核实的现状（代码证据，详见 `11-27-short-drama-plugin/research/reference-drama-pipeline.md` 2.3–2.5、5.3–5.5 与 `11-27-short-drama-plugin/research/reference-media-infra-and-gap.md` A.1、A.2、A.5）

- 参考项目在资产步骤为角色（多套造型）、场景、道具生图或上传；造型一致性依赖参考图。
- 分镜视频用「多张参考图 + 提示词」直出，不经首帧图；分镜版本由已完成的视频任务推导，参考图按绑定实时计算。
- 短剧线的 FFmpeg 只做拼接转码、时长探测和抽海报帧（字幕、混音、转场属于它的其他模块）。
- aiNovel 镜像里没有 FFmpeg（`Dockerfile:18`）。

## Out of Scope

- 字幕、配音、配乐、转场。
- 参考项目的视频技巧目录与 Seedance 素材库绑定（它的 Go 版独有功能）。

## 进入本子任务规划时需再确认

- 单次批量生成的分镜数量上限与并发数。
- 成片的分辨率、编码与是否统一转码。
- 视频版本保留多少个。
