# 项目备份与导出（P1-10 project-io-reader）

## Goal

对应差距清单 D3、D4，补齐以下能力：

- 项目可以完整备份为 JSON，再导入成新项目，用于迁移或恢复；
- 导出 EPUB。

阅读器、书架、暗色主题、移动端已拆到子任务 `reader-ui`（P1-10b），见"范围外"。

## 已确认事实（代码核查，2026-10-27）

- 导出：`GET /projects/{id}/export` 目前支持 TXT 和 MD，可以选章节（`export_service`）。已有的 JSON 局部格式有：
  - 角色和组织卡片 `ainovel.cards`
  - 大纲 `ainovel.outline`
  - 写作风格 `ainovel.styles`
  - 提示词模板 `ainovel.prompts`
- 数据库共有 36 张表。与项目相关的实体包括：
  - 世界观、角色、组织与成员、关系类型、关系及其历史、出场角色；
  - 职业、职业阶段、角色职业、职业历史；
  - 大纲、章节、细纲、大纲快照、章节版本、生成记录；
  - 章节分析与变更、伏笔及其角色和历史；
  - 项目默认风格（引用风格库）；
  - 灵感会话；
  - 知识库设置、文档和分块，剧情记忆，检索单元；
  - 后台任务。
- 前端主题在 `App.tsx` 里写死，只设置了一个主色，没有暗色模式。代码里没有任何响应式判断（`innerWidth` 和 `useBreakpoint` 都出现 0 次），项目列表是普通卡片。
- MuMu 的 JSON 备份按名称关联实体，同名就会冲突；只能新建项目；多个项目导出时会连续触发多次下载。它没有 EPUB。它的阅读器支持主题、字号和翻页，并带分析标注。暗色主题有 light、dark、system 三种模式。移动端只靠 `innerWidth ≤ 768` 判断，并且不监听窗口大小变化。

## 需求草案

1. **项目 JSON 备份与导入**：
   - 使用带版本号的 `ainovel.project` 格式；
   - 实体之间用导出时的内部 id 关联，导入时重新映射，不按名称匹配；
   - 导入前预览统计数据和警告，导入结果总是新建一个项目；
   - 包含的数据（Q2 已定）：
     - **核心数据，始终包含**：项目字段与向导进度、世界观、角色、组织与成员、自定义关系类型、关系及历史、职业与阶段及历史、大纲、细纲、章节与出场角色、伏笔及历史、章节分析与变更、剧情记忆（含钉住和屏蔽标记）、知识库设置与文档解析出的文本。
     - **可选数据**：章节版本（默认勾选）、大纲快照、生成记录、关联的灵感会话（后三项默认不勾）。
     - **不导出**：后台任务、知识库分块、检索单元和向量。导入后重新分块，并排队建立索引。
   - 风格引用：
     - 预设风格按 preset_key 对应；
     - 自定义风格随备份一起导出，导入时复制到导入者的风格库；导入者已有同名且内容相同的风格时直接复用。
   - 导入始终新建项目，重名时在书名后加「（导入）」；文件上限 100MB。
2. **EPUB 导出**（Q3 已定）：
   - 生成 EPUB 3，同时附带 NCX，兼容旧阅读器。用标准库 zipfile 生成，不引入新依赖。
   - 包含文字扉页：书名、作者、类型标签、简介。暂不做封面图，等封面任务完成后再接入。
   - 有分卷时加卷标题页，目录按卷嵌套。
   - 正文首行缩进 2 字，行距 1.6。
   - 作者名默认取用户名，导出时可以修改。
   - 章节选择方式与 TXT 导出一致；可以选择是否包含简介页。

## 范围外

- 阅读器、书架、暗色主题、移动端：拆到子任务 `reader-ui`（P1-10b），紧接着做。

## Acceptance Criteria

- [ ] 导出备份后再导入为新项目，备份中的所有实体数量和内容都一致，相互引用正确（包括同名角色、同名章节），可选项按勾选情况包含或不包含。
- [ ] 导入后知识库文档重新分块，剧情记忆保留钉住和屏蔽标记，并自动排队建立索引；索引完成前可以用关键词检索。
- [ ] 风格引用：预设按 preset_key 对应；自定义风格复制到导入者的风格库，同名且内容相同时复用，不重复创建。
- [ ] 跨用户：只能导出自己的项目；导入的项目归属当前用户。
- [ ] 导入前预览能列出统计数据、版本兼容情况和警告；不合法的文件返回 400 并说明原因；有大小上限。
- [ ] EPUB 结构合规：mimetype 是第一个条目且不压缩；container.xml、OPF（manifest、spine、nav）和 NCX 齐全；所有 XHTML 都是格式良好的 XML。至少能在一款主流阅读器中打开。
- [ ] 有分卷时，目录按「卷 → 章」嵌套，并带卷标题页；扉页显示书名、作者、类型标签，按选项显示简介；作者名可以修改；可以只导出选中的章节。
