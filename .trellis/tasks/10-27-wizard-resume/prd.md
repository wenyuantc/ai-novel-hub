# 向导失败后从中断处继续

## Goal

向导生成（世界观/职业/角色/大纲）是一次性流式 JSON 输出，大纲规模大时容易因上游中断（如 `Upstream HTTP/2 stream failed`）或 max_tokens 截断而失败，目前只能「重新生成」从零开始。需要基于失败任务已保存的部分输出续写。

## Requirements

- 失败 / 中断 / 取消且已有部分输出的向导任务，可「从中断处继续」：新任务以旧任务部分输出为前缀，让模型续写剩余 JSON，拼接后统一解析落库。
- 续写沿用旧任务的生成参数（卷数、每卷章数、模式、数量、补充指令），仅允许换 AI 配置。
- 续写任务再次失败时，其输出为完整累积文本，可再次继续（链式）。
- 校验：旧任务须属于当前用户、同项目同 kind、状态为 failed/interrupted/cancelled、输出非空；否则 400。
- 前端：重新打开向导页时，若同 kind 最近一次任务失败且有输出，恢复显示错误与部分输出；显示「从中断处继续」按钮，「重新生成」保留。

## Acceptance Criteria

- [ ] `POST /projects/{id}/wizard/{kind}` 支持 `continue_from_task_id`，非法引用返回 400。
- [ ] 续写拼接（截断到完整对象、去围栏、去重叠、补逗号）后大纲可成功解析落库。
- [ ] 新任务 `retry_of_id` 指向旧任务。
- [ ] 刷新页面后失败任务与「从中断处继续」按钮仍可见。
- [ ] 后端 pytest / ruff / mypy、前端 lint / 类型检查通过。
