# 本机 MCP 作者页面验收

2026-11-26，macOS Chrome 无头模式。验证对象为现有 MCP 管理页内的「服务器插件列表」、个人卡片和工具详情。

## 生产前端、真实后端与子进程

375 × 812 窗口加载 Vite 生产构建，由 FastAPI 同源提供页面。独立 SQLite 数据库从空库迁移至 0079，服务器清单登记仓库自带的字符统计程序，版本为 1.0。

| 作者操作 | 实际结果 |
| --- | --- |
| 注册普通用户，打开目录 | 显示「稿件字符统计 · 1.0」，作者可选择启用。 |
| 启用后关闭目录 | 个人卡片显示目录项 stats 和版本 1.0。启用请求携带页面所见版本，无命令请求体。 |
| 卡片测试连接、打开工具抽屉 | 真正的 stdio 插件返回 count_characters 工具。 |
| 输入「星 海 A」调用 | 接口成功，抽屉显示纯文本结果 3。 |
| 停用并重新加载页面 | 开关保持关闭，本机测试按钮禁用。浏览器未捕获页面异常。 |

## 桌面、窄屏与边界状态

使用可控接口在真实 Chrome 的 1280 × 850 和 375 × 850 两种视口验证：可用和缺失程序的目录项分别显示「启用」和「节点不可用」；添加后按钮更新为「已添加」，个人卡片隐藏远程编辑入口。启用、刷新和试用为三个独立请求。目录版本从 1.3 更新至 2.0 后，作者点击「更新工具」，刷新请求带新版本且个人卡片同步显示 2.0。混合 JSON 导入显示本机项的列表启用提示，后端仅收到远程条目。两个视口均未捕获页面异常。
