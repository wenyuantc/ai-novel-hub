# 提示词自定义输入表单

父任务：`11-08-prompt-components-inputs`（决策 D1、D6 的来源与现状证据见父任务 `prd.md`）。

## Goal

作者为自己的 Skill 定义输入项；在任何手动选用 Skill 的入口，选中后填写表单并预览填入后的 Skill 正文；智能体自行使用 Skill 时由它根据对话代填。

## Requirements

- **R1 输入项定义**：Skill 可声明最多 20 个输入项。每项：标识（作者可见的变量名，Skill 内唯一）、显示名、说明（可选）、类型（单行文本／多行文本／单选下拉）、是否必填、默认值、下拉选项（仅下拉，2–50 项，默认值须是选项之一）。全局 Skill 也可声明输入项。
- **R2 正文占位**：Skill 正文写 `{{ 标识 }}` 引用输入值。只有已声明的标识会被替换，其余花括号文本原样保留（已有 Skill 不受影响）。正文里有形如占位但未声明的写法、或声明了却从未引用 → 编辑时给出警告，不阻止保存（旧正文里本就可能有 `{{...}}` 文本）。组件（`11-08-prompt-components`）先展开，组件内容中的占位同样生效。
- **R3 表单（D6）**：以下六个入口选中带输入项的 Skill 后，在 Skill 选择下方展示表单并以默认值预填：章节生成／续写、改写、批量生成（整批共用一份）、场景 AI、区块改写、智能体对话中手动指定 Skill。必填项为空时不能提交。切换 Skill 时清空上一个 Skill 的填写内容。
- **R4 预览**：表单旁提供预览，显示填入当前值、展开组件后的 Skill 正文（即实际注入的补充工作流）。预览不落库。
- **R5 服务端校验与快照**：请求在 `skill_id` 之外携带 `skill_inputs`；服务端按 Skill 当前定义校验（必填、下拉值合法、长度上限、未知标识拒绝），缺省项用默认值，然后把渲染后的正文作为快照。重试、续跑、批量逐章都沿用同一快照，之后编辑 Skill 不影响。生成记录记下所用输入值。
- **R6 智能体代填（D6）**：
  - 智能体 `load_skill` 返回输入项定义（标识、显示名、类型、必填、默认值、选项）与未填值的正文，指示它按对话内容填写，必填项无法确定时向作者追问。
  - 用触发词（如 `/去ai味 ...`）强制启用带输入项的 Skill 时，同样附上输入项定义，由智能体代填。
  - 智能体启动生成任务（`start_task` 带 `skill_id`）时可传 `skill_inputs`，按 R5 校验；缺必填项返回工具错误，智能体据此追问。
- **R7 导入导出**：SKILL.md frontmatter 增加 `inputs` 列表，导出再导入后输入项定义一致；导入时对 `inputs` 做与 R1 相同的严格校验（只接受标量字段）。

## Acceptance Criteria

- [ ] 为 Skill 定义「基调」（下拉：轻松／沉重，默认轻松）和「重点人物」（单行，必填）；在章节生成入口选中它后出现表单，默认值预填，必填为空不能提交。
- [ ] 预览显示填入后的正文；提交后实际发送的补充工作流与预览一致。
- [ ] 六个手动入口都能填写并生效；批量生成只填一次，每章都使用同一组值。
- [ ] 绕过前端提交非法下拉值、未知标识、缺必填项：400。
- [ ] 任务创建后修改 Skill 输入项或正文，重试仍使用原值与原正文。
- [ ] 智能体 `load_skill` 能看到输入项定义；用触发词启用时智能体代填；`start_task` 缺必填项返回工具错误。
- [ ] SKILL.md 导出／导入往返保留输入项；非法 `inputs`（非标量、超量、下拉默认值不在选项中）导入被拒绝。
- [ ] 没有输入项的 Skill 行为与改动前一致，正文中已有的 `{{...}}` 文本原样保留。

## Out of Scope

- 系统模板覆盖声明输入项（D1）。
- 数字、复选、多选、日期等其他输入类型；输入项之间的条件显示。
- 在表单中预览包含参考资料、设定等完整上下文的最终提示词（现有模板预览保持不变）。
- 记住上次填写的值。
