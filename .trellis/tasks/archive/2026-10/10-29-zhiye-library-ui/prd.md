# 知页官网、认证页面、布局外壳与作品书库 UI

## 目标
将知页「纸上书房」视觉落到现有平台的公开官网首页、公共布局与 `/projects` 书库，让访客了解产品，让用户查看真实作品、继续写作并访问已有创作工具。

## 已确认事实
- 只读设计目录：`/Users/wenyuantc/.vetta/workspace/AI小说平台/zhiye-novel-full.vetd`。
- 视觉来源：DESIGN.md、theme.css、components/Shell.tsx、components/UI.tsx、frames/_layout.tsx、frames/library.tsx（引用 CoreScreens.tsx::Library）及补充的 frames/index.tsx 与官网整页截图。
- 项目为 Vite 8、React 18、Ant Design 5、React Router 6、Zustand 5；无 Tailwind。
- 现有项目接口提供状态、字数、章节数、最近编辑章节 id、版本化封面；账号/主题/后台任务有真实 store。
- 用户在本会话已同意按 Trellis 流程实现；原始范围为公共外壳与书库，后续补齐公开官网、首页认证入口与完整登录注册页；最终明确要求「提交归档」。

## 需求
- R1：迁移颜色、字体、圆角 token，本地安装 Fraunces/Geist，保留浅色/深色/跟随系统及偏好持久化。
- R2：实现米白纸面、216px 浅色侧栏、品牌、分组导航、56px 顶栏、账号及主题入口；所有入口映射现有路由、权限及 MCP 开关，任务数来自真实状态。
- R3：书库提供标题和真实统计、继续写作区、状态筛选、搜索、书架/列表切换、桌面四列卡片、书脊纸页效果、底部辅助入口。
- R4：只使用真实 API 数据。最近章节标题可按已有章节接口读取，无最近写作时不造章节；无封面展示文字装帧，不用示例素材冒充真实作品封面。
- R5：保留原有新建、灵感立项、拆书导入、备份恢复、阅读、导出、备份、删除、排序；新建复用已有表单/API。
- R6：完整的加载/错误重试/空数据/无匹配状态，移动菜单、响应式排列、键盘可达和焦点样式。
- R7：运行应用做真实接口与浏览器检查，对照参考设计并交付差异说明。
- R8：首页按 `frames/index.tsx` 及1440×2400截图实现；`/` 公开可访问，包含品牌导航、首屏书本/稿纸插画、创作能力切换、三步流程、创作方向示例、FAQ与页脚。访客不能读取私有项目；不使用 `HomeWorks.initialWorks` 假作品/账号/统计。功能示意文案与装帧须明确是示意，不能冒充真实用户作品或AI结果。
