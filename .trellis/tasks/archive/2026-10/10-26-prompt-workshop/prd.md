# 实例内提示词工坊（P2-14 prompt-workshop）

## Goal

在同一个部署实例内共享写作风格和提示词模板：用户提交，管理员审核，其他用户浏览后导入到自己名下。对应差距清单 C2（父任务 `10-23-mumu-parity`），用户决定从 prompt-styles 拆出。MuMu 的工坊依赖作者的中央云端、身份靠请求头可伪造、只能分享风格；本任务只在本实例内运行，身份走本实例登录，风格和模板都能分享。

## Background（代码证据）

- 依赖 prompt-styles（已归档）。写作风格 `WritingStyle`（`backend/app/models/entities.py:760`）是独立的行，`user_id` 为空是内置预设；字段见 `STYLE_FIELDS`（`backend/app/models/style_presets.py`）；导入同名加「（导入）」（`style_service.py:66`、`:276`）。

- 全局资源的权限先例：Skill 不可见返回 404，可见但不可写返回 403（`.trellis/spec/backend/skills-mcp.md`）。

## Key Decisions（用户 2026-10-28 确认）

- **D1 模板共享单位**：按单个模板 key 共享，不做模板包。导入时覆盖用户对该 key 的现有覆盖，旧内容必须能从版本历史恢复；导入本身也记一个版本，备注标明来自工坊。导入的模板要按当前系统模板重新校验；系统里已不存在的 key 不能导入。
- **D2 条目生命周期**：作者可以对已上架条目提交更新，更新要重新审核；审核通过前旧版继续在架，通过后替换为新版，点赞、下载数保留。作者可以随时下架自己的条目。
- **D3 管理员权限**：管理员可以不经审核直接发布（标为官方）；审核时可以改分类和标签；可以下架或删除任何条目；不能改别人的正文，只能驳回并写明原因。
- **D4 署名与删号**：默认显示用户名，提交时可选匿名；匿名只对其他用户隐藏，管理员仍看得到真实作者。作者账号被删后，已上架条目保留，署名显示为「已注销用户」，点赞、下载数不变；审核中的提交一起删除。
- **D5 分类与计数**：分类用固定列表，标签由作者自由填写（限个数和长度）；点赞每人每条一次，可以取消；下载数按人计，同一个人导入多次只计一次。计数都用原子更新。
- **D6 入口**（随最终规划确认）：顶部导航新增「提示词工坊」页 `/workshop`，分「浏览」「我的分享」「审核」（仅管理员）三个 Tab；写作风格库和提示词模板页上各加「分享到工坊」入口。

## Requirements

- **R1 提交**：用户可以把自己的一条写作风格，或自己对某个模板 key 的内容提交到工坊，填写名称、说明、分类、标签，可选匿名。提交进入待审核。内置预设风格不能原样提交；与系统默认完全相同的模板不能提交；模板提交要通过保存时的同一套校验。
- **R2 我的分享**：作者能看到自己的全部提交（待审核、已通过、已驳回及驳回原因）和自己的条目；可以撤回待审核的提交；可以对自己的条目提交更新（同一条目同时最多一份待审核更新）；可以下架自己的条目，也可以重新上架自己下架的条目（管理员下架的不行）。
- **R3 审核**：管理员看到待审核列表，可以通过（可同时改分类、标签）或驳回（必须填原因）。新条目通过后上架；更新通过后替换条目内容，计数保留。管理员自己的提交和更新直接通过，条目标为官方。
- **R4 管理**：管理员可以修改任何条目的分类和标签、下架、重新上架、删除；不能修改别人的正文。
- **R5 浏览**：所有登录用户能浏览已上架条目，可按类型（风格 / 模板）、分类、标签、模板 key、关键词筛选，可按最新、点赞数、下载数排序，分页。详情展示完整内容、署名、是否官方、点赞数、下载数，以及我是否已赞、已导入。
- **R6 导入**：风格导入为自己名下的新风格，同名按现有规则加后缀。模板导入前展示与我当前生效内容的差异，确认后覆盖并启用；旧内容能从版本历史恢复。首次导入时下载数加一。
- **R7 点赞**：点赞和取消点赞都是幂等的，计数与点赞记录一致。
- **R8 署名**：按 D4 展示；作者删号后条目保留，署名为「已注销用户」。
- **R9 权限与安全**：身份只来自本实例登录；别人的待审核或已驳回提交、他人下架的条目，对非管理员一律 404；普通用户调用管理员接口返回 403。提交内容有大小与条数上限。工坊不进项目备份。

## Acceptance Criteria

- [x] 用户 A 提交一条风格和一条模板，管理员通过后，用户 B 能在浏览页看到并按类型、分类、标签、关键词筛出它们。
- [x] 内置预设风格、与系统默认相同的模板、校验失败的模板（含锁定变量缺失）提交时被拒绝并给出原因。
- [x] 用户 B 导入风格后在自己的风格库看到新风格；重复导入生成新副本，但下载数只增加一次。
- [x] 用户 B 已覆盖某个 key，导入该 key 的模板前能看到差异；导入后覆盖生效并启用，从版本历史能恢复导入前的内容。
- [x] 系统模板升级导致共享内容不再通过校验时，导入返回 400 和校验错误，不改动用户覆盖。
- [x] 作者提交更新后，审核期间浏览页仍是旧版；通过后变成新版，点赞、下载数不变；驳回后旧版不变，作者看到驳回原因。
- [x] 同一条目已有待审核更新时，再次提交更新被拒绝。
- [x] 作者下架后条目从浏览页消失，作者可以重新上架；管理员下架的条目作者不能重新上架。
- [x] 管理员直接发布的条目无需审核、标为官方；管理员审核时能改分类、标签，但没有修改别人正文的接口。
- [x] 匿名条目对其他用户不显示作者，管理员能看到真实作者；作者删号后条目仍在架，署名为「已注销用户」，计数不变，其待审核提交被删除。
- [x] 点赞、取消点赞重复调用结果一致；并发点赞后计数与点赞记录数一致。
- [x] 非管理员调用审核、管理接口返回 403；读取他人未上架的提交或条目返回 404。
- [x] `cd backend && uv run ruff check . && uv run pytest` 通过；`cd frontend && npm run lint && npm run build && npm test` 通过。

## Out of Scope

- 跨实例、中央云端分享（C2 中不做的部分）。
- 模板包（多个 key 打包分享，D1 已排除）。
- 分享 Skill、MCP 插件。
- 评论、收藏、举报、站内通知；MuMu 管理端的统计卡（只在「审核」Tab 上显示待审核数）。
- 用户删号后回退其点赞、下载计数。
