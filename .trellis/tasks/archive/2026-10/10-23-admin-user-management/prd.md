# 管理员功能

## Goal

为 AI 小说平台增加管理员角色与用户管理能力：部署方通过环境变量获得首个管理员，管理员在界面上创建用户、查看用户、重置密码、禁用/启用、设为/取消管理员、删除用户；普通用户可自助修改密码。不再需要直接改数据库来处理账号问题。

## Background

- 现状无任何管理员或预置账号；`users` 表仅 `id / username / password_hash / created_at / updated_at`（`backend/app/models/entities.py:20-22`）；迁移仅 `0001_initial_schema`。
- 每次请求按 JWT 中的 user_id 从库中重新加载用户（`backend/app/core/deps.py` `get_current_user`），禁用检查放在此处即可即时生效。
- JWT 无状态（payload 仅 `sub/iat/exp`，`backend/app/core/security.py:24-35`），默认有效期 7 天；不引入失效机制的话，重置密码/禁用后旧令牌在过期前仍可用。
- 注册关闭时提示「注册已关闭，请联系管理员」（`backend/app/services/auth_service.py`），目前并不存在管理员。
- 业务数据全部按 user_id 隔离，外键 ON DELETE CASCADE，删除用户会连带删除其全部数据。

## Requirements

- R1 管理员引导：可选环境变量 `ADMIN_USERNAME` / `ADMIN_PASSWORD`（须同时设置，校验规则与注册一致）。服务启动时：账号不存在则创建为管理员；已存在则确保其为管理员且处于启用状态，**不覆盖密码**。注册是否开放不影响引导。
- R2 角色与状态：用户新增「是否管理员」「是否启用」两种属性；`/auth/me` 返回 `is_admin`，前端据此显示管理入口。
- R3 用户列表：管理员可分页查看全部用户，按用户名搜索；列出用户名、角色、状态、注册时间、项目数。管理员**不能**查看他人的小说内容。
- R4 重置密码：管理员为指定用户设置新密码；该用户所有已登录会话立即失效。
- R5 禁用/启用：被禁用用户的已登录会话立即失效，且无法再登录（提示「账号已被禁用，请联系管理员」）；启用后可正常登录。
- R6 设为/取消管理员：管理员可提升或撤销其他用户的管理员身份。
- R7 删除用户：永久删除用户及其全部项目、章节、AI 配置；界面要求输入用户名二次确认。
- R8 安全护栏：管理员不能对自己执行禁用、取消管理员、删除；任何操作都不能使系统失去最后一个启用中的管理员。
- R9 自助改密：已登录用户输入旧密码与新密码修改密码；成功后其他会话失效，当前会话保持登录。
- R10 权限：所有管理接口仅管理员可调用，普通用户调用返回 403。
- R11 创建用户：管理员输入用户名与初始密码（规则与注册一致），可勾选「设为管理员」；新用户默认启用。不受 `REGISTRATION_ENABLED` 影响，因此关闭注册后仍可由管理员开通账号。用户名重复时提示「用户名已存在」。

## Acceptance Criteria

- [ ] 设置 `ADMIN_USERNAME`/`ADMIN_PASSWORD` 后启动，可用该账号登录并看到「用户管理」入口；重启不会改动其密码（R1, R2）
- [ ] 普通用户看不到管理入口，直接调用管理接口返回 403（R2, R10）
- [ ] 管理员能分页、按用户名搜索用户，并看到每人的项目数（R3）
- [ ] 重置某用户密码后，该用户原会话的下一次请求返回 401，用新密码可登录、旧密码不可（R4）
- [ ] 禁用某用户后，其会话立即失效且登录提示已禁用；启用后可登录（R5）
- [ ] 可把普通用户设为管理员，对方重新加载后看到管理入口；可再取消（R6）
- [ ] 在 `REGISTRATION_ENABLED=false` 下，管理员创建的用户可用初始密码登录；勾选「设为管理员」的新用户能看到管理入口；重复用户名被拒（R11）
- [ ] 删除用户需输入用户名确认，删除后其项目等数据从库中消失（R7）
- [ ] 对自己禁用/降级/删除，以及移除最后一个启用中的管理员，均被拒绝并给出中文提示（R8）
- [ ] 用户自助改密：旧密码错误被拒；成功后当前页面仍处于登录状态，其他浏览器的会话失效（R9）
- [ ] 后端 ruff + pytest、前端 lint + build + test 全部通过；迁移可 upgrade / downgrade

## Out of Scope

运行时切换注册开关、管理员查看他人小说内容、操作审计日志、邮件找回密码、首次登录强制改密、批量操作。

## Key Decisions

- 功能范围：用户列表、重置密码、禁用/启用、设为/取消管理员、删除用户、用户自助改密（用户确认，2026-10-23）；追加管理员手动创建用户（用户确认，2026-10-23）。
- 首个管理员通过环境变量引导，已存在时不覆盖密码（用户确认，2026-10-23）。
- 重置密码由管理员直接输入新密码（不由系统生成临时密码，不强制首次登录改密）（用户确认开始实施，2026-10-23）。
- 会话失效采用令牌版本号：重置密码、禁用、自助改密时递增，旧令牌立即作废（用户确认开始实施，2026-10-23）。

## Constraints

- 迁移须兼容已有数据：现有用户默认为启用的普通用户；升级前已签发的令牌继续有效。
