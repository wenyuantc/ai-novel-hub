# API Key 管理与小说开放接口

## 目标与用户价值

用户可生成和管理平台访问 API Key，交给第三方读取已授权的小说及创作设定。调用方可直接从 OpenAPI 文档了解并调试接口，无须复用网页登录凭据。

## 背景与需求来源

- 用户最初要求增加 API Key 生成配置，开放小说信息和章节读取，并评估所需的其他接口；已同意创建 Trellis 任务并进入规划。
- 用户随后明确：密钥创建后仍可点击图标显示并复制，加入人物、大纲、世界观、组织和关系读取，并提供 OpenAPI 文档。
- 小说对应现有 `Project`；当前系统已有这些领域的内部读取和导出能力，但认证只有 Cookie / Bearer JWT，没有平台签发的 API Key。
- 本需求管理的平台 Key 与模型供应商的 AI 配置凭据分别管理。代码证据见 `research/current-inventory.md`、`research/read-contracts.md`、`research/key-auth-docs.md`。

## 范围与要求

### R1 密钥管理

- 新增全局 API Key 管理入口，可创建多把 Key、命名、编辑授权范围和有效期、查看状态及最近调用时间、撤销。
- 授权范围可选择“全部自己的小说”（包含未来新增小说）或“指定小说”。创建默认指定小说；必须明确选择小说或切换全部授权。
- 有效期可选择 30 / 90 / 180 天、指定时间或不过期；创建默认 90 天。
- 默认只显示掩码。所有者可主动点击图标显示 / 隐藏完整 Key，并通过独立按钮复制；隐藏状态也能发起复制。刷新页面之后仍可再次查看和复制。
- 查看或复制只对所有者开放；管理员没有额外的查看他人 Key 权限。完整 Key 不出现在默认列表响应、日志、URL 或浏览器持久存储。
- 过期但未撤销的 Key 可查看和调整有效期；撤销永久失效且不能再次查看或启用。需要轮换时创建新 Key 再撤销旧 Key。

### R2 独立鉴权与小说隔离

- 第三方使用 `X-API-Key` 认证，Key 只能访问明确开放的读取接口。
- Key 无效、过期、撤销或所属账号被禁用 / 删除时拒绝访问。Key 不因网页登录登出、改密或重置密码自动失效。
- 每次读取同时校验 Key 的小说授权范围、小说所有权及子资源归属；他人和未授权资源统一返回 404。
- 开放请求提供每 Key 的基础限流，默认每分钟 120 次，可通过部署配置调整；超额返回 429 和重试等待时间。现有网页业务不受该额度影响。

### R3 小说与章节读取

- 小说列表与搜索、详情；含简介、类型、标签、状态、字数和章节数等领域信息。
- 章节目录、分卷信息和单章正文；目录不包含正文，按小说章节顺序返回，包含空章与当前章节状态。
- 小说封面与 TXT / Markdown / EPUB 全文下载。
- 当前 Key 的信息与授权范围读取，供调用方验证接入；不返回完整 Key 或账户管理数据。

### R4 创作设定读取

- 人物列表与详情、世界观列表与详情。
- 大纲列表与详情，包含分卷信息；支持读取大纲下的章节细纲。
- 组织列表与详情、组织成员列表。
- 人物关系列表与详情、关系类型列表；关系类型仅含全局预置及当前小说自定义类型。
- 保留现有业务排序、组织成员状态和人物关系视角语义；返回当前保存状态，不按阅读章数恢复历史设定。

### R5 一致的调用契约

- 列表统一分页，默认每页 20 条、最多 100 条；文档说明筛选条件和排序。
- 章节支持按行更新时间筛选；时间带 UTC 时区，不承诺覆盖删除与派生字段变动的完整增量同步。
- 错误返回中文 detail，身份验证、资源不存在、参数错误和限流使用正确 HTTP 状态。
- 原有网页登录、内部接口、备份和导出功能保持兼容，项目备份不携带平台 Key 或其授权信息。

### R6 OpenAPI 文档

- 提供独立、完整的 OpenAPI JSON 描述和 Swagger UI 文档；只列出开放读取接口。
- 文档包含鉴权、请求参数、分页、响应字段、错误状态、下载类型及 curl 示例；支持填写 Key 在线调试和下载描述文件。
- 管理页可直接进入文档和下载 OpenAPI JSON；文档本身可无 Key 查看，业务调试始终校验 Key。
- 文档不自动填入或持久化真实 Key，明确当前设定可能含后续剧情、更新时间筛选及空章节导出的边界。

### R7 面向客户的公开开发文档

- 用户于 2026-10-30 追加要求：首页顶部常见问题之后增加“开发文档”，位置按所附截图标记，与首页 UI 风格保持一致。
- 提供无需登录即可阅读的独立开发文档页；内容面向第三方接入客户，包括快速开始、密钥获取与鉴权、只读接口目录、分页与筛选、响应示例、错误与限流、封面及导出注意事项。
- 延续首页的品牌、纸面背景、墨绿色、衬线标题和布局节奏，支持移动端和明暗主题；包含章节目录、返回首页、管理密钥、Swagger 调试与 OpenAPI JSON 下载入口。
- 文档只展示说明与占位符，不读取或展示用户密钥、作品数据；接口路径、字段、默认值和限制必须与现有实际实现一致。

## 不在首版范围

- 对外写入或删除小说、章节和设定，触发 AI 生成，开放后台任务或管理员接口。
- 知识库、剧情记忆、伏笔、职业体系、提示词、Skill、MCP 配置、章节历史版本及完整项目备份读取。
- 公开发布 / 匿名阅读、按章节回溯设定、webhook、删除事件流及完整增量同步。
- 密钥收费计量、OAuth 授权流程、独立 SDK 和新增 Redis 基础设施。

## 约束与风险

- 支持再次查看完整 Key 需要可恢复的加密保存，依赖部署加密密钥稳定；若丢失，用户需撤销并重建。
- 创作设定读取可能包含后续剧情；授权界面与文档应提示调用方按需使用。
- 请求额度是分钟固定窗口，窗口切换时可能突发；它不是完整 API 网关或流量防护系统。
