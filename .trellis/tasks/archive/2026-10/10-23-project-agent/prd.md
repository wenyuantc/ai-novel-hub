# 项目智能体（P2-11 project-agent）

## Goal

在项目内提供一个对话式助手：用户用自然语言提问或下指令，例如"把林远的性格改成更冷静""给第 3 卷再补两章大纲""检查一下伏笔有没有忘记回收的"。助手通过工具读取项目数据，写操作先给出修改预览，经用户确认后执行，执行后可以撤销。对应差距清单 C4。

相比 MuMu 的改进：
- 使用三家模型原生的工具调用协议（OpenAI tools、Anthropic tool_use、Gemini functionCall），不再每轮把历史重新拼成文本。
- 写操作执行后可以撤销，并做冲突检测。
- 批准模式保存在服务端。
- 工具结果按不可信数据隔离。

## 已确认的可复用能力

- 实体服务：角色、组织、关系、职业、世界观、大纲、细纲、章节、伏笔、写作风格、知识库与记忆，各自有完整的增删改和校验。
- 版本体系：章节版本、大纲快照。
- 任务引擎：可以由工具启动生成、批量、分析等后台任务。
- 上下文组装（`context_builder`）、提示词模板注册表（可覆盖）、生成记录。
- SSRF 防护和 Provider 抽象。Provider 目前没有工具调用能力，需要新增。

## Requirements（逐步确认中）

- R1 交互与写操作确认（已确认）
  - **入口**：项目页右侧有一个可折叠、可调宽的面板，手机上是抽屉。每个项目保存多个会话，存在服务端，可以跨设备继续。
  - **修改提案**：所有写操作都先生成修改提案，带逐字段的修改前后对比。可以逐条确认或拒绝，也可以一键全部确认或拒绝。
  - **确认时重新校验**：确认时重新生成预览，并与提案时的预览比较。数据已被改动时，刷新预览并要求重新确认，不按过期数据执行。
  - **自动执行**：用户可以开启"自动执行小修改"，设置保存在服务端。每轮首次写操作批次最多 3 项，且全部是小修改时可自动执行；同轮后续写操作继续等待确认。删除、批量修改和启动后台任务始终需要确认。
  - **撤销**：已执行的修改可以单条撤销，也可以撤销整轮。撤销前检查数据在执行后是否又被改动，有改动就提示冲突，不覆盖。
  - **当前页面**：请求附带当前页面的上下文（例如正在编辑的章节），模型可以直接引用。
- R2 工具调用技术方案（已确认）
  - **原生工具调用**：OpenAI 兼容、Anthropic、Gemini 三家 Provider 都实现原生的流式工具调用。模型不支持工具调用时，提示用户换模型，不做文本降级。
  - **运行方式**：对话作为后台任务运行，面板订阅流式输出，关闭页面不会中断。
  - **调用上限**：每轮最多调用 8 次工具，达到上限后要求模型直接作答。
  - **上下文预算**：
    - 历史按模型的上下文预算裁剪，较旧的对话自动压缩成摘要。
    - 单条工具结果有长度上限，超长时分页。
  - **防注入**：工具结果和项目数据都标记为不可信内容。项目由服务端绑定，模型不能指定其他项目。
  - **提示词**：系统提示词纳入提示词库，可以覆盖，但安全规则部分锁定。
  - **记录**：每轮都写生成记录和 token 用量。
- R3 工具清单、撤销与安全（已确认）
  - **读工具**：覆盖全部项目数据与检索，包括概览、各类设定、大纲与细纲、章节列表、章节正文（分页）、分析结果、伏笔状态、知识库检索、剧情记忆检索、写作风格、进行中的任务。
  - **写工具**：
    - 设定（角色、组织与成员、关系、职业与阶段及角色职业、世界观）、大纲与细纲、伏笔、项目字段，支持增删改。
    - 章节正文只做带原文校验的局部替换，替换后保存为版本，来源为 `agent`。
    - 生成类工作只能启动已有的后台任务（生成、重写、润色、批量、分析、大纲展开与续写、实体生成），不能由智能体直接写正文。
  - **不提供的工具**：删除项目、账号、AI 配置、导入导出、管理员相关操作，以及跨项目操作。
  - **确认后续跑**：有待确认的提案时，任务暂停；全部确认或拒绝后，同一轮继续执行，模型能拿到执行结果（例如新建角色的 id）。
  - **撤销**：按修改前后的快照恢复。
    - 删除操作连同关联数据一起恢复。
    - 章节正文按版本恢复。
    - 已启动的任务只能取消，不能撤销。
  - **批量上限**：单次批量最多 50 项，即一轮里的写提案不超过 50 条，超出部分拒绝执行，并提示模型分批处理。

## Acceptance Criteria

- [ ] OpenAI 兼容、Anthropic、Gemini 三家都能流式工具调用：文本增量、多个工具调用、工具结果回传、token 用量。不支持工具调用时给出明确提示。
- [ ] 对话作为后台任务运行：关闭页面不中断，重新打开能看到完整过程；取消、重启中断、重试都符合任务引擎的约定。
- [ ] 每轮最多 8 次工具调用；历史超出预算时压缩成摘要；工具结果超长时分页。
- [ ] 系统提示词出现在提示词库中，可以覆盖；锁定的安全规则无法被删改；工具结果和项目数据带"不可信"标记。
- [ ] 读工具只能读当前项目。即使模型传入其他项目或其他用户的 id，也返回"不存在"。
- [ ] 写提案带逐字段对比；可以单条或全部确认、拒绝；确认时数据已变则返回 409 并刷新预览。
- [ ] 打开"自动执行小修改"后，首次写操作批次不超过 3 项且全部为小修改时直接执行；该批次超过 3 项或包含删除、启动任务时，整批等待确认；同轮后续写操作始终需要确认。
- [ ] 确认或拒绝完所有提案后，同一轮继续执行，模型能拿到执行结果（例如新建角色的 id）。
- [ ] 撤销：
  - 单条撤销和整轮撤销都正确恢复；
  - 删除操作连同级联删除的关联数据一起恢复，id 不变；
  - 数据在执行后被改动时提示冲突，不覆盖；
  - 章节正文的局部替换按版本撤销。
- [ ] 局部替换的原文与当前正文不一致时被拒绝；成功时保存来源为 `agent` 的版本。
- [ ] 启动的后台任务出现在任务面板中，可以取消。
- [ ] 一轮超过 50 条写提案时被拒绝，并提示模型分批。
- [ ] 每轮的生成记录和 token 用量可以查看。
- [ ] 前端：面板可折叠、可调宽，手机上为抽屉；会话列表；时间线显示文本、工具步骤和提案卡片；可以确认、拒绝、撤销；有自动执行开关；能附带当前页面信息。没有页面级横向溢出，不写死颜色，面板懒加载。
- [ ] 后端和前端的全量测试、lint 和构建都通过。

## Out of Scope（初拟）

- MCP 外部工具与 Skill：由 P2-12 skills-mcp 接入本任务的工具层。
- 跨项目操作。
- 语音输入。
