# 阅读器与界面体验（P1-10b reader-ui）

## Goal

本任务提供章节阅读器、书架式的项目列表、全站暗色主题，并完成移动端适配，对应差距清单 D5、A18。它是用户决定从 project-io-reader 拆出来的部分，接在其后完成。

## 已确认事实（代码核查，2026-10-27）

- **主题**：`App.tsx` 中的 `ConfigProvider` 只设置了 `colorPrimary` 和 zhCN 语言包，没有暗色模式。代码里有 60 处写死的颜色值，分布在约 20 个文件中。最集中的几处是伏笔时间线（10 处）、分析历史（7 处）、TextDiff（6 处）、关系图配色（`graphFilter`，5 处）和关系图（3 处）。全局样式只有一个 `index.css`。
- **布局**：
  - `AppLayout` 是顶栏加内容区；
  - `ProjectLayout` 使用 antd `Sider`，`breakpoint="lg"` 时折叠为 56px 宽的图标栏，边框颜色写死；
  - 全站没有任何响应式判断；
  - 一共有 32 个 `<Table>`。
- **项目列表**：`ProjectListPage`（208 行）是普通卡片，没有搜索和排序，也没有封面。灵感模式入口和导入备份按钮已经放在这一页。
- **阅读器**：没有，只有编辑器 `ChapterEditorPage`（882 行）。
- **可复用的数据**：
  - 项目已有字数统计、目标总字数和类型标签；
  - 章节有分析数据，包括摘要、情节点、钩子和伏笔；
  - 导出、备份的弹窗都已实现，并且是懒加载。
- **MuMu 的做法**（调研 §5.5、§8、§9）：
  - 书架是书本样式的卡片，带书脊和书签，封面可以翻面；
  - 暗色主题分 light / dark / system 三档，用 View Transition 做过渡；
  - 移动端只在渲染时读一次 `innerWidth ≤ 768`，窗口缩放后不会更新；
  - 阅读器支持主题、字号、翻页，并带分析标注。

## 需求草案

1. **阅读器**（Q1 已定）：
   - 独立的全屏路由 `/projects/:pid/read/:cid`，入口放在书架卡片、章节列表和编辑器里。
   - 章内滚动，章末提供"上一章 / 下一章"，左右方向键也能切章；有目录。
   - 设置项：字号、行距、版心宽度、背景（浅色 / 护眼 / 暗色 / 跟随全局）、字体（宋体 / 黑体）。设置存在 localStorage，所有项目共用。
   - 阅读进度（章节 + 章内位置）保存在服务端，换设备也能接着读。
   - 只显示已经写了正文的章节。
   - 正文里不做分析标注。可以打开侧边栏，查看本章的摘要、情节点、钩子和伏笔。
   - 可以一键跳到本章的编辑器。
2. **书架**（Q2 已定）：
   - 书本式卡片网格。封面为 2:3 的文字封面，按书名哈希取色，带书脊，显示书名和题材；以后有封面图时直接替换。
   - 卡片下方显示书名、状态、前 3 个类型标签、字数相对目标的进度条、章节数和更新时间。
   - 主按钮有两个：「继续写作」跳到最近编辑的章节；「阅读」显示"读到第 N 章"。"更多"菜单里放概览、导出、备份、删除。
   - 第一张固定为「新建」卡，提供新建项目、灵感模式、导入备份三个入口。
   - 顶部有搜索（匹配书名和标签）、排序（最近更新 / 创建时间 / 书名 / 字数）和状态筛选，选择结果记在 localStorage。
   - 顶部统计作品数、创作中的作品数和总字数。
   - 手机上每行两列。
3. **暗色主题**（Q3 已定）：
   - 使用 antd 的 darkAlgorithm，提供浅色 / 暗色 / 跟随系统三档。选择存在 localStorage，并监听系统主题变化；开关放在顶栏。
   - 把全部 60 处写死的颜色改为主题 token。关系图、时间线、差异对比在暗色下也要能看清。
   - 加一个测试，禁止新增写死的颜色（白名单除外）。
   - 不做切换过渡动画。
4. **移动端**（Q3 已定）：
   - 以 768px 为界，统一用 `useIsMobile` hook 判断，窗口缩放时实时更新。
   - 小屏下，顶栏菜单和项目侧栏都改为抽屉。
   - 以下页面完整适配：书架、概览、章节列表（小屏改为卡片列表）、编辑器（AI 面板收进抽屉）、阅读器、灵感会话。
   - 其余页面只保证可用：表格可以横向滚动，弹窗占满宽度，页面整体不出现横向溢出。

## 范围外

- 主题切换的过渡动画、节日装饰。
- 封面图生成：属于封面任务，书架只预留替换位置。
- 其余管理类页面的表格改为卡片列表。

## Acceptance Criteria

- [ ] 阅读器能翻章（按钮和左右方向键）、打开目录，并调整字号、行距、宽度、背景和字体；设置在刷新页面后保留。
- [ ] 阅读进度保存在服务端：换一个浏览器登录后，能回到上次读到的章节和位置；跳过空章节。
- [ ] 侧边栏显示本章分析的摘要、情节点、钩子和伏笔；本章没有分析时给出提示；可以从阅读器跳到编辑器。
- [ ] 书架的搜索、排序、筛选可用，刷新后保留选择；同一书名的封面颜色每次都一样。
- [ ] 「继续写作」跳到最近编辑的章节，项目没有章节时跳到概览；「阅读」显示读到第几章，没有阅读进度时从第一个已写章节开始；导出、备份、删除都可用。
- [ ] 顶部统计数字正确；在 375px 宽的屏幕上每行两列。
- [ ] 主题能在浅色、暗色、跟随系统三档之间切换，无需刷新；选择会保存；跟随系统时，系统主题变化会实时生效。
- [ ] 暗色下没有残留的写死浅色块，关系图、伏笔时间线、差异对比、分析历史都能看清；有测试禁止在 tsx 中新增写死的颜色（白名单除外）。
- [ ] 在 375px 宽的屏幕上：
  - 顶栏和项目侧栏是抽屉；
  - 书架、概览、章节列表（卡片形式）、编辑器（AI 面板在抽屉里）、阅读器、灵感会话都完整可用；
  - 其余页面没有页面级的横向溢出，表格可以横向滚动，弹窗占满宽度；
  - 窗口缩放时布局实时切换。
