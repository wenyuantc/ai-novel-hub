# 管理员作品管理

## 目标与用户价值

为管理员提供实例级作品管理入口，集中查询用户创建的小说，直接查看和维护项目资料、章节正文及创作设定，并能单独删除项目。

用户原始需求：`管理员增加 项目管理`。用户已同意创建任务并规划，并选择方案 3「完整管理」：在基本信息查询与删除之上，允许管理员读取和修改其他用户的项目资料、正文和设定。用户随后回复“开始”，批准最终方案实施；追加要求将管理员菜单名称统一为“作品管理”。

## 背景与约束

- 现有管理员只提供用户管理，入口位于账户菜单和全局侧栏底部：`backend/app/api/v1/admin.py:13`、`frontend/src/components/AppLayout.tsx:40`、`:86`。
- 本需求明确扩展原有“管理员不可读取其他用户小说内容”的契约，实施时必须同步 `.trellis/spec/backend/auth-admin.md:76` 和 `README.md:311`，不能留下相反的权限说明。
- 普通用户访问他人项目仍按现有规则返回 404：`backend/app/services/project_service.py:22`；管理员只在本需求列明的项目内容操作中获得例外，账户私有资源不随之开放。
- 编辑界面和业务规则已经存在；章节版本、字数计算、跨项目引用校验、组织循环检查、编号平移、生成中锁定等规则继续适用。

## 需求

### R1：管理入口与真实管理员身份

- 管理员在账户菜单及全局侧栏看到与“用户管理”同级的“作品管理”，普通用户不显示入口。
- 管理列表仅允许当前启用中的管理员访问。所有内容操作由后端重新校验真实请求身份；禁止切换成项目所有者会话。
- 普通用户仍只能操作自己的项目，管理员被降级或禁用后不能继续管理他人内容。

### R2：跨用户项目查询

- 展示项目名称、所属用户、题材、状态、章节数、总字数、创建时间和更新时间。
- 支持按项目名称或用户名搜索、按所属用户及项目状态筛选，以及分页；搜索与筛选支持组合，改变条件后回到第一页。
- 默认按更新时间从新到旧排列，同时间结果稳定；没有章节的项目统计为零。
- 搜索特殊字符按普通文本处理；空结果、加载失败、空项目都有明确反馈。
- 管理列表与管理员自己的书架分开，个人书架和密钥授权项目选择继续只列当前账户自己的项目。

### R3：完整的人工内容管理

- 管理员从列表打开项目后，能够查看、修改项目资料与状态，维护世界观、人物、组织与成员、人物关系与类型、职业与分配、大纲与细纲、伏笔等现有人工设定。
- 章节支持查看、新建、修改标题与正文、删除、选角、从既有大纲建章；保留版本内容查看与恢复能力以及原有生成中保护。
- 支持手动上传、查看及删除封面。支持查看和维护已有知识库文档的人工设置、分块及删除，以及剧情记忆既有人工维护能力；自动记忆仍遵守原有内容不可直接修改/删除规则。
- 管理他人项目的内容保存不会自动调用所有者模型或排队索引任务。
- 项目默认风格与章节风格保留现有绑定并可显示当前摘要；本次跨用户管理不修改引用，也不读取所有者完整私有风格库。
- 修改直接保存到原项目，所有者重新读取后看到结果；不承诺跨浏览器实时协作或新增多人冲突合并。

### R4：明确的管理身份与工作区行为

- 复用现有项目工作区；管理他人项目时持续显示所属用户名和管理提示，提供返回作品管理列表的入口。刷新和直接访问链接后仍能正确识别归属。
- 只读阅读可以使用现有阅读器；管理员阅读他人项目不使用或修改所有者的阅读进度。
- 管理他人项目时关闭未授权的 AI、智能体、批量生成、向导、自动分析/任务订阅和私有资源入口，后端同样拒绝对应操作。正常维护自己的项目仍保留原有功能。
- 标题/正文保存、未保存离开提示、中文错误、桌面/移动端和明暗主题行为继续适用。

### R5：删除项目

- 管理员可以单独删除任意用户的项目。
- 删除前明确展示项目名称与所属用户，提示关联内容将永久删除，并要求输入项目名称确认。
- 取消不产生删除请求；确认后只删除目标项目及其项目内关联数据，不删除所属用户、模型配置或其他项目。
- 删除列表当前页最后一项时合理回退；工作区删除后返回作品管理列表。

## 验收标准

- [x] AC1（R1）：管理员看到入口，管理列表未登录返回 401、普通用户返回 403；普通用户对他人项目和子资源继续 404。
- [x] AC2（R1）：降级、禁用或会话失效后，原管理员不能继续读取/修改他人项目；不存在及跨项目混用子资源 ID 继续拒绝。
- [x] AC3（R2）：两个以上用户的项目能合并查询；组合搜索/筛选、分页、总数、稳定排序及空章节统计正确，`%`、`_`、反斜杠不会扩大匹配范围。
- [x] AC4（R3）：管理员对他人项目的资料、正文和各类人工设定能完成读取和保存；所有者重新读取看到结果；正文字数、版本、引用关系及章节号相关规则正确。
- [x] AC5（R3）：人工章节/记忆保存不创建所有者 AI/索引任务、不调用模型；原有风格绑定不被清空或换成管理员私有风格；自动记忆限制和生成中锁继续生效。
- [x] AC6（R4）：管理他人项目的工作区和阅读器明确显示归属，刷新有效；不请求/订阅他人任务，不修改其阅读进度；自己的项目能力正常。
- [x] AC7（R5）：取消不删除，确认仅删除目标项目关联数据，其他项目与账户资源不受影响；成功后导航和分页正确，不存在项目返回 404。
- [x] AC8（R1、R3、R4）：模型凭据、平台密钥、私有 Skill/MCP/模板/风格库、生成日志完整提示词和所有者任务均未因新增项目权限而开放。
- [x] AC9（全部）：前后端质量门禁通过，并完成管理员/所有者/第三名普通用户及桌面/375px、明暗主题的真实浏览器验收。

## 不在本次范围

- 代项目所有者调用模型，AI 生成/分析/改写、智能体执行、批量生成、创建或接管所有者后台任务。
- 跨账户密钥、模型配置、私有 Skill/MCP、提示词模板、私人风格库的读写；修改项目/章节的风格绑定。
- 知识库上传解析、重建索引与向量搜索等依赖任务或模型的操作；生成日志提示词全文。
- 导入/导出/全项目备份、转移项目所有权、批量处置项目、新建审计系统、新增实时协作与冲突合并。
