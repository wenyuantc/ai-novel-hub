# 设定缩略图 AI 生成设计

## 边界与数据流

- 作品入口为角色、世界观（含地点）、组织、职业的已保存本地条目；系列入口为系列库角色和世界观。按钮放在现有缩略图编辑控件旁；列表只展示。系列已采用图在单书投影仍只读。
- 统一的交互为：获取安全默认提示词及其来源凭据 → 用户编辑、选择图片模型 → 生成标准化单张预览 → 用户明确应用。重新生成会使旧预览不可误用；取消不写库。说明默认词取自已保存内容，当前未保存表单不自动发送。
- 项目和系列分别授权、投影、绑定模型和执行发送门禁；可以复用低层图片 Provider、图片 codec、控件及存储逻辑，但不能把系列伪装成任何作品。系列可能尚无采用作品。
- 保留图片长宽比并复用现有模型输出尺寸与缩略图标准化，不改封面生图尺寸和 Provider 全局语义。模型失败或网络错误不会自动重试造成意外重复费用（现有受控 Provider 的明确尺寸兼容回退除外）。

## 语义合同

建议在单书与系列各自现有 thumbnail 路径下对称新增 `GET /ai/prompt`、`POST /ai/generate` 与 `POST /ai/apply`。具体 schema 随实现完善，但必须满足：

1. **提示词**：服务端按真实认证身份、目标及权限构建，返回非空可编辑文本与防篡改、受主体和原始来源状态约束的凭据。单书以 `setting_ai_context` 为依据显式选择目标，按字段与引用可见性投影；系列只投影 `SeriesEntry.data` 的 AI 可见共享字段，使用其 `ai_settings`，不读取某部书的私人字段或作者私人风格。`manual_only` 允许本次显式选择，`never` 拒绝，隐藏字段不自动输出；不自动展开其他关联条目，不发送原图。自定义字段只在当前条目中且确实通过既有字段可见性投影时使用。
2. **编辑边界**：提示词去空白后限制 1–2000 字符，用户可自由编辑。系统保证自动投影与旧来源凭据的检查，不声称能识别用户手动复制到自由文本中的隐藏内容；界面应让用户在发送前检查提示词，日志不记录提示词、设定正文、密钥或敏感第三方错误。
3. **生成**：请求必须携带提示词来源凭据、可选图片配置和生成时捕获的图片版本；系列还固定 revision。来源凭据由服务端验证，绑定原 actor／认证代次、目标、设定来源和可见性，不能用客户端自报版本代替。文本、设定策略或目标已变时返回冲突，保留编辑内容并要求重新读取核对，不以新戳静默重放旧文本。生成响应只包含标准化预览、实际模型来源及可用于确认的受保护证明，不写图片表。
4. **确认**：生成预览与真实 actor、原协作邀请轮次、主体、来源／策略、配置指纹、图片版本、图片摘要及系列 revision 绑定。使用有明确用途和有效期、不泄露作者私有配置的防篡改证明，且在服务器短事务和原有锁序内复验；不能信任调用者自行宣称原授权。确认路径校验标准 WebP、证明及当前图片 CAS，再复用既有资源与绑定写入；同一证明不得借撤权重邀后的新授权使用。普通人工上传路径继续独立运作，不把人工上传误当 AI 预览确认。标准图验证后尽量保留相同 bytes，避免预览后重复有损编码。
5. 图片版本沿用既有 `expected_version`，无图为空字符串；系列还用 `expected_revision`。409 保留草稿、重新读取并明确告知，不能自动以新版本覆盖。生成返回前已变化的目标／权限／策略／模型使结果失效；可见性变化后不能把旧默认词重新提交。

## 授权、发送和响应

- 作品必须同时具有图片编辑权与 `ai.use`；真实作者和已接受 editor 按项目现有模型规则选择，作者委托配置只能在既有授权条件下回退，返回 `actor` / `owner` 来源而不返回作者配置 ID、模型名、端点或凭据。纯管理员人工权限不带来生图权；已采用的系列图片不可从作品入口绕过。
- 系列作者、已接受的系列 editor 只能使用各自本人的图片配置；系列管理员身份、单书权限或作品作者模型授权都不能推导系列生图权。缺模型或本人配置失效时清晰报错，不静默换用他人配置。
- 作品协作者路径复用并扩展现有受控图片模型／发送机制；作者路径同样绑定构建时可见性戳和实体来源，不能照搬封面作者路径的无设定门禁实现。以可信来源捕获并重验身份、邀请轮次、目标归属、文本／策略版本和配置实例；不能把仅支持后台任务的 `EntitySourceSnapshot` 冒充 HTTP 凭据。
- 系列建立与现有 `DispatchHooks` 物理发送语义等价的独立受控门禁：固定 actor/token 版本、系列 owner、原 editor 邀请身份、entry、系列 revision 和本人的模型指纹。沿现有系列认证 → 系列父行 → 配置锁顺序，针对 SQLite 和 PostgreSQL 证明其与撤权、重邀、条目／策略修改相冲突；不得伪造 `project_id`。
- 外部调用的每次实际请求、明确尺寸回退、URL 下载和重定向均在受控发送边界重验。持锁严格限定在既有物理发送租约之内，收到响应头即释放；不在模型构造、等待完整响应体、图片解码或用户预览期间持业务写事务。错误、超时和取消必须释放锁。来源、权限和模型在响应前复验，敏感响应使用与封面同级的有界 ASGI 发送保护；已向外发送的数据无法撤回。
- 前端固定 actor、登录／授权代次、作用域、条目、图片版本和系列 revision，并对关闭、切换、撤权重邀及迟到响应作失效处理。确认期间与上传、删除互斥；写入结果未知先重读，不自动重复写或重复生图。更新只合并图片元数据与必要的系列 revision，不能覆盖文本草稿。

## 图片、兼容性与风险

- Provider 输出先受现有 10 MiB 上限及格式限制，再经现有 `normalize_image_async` 有界线程实际解码、单帧／尺寸／像素校验、去元数据，输出最长边 512、最多 512 KiB 的 WebP 供预览。不能仅用封面的文件头检查；失败时原图不变。
- 预览和凭据为短暂状态，设计不依赖新持久化实体，预计不需迁移，不修改备份、设定卡、模板格式；实施前须用真实配置和各调用链确认。既有人工上传及删除接口兼容保持。
- 来源凭据、预览证明与受控响应应有独立用途绑定，跨 actor／条目／版本／系列无效；密钥使用现有服务器密钥管理且不可泄露敏感声明。若无法在现有锁序下保证原邀请与实体来源的真实发送／确认边界，应先解决并证明，不能退化为仅前端禁用或单次预检。
- 系列与作品 CAS 的现有语义是比较当前版本，而非记录图片的全部历史；无图版本为空串，不能宣称它检测了无图→有图→无图的全部历史变化。当前有图的并发写不能被旧版本覆盖。无状态确认不承诺凭据全局严格一次性：若确认响应丢失，界面必须先刷新，不能自动重放；严格的跨实例 nonce 消费和图片历史代次需持久化与迁移，留待另项需求。
- 生成可能产生第三方费用；请求失败或断线不保证服务商没有计费。不同 Provider 对比例和模型能力的支持不同，不能保证输出为方图或验证真实服务商效果。

## 追加：个人生图提示词模板

- 将当前 `setting_thumbnail.py` 的默认文本迁入现有提示词模板注册表及 `.j2` 默认模板，key 为 `setting.thumbnail`，显示名称为“设定图片”，复用“设定生成”分类；必须保留用户本轮修改的结尾“画面中不要出现除了当前角色以外的人物、文字、字母、数字或水印。”，默认输出与修改后的现有实现保持一致。用户可在已有模板页面保存、启停、恢复与复用个人覆盖及提示词组件，不新增平行存储或数据库迁移。
- 模板变量 `subject` 与 `fields` 分别提供条目类型与按现有 AI 可见性过滤的已保存字段。默认模板引用它们；用户可在模板编辑器内自由调整内容与变量，模板渲染不绕过现有实体资格和字段投影。作品及系列均按实际发起人的 `actor_id` 查询本人有效覆盖，缺省使用系统模板，不读取作品或系列作者的私人覆盖。
- 图片模型只接收一段文本：遵循现有模板注册表和组件展开规则，将非空系统段与用户段按顺序组合。保留默认情况下字段裁剪及提示词 2000 字上限；自定义模板渲染后为空或超限时给出清晰错误，不静默截断用户写入的模板。生图弹窗内修改仍仅作用于当前请求，不会静默保存成模板。
- 生图弹窗提供到该模板的快捷入口，使用现有 `/prompt-templates?key=...` 深链并在新标签打开，以保留当前弹窗草稿；提示用户保存后重新打开生图弹窗以读取模板。
- 模板取值发生在获取默认提示词时，不改变现有提示词凭据、生成前资格重验、系列锁序、图片版本及预览确认语义。测试默认文案、模板管理 API 保存／停用／恢复及组件、作品与系列执行者隔离、隐藏字段和重开弹窗后的生效效果。
