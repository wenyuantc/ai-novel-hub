# 提示词可复用组件

父任务：`11-08-prompt-components-inputs`（决策 D2–D5 的来源与现状证据见父任务 `prd.md`）。

## Goal

作者把反复出现的提示词片段（如「本书禁用词」「对话写法要求」）保存为组件，在自己的 Skill 正文和系统模板覆盖中引用；修改组件后所有引用方同时生效，并能查看每个组件被哪些地方使用。

## Requirements

- **R1 组件库**：组件归属作者个人（对其全部作品生效）。字段：标识（小写字母、数字、连字符，作者内唯一）、名称、说明、内容（≤ 20000 字）。每位作者最多 200 个。支持新建、编辑、删除、搜索；编辑有修订号并发保护，旧修订保存得到冲突提示而不静默覆盖。
- **R2 引用语法**：在 Skill 正文或模板覆盖的 system／user 段写 `{{> 标识 }}` 引用组件，按引用处原样展开组件内容。组件内不能再引用组件（D4）；出现即视为错误。
- **R3 模板覆盖中的组件**：保存、导入、预览、回滚覆盖时，先展开组件，再对展开结果执行原有全部沙箱校验与长度限制；错误信息标明来自哪个组件。运行时同样先展开后渲染。组件内容可以使用该模板已声明的变量。
- **R4 Skill 中的组件**：保存 Skill 时校验引用存在；任务创建时快照「展开后」的正文，之后修改组件不影响已有任务及其重试。智能体 `load_skill` 读到的是展开后的正文。
- **R5 引用完整性**：保存引用方时，引用不存在的组件 → 校验错误。被引用的组件不能删除，也不能修改标识，提示列出引用方。修改组件内容时，若会让任何引用它的覆盖校验失败，拒绝保存并列出受影响的覆盖与原因。
- **R6 使用关系**：组件列表显示每个组件的引用数；组件详情列出引用它的 Skill 与模板覆盖（名称、类型、是否启用），可跳转到对应编辑页。Skill 与模板覆盖编辑页显示其引用了哪些组件。
- **R7 离开作者本人时展开（D5）**：Skill 导出（SKILL.md／zip）、模板覆盖导出（`ainovel.prompts`）、工坊分享模板覆盖时，组件引用替换为组件当前内容。全局 Skill 保存或导入时禁止引用组件（提示改为直接写正文）。
- **R8 组件库导入导出**：单独导出为 JSON（`ainovel.prompt-components` v1），导入逐项给出结果：新建、更新、不变、无效（含原因）；更新同样执行 R5 的影响校验。

## Acceptance Criteria

- [ ] 新建组件「禁用词」，在一个 Skill 和 `chapter.generate` 覆盖里引用；用该 Skill 整章生成时，实际发送的 system 中两处都是组件内容。
- [ ] 修改组件内容后，新任务立即使用新内容；修改前已创建的任务重试仍使用旧快照。
- [ ] 覆盖里引用不存在的组件、组件内含 `{{> x }}`、组件内容含该模板未声明的变量或禁止语法：保存覆盖返回带位置与组件来源的 400。
- [ ] 删除被引用的组件、修改其标识、把其内容改成会让引用方校验失败的内容：都被拒绝并列出引用方。
- [ ] 组件详情列出全部引用方，可跳转；Skill／覆盖编辑页能看到所引用的组件。
- [ ] 导出带组件引用的 Skill、导出模板覆盖、分享到工坊：得到的内容不含 `{{> }}`，与展开结果一致。
- [ ] 全局 Skill 含组件引用时保存被拒绝。
- [ ] 他人的组件不可见（404），也不能被引用。
- [ ] 组件库导出后再导入到另一个账号，逐项结果正确。
- [ ] 没有组件引用的覆盖与 Skill，行为和渲染结果与改动前逐字一致（parity 不变）。

## Out of Scope

- 组件嵌套引用组件（D4）；组件带参数。
- 管理员级的全局组件库；工坊分享组件本身。
- 组件内容的历史版本（覆盖自身已有版本历史）。
- 系统默认模板引用组件。
