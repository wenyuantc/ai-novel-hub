# Word 导出与内容组合导出

## 目标

落实 `TODOS.md:144` 第 12 项，让作者与有导出权限的协作者把所需正文、摘要和创作资料组成可阅读文档，用于审阅、分享或继续编辑。

## 背景与已确认决定

- 用户于 2026-11-16 同意创建任务并规划。
- 用户选择 A：DOCX／Markdown／TXT 支持内容组合，EPUB 保持现有功能。
- 用户确认资料按具体条目勾选：设定按条目、聊天按会话、笔记按篇。
- 当前弹窗只有 TXT／MD／EPUB 和整章选择，空选代表全部（`frontend/src/components/ExportModal.tsx:16`）。站内作者与 accepted 协作者可导出；开放 API 为严格作者路径（`backend/app/services/export_service.py:101`、`:116`；`backend/app/services/project_access.py:64`）。
- 场景已有正文和摘要（`backend/app/models/scenes.py:11`）；章节无摘要字段（`backend/app/models/entities.py:579`），阅读器使用最新章节分析摘要及过期状态（`frontend/src/components/reader/ReaderAnalysisPanel.tsx:15`）。
- 正文格式投影排除作者区块和标记（`backend/app/services/rich_document_render.py:1`、`:155`）；笔记是作品级内容，聊天按实际会话创建者隔离（`backend/app/services/note_service.py:20`；`backend/app/services/agent/service.py:353`、`:522`）。

用户已在审阅完整方案后的消息中明确批准实现；以下为本任务的验收依据。

## 需求

### R1 格式与文档

- 新增 Word（DOCX）。DOCX、Markdown、TXT 共用内容选择规则，每次输出一份文档。
- 顺序为作品信息 → 所选正文／摘要 → 设定 → 聊天 → 笔记；未选分类不出现。
- 标题层级清楚。DOCX 保留正文的粗体、斜体、标题、列表、引用与段落；Markdown 沿用现有格式语义，TXT 为纯文本。
- 只读取已保存内容，不触发 AI、不保存编辑器草稿、不改变作品数据。

### R2 章节／场景及内容模式

- 按章节或按场景选择；范围为全部、自选或不包含正文／摘要。自选可全选／清空，按书内顺序输出，不按点击顺序。
- 模式为正文、摘要、正文＋摘要。默认按章导出全部正文，资料默认不选。
- 章级使用完整章正文与最新章节分析摘要；场景级使用场景原文与已保存场景摘要，按所属章分组，不附带整章摘要。
- 二者组合时每单元先摘要后正文，明确标签。缺摘要显示“暂无摘要”；过期章摘要保留并注明“正文或分析来源已修改，摘要可能过期”。场景摘要不伪造过期判断。
- 不以细纲代替摘要。纯正文模式跳过空正文并提示；有摘要无正文仍可导出。摘要模式保留缺摘要单元及占位说明。
- 生成中的章及场景不可自选；全部模式跳过并提示。自选项在提交时才开始生成，返回冲突，让用户等待或重新选择。
- 自选为空不代表全部。允许明确关闭正文／摘要，仅导出资料；完全无选择或全部被排除时提示，不生成空文件。
- 删除、退场、跨作品的选择不静默忽略或扩大为全部。

### R3 按项组合创作资料

| 分类 | 单位 | 输出内容 |
| --- | --- | --- |
| 设定 | 人物、世界观、组织、职业条目 | 当前档案、别名／标签、自定义字段；选项与引用具名，职业包含阶段。 |
| 聊天 | 本作品内本人的会话 | 已保存用户／助手消息、会话标题、角色和时间，保持消息顺序。 |
| 笔记 | 篇目 | 标题和完整正文，不以列表摘录代替。 |

- 设定支持分类／搜索，笔记支持搜索；翻页与切换分类保留选择，显示已选数量，可单独取消和清空。
- 所选档案相关的当前人物关系、职业挂接、组织隶属／成员以名称及简短关系呈现；不自动追加引用对象的完整档案或关系历史。
- 设定是当前本书值，与当前设定页一致，可能含计划章节事件。系列资料仅取已采用的本书投影。
- 三类资料默认关闭，可与正文组合或独立导出；不因引用或同名扩大条目选择。

### R4 权限与失败

- 继承现有 `can_export`：作者与 accepted 协作者可用；仅管理员作品读取权限不能导出。
- 聊天始终仅本人；作者不能导出其他协作者聊天。查看者可导出自己可读的旧会话，不要求 AI 或模型权限。
- 聊天沿用私人内容安全投影，排除工具消息、工具参数／结果、任务结构、模型秘密、Skill 快照等内部载荷。
- 最终交付核验前已生效的撤权、作品回收、账号／会话失效会使导出被拒绝；回收后恢复或撤权后重邀也不能恢复旧请求。已通过最终核验并交付的文件无法撤回。
- 加载失败可重试；导出失败保留选择，不自动重发。关闭弹窗、切换作品／身份或权限变化后，旧响应不能下载或影响新弹窗。

### R5 兼容与可用性

- EPUB 保留整章正文、作者、简介页、分卷目录行为，不携带组合参数。切回文档格式保留当前弹窗内的选择。
- 旧 TXT／MD／EPUB 接口、开放 API、项目 JSON 备份及其默认语义保持兼容。
- 桌面与 375px 窄屏可用，支持键盘，说明仅导出已保存内容与已选数量。

## 不在本次范围

- EPUB 内容组合、PDF、新开放 API 格式或参数。
- 设定历史／指定时点、历史版本、知识库原文、灵感会话、作者区块、正文标记和未保存草稿。
- 按单条聊天消息剪选、工具执行报告、AI 自动摘要。
- 自定义 Word 模板、印刷级排版、封面图片、自动页码目录、定时导出与组合文档回导。
