# 管理员系统设置

优先级：P2。沿用2026-10-30建档的 `admin-system-settings`，不重复创建任务。

## 目标

管理员无需修改部署文件或重启服务，即可管理六项业务运行设置，看到有效值、来源及生效边界；部署凭据仍由运维管理。

## 已核实背景

- `backend/app/core/config.py:20` 的 Settings 从环境变量/.env加载，第98行使用lru_cache；六项代码默认值定义在 `backend/app/core/config.py:28-47`，不等于具体部署有效值。未读取开发者.env或部署密钥。
- 请求从 `backend/app/core/deps.py:17-18` 读取共享Settings，同一对象传入任务上下文（`backend/app/main.py:95-107`）；并发检查在 `backend/app/services/task_engine/engine.py:226-233`，目前没有后台持久化入口。
- 前端仅在认证初始化时获取公开开关（`frontend/src/stores/auth.ts:25-39`），必须补齐后续同步。
- `docker-compose.yml:27-38` 注入全部六项环境变量，环境变量永远优先会使后台覆盖无效。
- 现有调度器要求单进程部署，见 `.trellis/spec/backend/database-guidelines.md:485-489`；本任务不改变此已有前提。

## 已确认需求

### R1：首期白名单

| 设置 | 字段 | 代码默认值 |
| --- | --- | --- |
| 注册开关 | registration_enabled | true |
| 全局任务并发 | task_max_concurrency | 4 |
| 单用户任务并发 | task_max_per_user | 2 |
| 自动分析开关 | auto_analyze_enabled | true |
| MCP开关 | mcp_enabled | true |
| 开放API每Key每分钟限流 | open_api_rate_limit_per_minute | 120 |

### R2：来源与恢复

优先级为「后台已保存值 > 环境变量/.env > 代码默认值」，覆盖跨重启持久保留；未设置覆盖沿用旧部署行为。展示有效值/来源/部署值/代码默认，支持逐项取消覆盖恢复部署值，不修改环境变量或.env。已有覆盖时，后续修改环境变量不会取代它。

### R3：即时生效与现有工作

- 六项均保存后即时生效、无需重启，后续请求/调度/自动分析触发使用新值。
- 降低并发不取消运行任务，新调度按新上限排队；单用户上限仍受全局约束，不新增必须小于全局的限制。
- 关闭MCP阻止后续调用，已经发出的调用允许结束，不承诺撤回外部副作用。
- 关闭自动分析不取消已排队/运行分析，不影响手动分析；后续普通与批量自动分析按有效开关判断。
- 修改API限额保留当前UTC分钟计数，不影响网页登录接口。

### R4：公开界面同步

页面可见时每30秒同步注册/MCP公开开关，切回前台立即同步，隐藏暂停。后端限制即时生效，不承诺轮询/网络异常期间界面零延迟。刷新失败保留最近成功值；本页管理保存成功立即应用公开两开关，旧响应不能反写，不重复初始化登录态。

### R5：安全、校验与编辑保护

只有启用管理员可读取/修改管理配置，公开接口仍只有两个开关。严格白名单/布尔/正整数校验；开放API限额另受数据库Integer计数上限2_147_483_647约束，拒绝会导致后续绑定溢出的超大输入，非法批次整体拒绝且正常回滚不改变旧值。并发编辑不能静默覆盖；设置变更与真实actor审计同事务。只输出/审计六项安全数据，不回显部署凭据、完整Settings或异常原文。表单支持忙态、错误/重试、逐项恢复确认，刷新不覆盖未保存编辑。网络/提交结果不确定时先刷新核实，不伪造成功或相反失败事实。

## 验收标准

- [x] AC1（R1/R2/R5）：恰好六项安全读写及来源，false/null/未提交正确，非法批次整体拒绝。
- [x] AC2（R2）：新建应用/重启保留覆盖，无覆盖/逐项恢复正确沿用部署，环境文件不被修改。
- [x] AC3（R3）：真实注册立即受新开关约束，登录/管理员建号不受注册关闭影响。
- [x] AC4（R3）：真实两级并发调度可更新，降低不杀任务，提高能唤醒调度，资源互斥/FIFO/取消不回归。
- [x] AC5（R3）：普通与批量后续自动分析使用新值，已排队/运行/手动分析行为不变。
- [x] AC6（R3）：插件试用/发现与智能体待执行MCP调用均被关闭阻断，包括连接建立或Worker排队后尚未发出的工具调用；已发出调用可完成。
- [x] AC7（R3）：开放API新阈值生效且不重置本分钟计数，429/Retry-After保持正确。
- [x] AC8（R4/R5）：30秒/前后台/慢请求/卸载/旧响应/保存失败/脏表单可验证；375px、浅暗主题与键盘可用。
- [x] AC9（R5）：管理401/403、无凭据泄露，过期版本保存409、不丢失其他管理员变更。
- [x] AC10（R5）：审计失败回滚设置；提交确认丢失重读持久事实，无相反审计或永久运行时分叉；迁移及原有回归通过。

## 不在范围内

任意环境变量/部署密钥/数据库连接/模型参数/SSRF私网许可；自动部署或重启、隐式取消任务、外部副作用撤回、角色配额、多实例调度改造、实时推送、小说备份携带实例设置。
