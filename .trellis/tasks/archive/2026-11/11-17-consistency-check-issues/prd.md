# 一致性检查与问题清单

## 目标
父任务 `11-17-consistency-check-impact-tracking` 的子任务 1，承接其 R1–R3 及 R5、R6 的相关部分：作者手动发起全书或章节范围的 AI 一致性检查，得到带原文证据、可跳转、可跟踪状态的跨章问题清单。本任务同时落地「事实台账」，供子任务 2 复用。

## 背景
证据见父任务 research/code-inventory.md。父任务决策 D1 已定检测方式：手动发起的后台任务，先逐章抽取事实台账，再跨章比对。

## 需求
| ID | 行为 |
|---|---|
| C1 | 发起检查：选择全书或起止章节范围；先看预览（范围内章数、需重新抽取的章数、可复用台账的章数、空章数），确认后作为后台任务运行，可见进度、可取消、失败后可重试续跑。 |
| C2 | 事实台账：逐章抽取人物经历、人物状态、物品去向、时间线索、伏笔相关五类事实，每条带原文引句。按章保存；正文未变的章节复用台账，不再调用模型。取消或失败时已完成章节的台账保留。 |
| C3 | 跨章比对：按章节顺序比较台账，产出矛盾问题。范围检查只重新抽取范围内章节、只报告至少涉及一个范围内章节的问题，但比对时可使用范围外章节已有的台账。伏笔前提的比对同时参照伏笔管理中的记录。 |
| C4 | 问题内容：类别、标题、说明、修改建议、严重程度、涉及章节，以及每处证据的原文引句。 |
| C5 | 证据跳转：证据可跳到阅读器或编辑器的对应位置；正文已变时提示位置失效而不误指；引句无法在原文逐字定位时降级为跳到该章开头并说明。 |
| C6 | 问题状态：待处理／已解决／已忽略，可备注；并发修改返回冲突并保留本地输入。 |
| C7 | 需重新核查：问题任一证据所在章节的正文在检查之后发生变化（或章节被删除），显示「需重新核查」；作者可对单个问题发起重新核查，等同于对其涉及章节运行一次检查。 |
| C8 | 重复检查的口径：同一矛盾不产生重复问题。已忽略的问题再次检出仍保持已忽略；已解决的问题再次检出则重新变为待处理并标注「再次出现」；待处理的问题本次未检出时标注「本次未复现」，状态不自动改变。 |
| C9 | 问题清单页：作品内新页面，按状态、类别、章节、是否需重新核查筛选，分页；显示最近一次检查的时间、范围与结果概要，以及台账覆盖情况（最新／已过期／未抽取的章数）。 |
| C10 | 权限：查看者可查看清单与证据；编辑者与作者可改状态、可发起检查（沿用现有 AI 能力与模型授权规则）；撤权或降级后进行中的检查失效关闭，已保存的台账与问题保留。 |
| C11 | AI 出站边界：抽取只发送章节正文，遵守作者区块的 AI 可见设置；不发送结构化设定档案。比对只发送台账事实与允许进入上下文的伏笔记录。 |
| C12 | 备份：问题（含状态与备注）和事实台账纳入作品备份并升级格式版本；检查运行记录不导出；合法旧备份仍可导入。 |
| C13 | 同一作品同一时间只允许一个进行中的检查；检查期间章节正文被修改时，该章本次结果不保存并在结果概要中列出。 |

## 口径
- 「矛盾」由模型根据台账判断，属于提示而非结论；清单文案须表明是「潜在冲突」。
- 检查不改动正文、设定、伏笔、剧情记忆，也不自动修复。
- 不做费用估算；预览只给出将调用模型的章数。单次检查需重新抽取的章数设上限，超出时提示缩小范围。
- 测试使用隔离数据与 FakeLLM，不代表实际模型的检出率保证。

## 验收标准
- [ ] AC1 / C1–C5：第 5 章写明佩剑已毁、第 12 章仍使用该剑时，全书检查产出一个「物品去向」类问题，展示两处原文，分别跳转到对应位置。
- [ ] AC2 / C2：再次运行检查时未改动的章节不再调用模型；只修改一章后重跑，仅该章重新抽取。取消后已完成章节的台账保留，重试从断点续跑。
- [ ] AC3 / C3：仅检查第 10–15 章时，不重新抽取范围外章节，仍能报告第 5 章与第 12 章之间的问题；不报告完全发生在范围外的问题。
- [ ] AC4 / C5,C7：修改证据所在章节后，问题显示「需重新核查」，旧证据跳转提示失效；删除证据章节后同样提示且不报错。
- [ ] AC5 / C6,C8：状态与备注可保存；两端并发修改返回冲突；已忽略、已解决、待处理三种状态在重复检查后的表现符合 C8。
- [ ] AC6 / C9：筛选、分页、检查概要与台账覆盖数值正确；切换作品或身份后不串数据。
- [ ] AC7 / C10：查看者只读、发起检查与改状态被拒；编辑者可发起；非协作者 404；撤权后进行中的检查停止且不再保存结果。
- [ ] AC8 / C11：出站内容不含关闭 AI 可见的作者区块，不含「永不加入」或隐藏字段的设定内容。
- [ ] AC9 / C12：备份导出再导入后问题、状态、备注、证据定位与台账复用均保持；v1–v11 备份可导入。
- [ ] AC10 / C13：已有进行中的检查时再次发起被拒；检查期间改动的章节不保存旧结果。
- [ ] AC11：后端与前端完整门禁通过；新页面在桌面、窄屏、深色主题与键盘操作下可用；README、规范文档同步。

## 不在本任务
改稿后的派生内容过期标记、评估影响与受影响清单（子任务 2）；随分析自动检查；自动修复；费用估算与用量统计；全书搜索替换。
