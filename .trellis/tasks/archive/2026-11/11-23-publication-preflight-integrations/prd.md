# 发布前检查与外部平台对接

## 目标

作者在定稿和发布前，能看到实际要交付的那一版里有哪些词值得核对，并自行决定是否继续。作品在不同平台的发布结果仍可回到同一份连载记录中查询。

## 已有能力

第 18 项已支持保存不可变定稿、手动登记平台及实际发布时间、按章统计首发，以及从发布历史下载原稿。现有连载下载入口需要发布记录，首次投稿还缺少按指定稿次导出的入口。[连载工作台契约](../../../../spec/backend/serialization.md)

## 需求

| 编号 | 作者或管理员可观察到的行为 |
| --- | --- |
| R1 维护词表 | 有对应权限的管理员维护全站词表，作者在个人设置中维护自己的词表。两处均支持新增、修改和删除词条。每部作品使用「全站＋作品作者」两份词表的并集；协作者操作时也按作品作者取词。协作者仅能看到本章实际命中的词及位置。 |
| R2 检查与定位 | 确认定稿时检查工作台预览的已保存草稿，登记发布或自动发送时检查所选定稿。范围为章名和读者可见正文。每一处命中给出命中词、上下文和跳转，在同一稿次高亮。作者备注和协作讨论不参与匹配。 |
| R3 提醒后继续 | 用户已确认采用提醒模式。零命中按原流程继续；有命中时先展示清单，操作者可返回修改，或明确确认本轮结果并继续。更换稿次、修改原稿或任一词表后需重新核对。 |
| R4 人工提交 | 在连载工作台选择待发布定稿，可导出该稿的通用 TXT，将章名、正文提交至平台作者后台；确认平台实际发布后再手动登记。保留已有自定义平台名与历史稿下载。 |
| R5 平台直发 | 分别评估平台的写入授权、稿件格式、审核状态及回执。对已验证可对接的平台，将指定定稿发往已绑定的远端作品，回执确认实际发布后写入现有分平台记录。受理中、失败或结果不明时可查看状态并核实。首批候选和证据见[平台调研](research/platforms.md)。 |

## 验收条件

- [x] **A1 · 两级词表（R1）。** 管理员添加甲词，作者添加乙词，协作者仅在自己词表添加丙词。三词同章出现时，作者和协作者均命中甲、乙。两份有效词表中的同一词在同一位置只显示一次。普通账号不能修改全站词表，协作者不能列出作品作者的个人词表。
- [x] **A2 · 原稿定位（R2）。** 在章名、正文第二次出现的词及表情符号后的词上逐项跳转，均高亮对应原文。只写在作者备注里的词不出现。草稿已改成 B、选择定稿 A 补发时，命中清单和待导出文件均取 A。
- [x] **A3 · 确认时效（R3）。** 取消核对后没有新定稿或发布记录。确认后只完成所选动作。另一窗口更改草稿或任一词表、切换操作账号或稿次后，旧确认无法提交新操作；直接调用写接口也得到同样结果。
- [x] **A4 · 人工发章（R4）。** 尚无发布记录时即可导出所选定稿。只导出、取消发布或平台审核中均保留存稿；实际发布后手动登记两个平台，能各自查看对应稿次，首发和存稿只按一章计算。
- [x] **A5 · 平台能力（R5）。** 每个候选平台都有官方出处、可确认的作者操作、文件格式证据及待验证条件。如果没有取得可验证的作者写入权限，交付清单标明人工途径和待办，自动发布保持待验。
- [ ] **A6 · 有直发能力的平台（R5）。** 官方测试作品上的实际发布回执只产生一条本地记录。模拟审核中、明确拒绝、发送后断网及同一回执重复到达，均能核实状态；重复点击或恢复操作不重复发章，未能确认成功时不扣存稿。

## 本期边界

首版按字面匹配维护的词条。拼音或谐音识别、AI 内容审核、内置平台违禁词库、定时群发和修改已上线章节另行评估。直发联调取决于平台授权及可核验的测试作品；仅完成通用导出时，第 29 项的直发子项继续保持待办。
