# 两级发布词表浏览器验收

2026-11-26 在隔离 SQLite 数据库、真实 FastAPI 服务、Vite 和本机 Google Chrome 上操作。管理员使用 1280 × 900，作品作者使用 375 × 812，协作者使用独立 Cookie 会话。

| 操作 | 实际结果 |
| --- | --- |
| 管理员新增「晨光旧名」，改为「晨光」，另加一条后删除 | 全站词表接口回读仅有「晨光」。 |
| 作者先新增「路标」，再输入首尾含空格的相同词条 | 保存时提示词表中已有相同词条，原列表保持一项。 |
| 作者在两标签页编辑同一份词表 | 第一页新增「并发词」成功。第二页以旧版本改名收到冲突，关闭并刷新后能看到「并发词」与原「路标」。 |
| 作者在 375px 页面新增、核对并删除临时词 | 页面宽度与视口一致，列表回读为「路标」「晨光」「备注私词」。 |
| 协作者新增「协作私词」，再尝试打开全站维护地址 | 个人接口回读仅有「协作私词」。管理页面提示缺少权限，直接读取管理接口返回 403。 |
| 协作者已打开个人词条编辑框，另一个标签页切换成其他账号，再提交旧词条 | 服务端返回 409，页面立即隐藏旧词表与编辑框，实际新账号词表保持原状；点击刷新页面后显示新账号的词表。 |

本机临时目录 `/tmp/publication-preflight-browser.gIar29/` 中的 `terms.cjs` 和 `terms-cookie.cjs` 是验收脚本，`screenshots/terms-global-desktop.png`、`screenshots/terms-personal-mobile.png` 与 `screenshots/terms-conflict-mobile.png` 为实机截图。
