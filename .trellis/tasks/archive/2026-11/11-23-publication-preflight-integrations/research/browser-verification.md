# 发布前检查浏览器验收

2026-11-26，使用本机 Chrome 158.0.8127.37、Vite 和真实 FastAPI。SQLite 从空库迁移到 0076，数据与账号均在本机临时目录。桌面为 1280 × 900，由作者操作；窄屏为 375 × 812，由该书的编辑协作者操作。另用只读协作者验证操作权限。[词表维护、并发编辑与账号切换验收](browser-terms.md)

| 操作 | 观察结果 |
| --- | --- |
| 确认已保存草稿 | 章名和正文共有三处「晨光」，其中一处在表情后、横跨加粗和普通文本。两份词表都有「晨光」，仅列出三个原文位置。作者词表中的「路标」有一处，两种身份的核对清单均为四处。只在作者备注出现的「备注私词」以及协作者自己添加的「协作私词」均未进入清单。点击条目，依次在章名、表情后的加粗文本、第二段与「路标」高亮对应文字。窄屏页面无横向溢出。 |
| 取消、过期与明确确认 | 取消后接口回读定稿数为零。在另一会话改动作者词表后，点击旧确认，出现重新核对提示，定稿数仍为零。再确认后形成 v1。另一份草稿在核对期间被改名，旧确认失效，页面显示新章名，定稿数保持为零。跨标签页将账号从作者切到编辑协作者后，旧确认返回 409 并关闭，未生成定稿。 |
| 投稿 TXT | 尚无发布记录时点击导出，Chrome 收到 TXT 下载。按 UTF-8 回读的文件包含原章名、分行正文和表情，未包含作者备注。下载前后发布记录均为零，存稿均为一章。 |
| 发布、换稿、跨平台登记 | v1 定稿后在另一会话修改草稿章名。工作台提示草稿有修改，登记 v1 时命中和高亮仍取旧章名。更换目标平台、取消核对均未新增记录。确认后得到第一条记录。新草稿定为 v2 后，旧章名命中消失；在登记核对中 v2 → v1 → v2 两次换稿，旧确认均立即关闭。两次登记分属自定义平台「起点样稿」「番茄样稿」，历史依次引用 v1、v2。存稿只在第一次登记从一章变为零，本月合计首发一章。只读协作者能查看当前草稿，页面没有定稿动作。 |
| 长列表和慢响应 | 375px 下的 56 个命中分成 50 和 6 条两页。点击最后一项后，高亮落在正文末尾。翻页和定位后定稿数保持零。另一次操作暂存后端已生成的核对响应，先关闭抽屉、进入另一章，再放行旧响应；新章预览保持原样，两章未被误定稿。 |

两条主流程、分页与迟到响应、账号切换均通过断言。主流程与分页验收未捕获 JavaScript 页面异常。浏览器控制台包含既有 React Router 升级提示和核对流程预期的 HTTP 409。首次运行修正了验收脚本中的标题保存基线和下拉框点击目标，在新样书重跑了桌面与窄屏全流程。

本机证据在 `/tmp/publication-preflight-browser.gIar29/`。脚本为 `ui.cjs`、`stale.cjs` 和 `actor.cjs`，最终日志为 `desktop4.log`、`mobile2.log`、`stale.log` 和 `actor.log`。下载的两份样稿在目录根部，截图在 `screenshots/`。两个平台名称只用于本地历史登记，实际平台直发条件见[逐平台核查](platforms.md)。
