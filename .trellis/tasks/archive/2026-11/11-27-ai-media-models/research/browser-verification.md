# 浏览器验收记录

2026-11-27，在隔离 SQLite、临时媒体目录和独立 Chrome 用户资料中测试。FastAPI、Vite、Chrome、任务执行器和媒体服务均运行项目代码。厂商端为回环地址上的模拟 OpenAI 兼容 HTTP 服务。测试专用部署显式允许内网模型地址。

| 场景 | 操作与观察 |
| --- | --- |
| 建立配置 | 浏览器登录后在「模型配置」新增 OpenAI 兼容视频配置。保存返回 201，列表显示该配置的「测试生成」入口。 |
| 带参考图生成 | 弹窗上传 PNG 返回 201，创建探针返回 202。模拟服务收到 multipart 首帧、模型与 4 秒时长。浏览器显示「等待厂商生成视频」和 42%。 |
| 硬杀后的自动续等 | 任务 4 收到首次轮询后，SQLite 台账状态为 submitted，外部任务号为 local-2。对临时后端执行 SIGKILL，然后用同一临时数据库启动新进程。原浏览器保持打开。22:51:30 新进程启动，22:51:46 台账成功，浏览器自动出现播放器。该外部任务总共提交一次、查询两次，生成一条 4 秒的用量。 |
| 实际播放 | Chrome 收到本机媒体接口的 206 分段响应，播放器 readyState 为 4，分辨率为 160×120。调用播放后 450 毫秒，currentTime 从 0 变为 0.4498 秒。模拟接口声明生成 4 秒，提供的是 1 秒播放器测试片段。 |
| 取消 | 初测任务 5 暴露任务已取消、外部台账仍是 submitted 的问题。修正后，任务 6 在 local-4 首次查询返回 42% 时通过页面取消，接口返回 200。页面显示已取消，任务和台账均为 cancelled，台账含结束时间，结果及用量关联为空，执行槽位数为 0。 |
| 个人用量页 | 通过「AI 用量与费用」进入页面，显示 2 次调用、视频共 8 秒。两条成功探针各 4 秒，均显示缺少模型单价。已取消的任务没有计入调用次数。 |

首轮断线测试发现原弹窗保持旧进度，必须重开才能播放。补充活动任务状态查询后用任务 4 原地复验通过。迭代期间两个探针在提交前因加载了更新中的预算模块而失败，重启到完整实现后再次验证。

本记录覆盖单机进程更换、兼容协议、权限内的媒体读取和视频解码；四家服务的真实凭据、网络条件及厂商生成质量还需真机账号验收。
