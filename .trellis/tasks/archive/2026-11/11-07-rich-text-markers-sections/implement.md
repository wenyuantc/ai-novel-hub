# 富文本、标记与分区块：实施计划

## 启动与拆分门槛

- 本文为一个端到端任务的顺序切片，不把格式、标记或区块单独标为交付：三者共用场景投影、内容 CAS、历史和 AI 处理，单独发布会绕过另外两者的数据保护。
- 在用户审阅并明确批准本版规划后，才能 `task.py start` 和修改产品代码。发现方案须改变已批准产品行为时回到规划并再次确认。
- 每个切片先建立可失败的针对性测试再实现；留可复现的迁移、冲突和实际出站证据。已存在的无关工作区变更不纳入本任务。

### 3. AI 过滤、确认及任务恢复（依赖 1–2）

## 验收边界

- AC9 的外部自动分析在正常成功路径执行一次；进程在外部调用边界中断时避免自动重发，可能需要人工补分析，不能保证任意故障下严格恰好一次。旧 v8 双活备份和旧标记墓碑按兼容规则保留，不追溯清洗。最终测试与实际浏览器证据见 `research/verification-baseline.md`。

## 验证命令

从仓库根目录执行，PG 连接仅指向专用隔离测试库并按测试约定通过环境变量注入，不记录凭据：

```bash
LC_ALL=en_US.UTF-8 LANG=en_US.UTF-8 uv --directory backend run ruff check .
LC_ALL=en_US.UTF-8 LANG=en_US.UTF-8 uv --directory backend run pytest tests/test_scenes.py tests/test_scenes_migration.py tests/test_scene_versions.py tests/test_scene_transfer.py tests/test_scene_generation.py tests/test_batch_generate.py tests/test_mentions.py tests/test_export.py tests/test_epub.py tests/test_project_transfer.py
LC_ALL=en_US.UTF-8 LANG=en_US.UTF-8 uv --directory backend run pytest tests/test_scenes_postgresql.py tests/test_scene_ai_postgresql.py
LC_ALL=en_US.UTF-8 LANG=en_US.UTF-8 uv --directory backend run pytest
npm --prefix frontend run lint
npm --prefix frontend run build
npm --prefix frontend run test
```

新增专项测试文件应加入定向命令；PostgreSQL 必须设置 `AINOVEL_SCENES_POSTGRES_TEST_URL` 并使用测试代码允许的本机专用库或建立等价独立 fixture。浏览器测试记录自身启动命令和隔离资源，不连接或修改用户真实作品。

## 故障与回退点

- 切片 0 不能做到无损：不进入正式编辑器迁移。
- 数据／备份发现结构无法恢复：停止升级，不强制丢失新结构降级；保留数据库和 v8 导出。
- AI 结果映射不可靠或快照过期：保留提案、等待用户核对或重新生成，不自动移动区块、不半写章。
- 任一完整回归或独立检查失败：保留失败证据，修复并重跑所影响的定向及全量门禁后再声称完成。
