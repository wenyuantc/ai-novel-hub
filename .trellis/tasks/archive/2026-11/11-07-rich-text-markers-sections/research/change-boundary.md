# 实施边界

- 当前缺口：正文只有字符串，没有可校验的富格式、附属区块、标记及其 AI 过滤投影；既有客户端、AI、阅读和备份均依赖场景纯文本权威。
- 真实责任边界：场景文档的结构和纯函数位于后端 schema／service，实际写入必须经现有授权、章节 revision、版本快照及项目 AI 发送屏障；编辑器仅持有同一结构的草稿，不反向成为数据库权威。
- 修改范围：新增场景文档的类型、持久化、原子 API 与迁移，接入现有场景／版本／备份／AI／任务／阅读／导出，并替换场景编辑组件和补测试。先建立严格纯结构与投影测试，再做持久化，最后接通全部入口；任一阶段未接通不视为交付。
- 非范围：无关重构、自动保存、DOCX、跨场景拖动、图片表格、会话授权变更或无关用户工作区改动。
- 兼容证明：旧场景在空结构下的投影、正文、revision 与时间不变；旧入口对有结构文本要走同一安全映射或明确 409；相关旧测试与真实迁移／双端竞争均需验证。
- 记忆 UI 子边界：`Memory.source_stale` 只表达有真实分析来源的自动记忆当前是否过期；手写及不可验证来源为 null。同步传输类型、现有记忆表格提示和纯逻辑测试，明确关闭区块不会追回既有摘要／聊天／记忆，旧派生内容仍可能被召回；不改变钉住、屏蔽和召回规则，不把这个提示当作富编辑器完成。
