# 设定条目与字段的 AI 可见策略

## 目标

完成 `TODOS.md` 第 5 项。作者可以决定哪些档案何时供 AI 使用、哪些信息只保留给自己，并能调整提及匹配以减少误报。保存限制不要求作者删掉档案、改动章节历史或放弃人工追踪。

## 背景

当前角色有常驻／主角、手动选角和自动匹配；世界观默认整体加入章节上下文。人工提及只覆盖角色、地点、物品，且匹配算法与 AI 选角不同。已有自定义字段、规划引用、章初有效关系等机制应复用。章节分析、非章节生成及智能体另有结构化读取，历史工具结果也可被重新发送。源码和参考产品证据见 [匹配与配置调研](research/matching-and-settings.md)、[AI 出口调研](research/ai-paths.md) 和 [发送边界调研](research/dispatch-boundary.md)。

## 已收敛的需求

| 编号 | 要求 |
|---|---|
| R1 | 角色、六种世界观、组织和职业均支持四档条目策略（下表）。只要本应用的 AI 入口从设定库取用资料，就必须统一执行硬限制：包括写作、分析、大纲／设定生成、智能体工具和由设定构成的检索请求。作者显式选择、工具查 ID、名单、二级结构化引用等均不能绕过「永不加入」或字段隐藏。人工档案读写、剧情回溯与备份仍保留原内容及原权限。 |
| R2 | 作者手动选角、规划指定及明确选择的 AI 任务目标是显式引用；模型自行猜 ID 不是。保留目标章节有效的成员／任职挂接；另可配置同作品、单向一跳的条目关联，例如「黑市 → 暗号本」。只有直接入选的来源可以展开，关联入选不递归、不反向，禁用的来源或目标不能参与。普通自定义引用和人物关系不自动变成上下文关联。 |
| R3 | 共享自定义字段（多行、单行、下拉、引用）在定义上设置可见性，旧条目级字段单独设置，内建内容字段按条目逐字段设置。隐藏同时排除标签、值及结构化派生或回显；不修改原值及其按章历史。名称／别名作为匹配身份，由条目策略而非字段隐藏控制是否发送。 |
| R4 | 全部设定类型支持人工标记、提及列表和热力图，复用 AI 字面检测的追踪开关、大小写与排除短语。开关只影响字面匹配，不阻止其他合格纳入原因。保留正文、聊天、笔记、知识库四类来源及权限；不改原文和码点位置。 |
| R5 | 已有条目与不含策略的合法旧备份／卡片先沿用原有注入和追踪行为，作者显式设置后采用新规则；原先未参与追踪的存量类型不自动开启。新建条目默认「检测到才加入」、追踪开启。新完整备份保留全部策略和链接，新卡片保留支持范围内的配置并明确包外映射。普通档案编辑、旧客户端更新、导入复用与旧效果撤销不能静默放宽已配置限制。 |
| R6 | 收紧设置保存成功后，不得为后续模型调用重发可能含受限结构化设定的旧上下文；能安全重建的任务使用当前策略，不能重建的任务在下次调用前停止。不能安全继续的旧会话保留可读并提示新开会话。已经发出的单次请求不撤回；旧聊天、工具、任务和审计记录不删除。 |

### 条目纳入规则

| 策略 | 无匹配、无引用 | 字面有效命中 | 作者显式引用 | 合格的一跳关联 |
|---|---|---|---|---|
| 始终加入 | 加入 | 加入 | 加入 | 加入 |
| 检测到才加入 | 不加入 | 加入 | 加入 | 加入 |
| 检测到不自动加入 | 不加入 | 不加入 | 加入 | 加入 |
| 永不加入 | 不加入 | 不加入 | 不加入 | 不加入 |

“加入”表示在会取用设定的场景中有资格纳入，仍受权限、目标章节、去重和预算限制，不给原本与设定无关的模型操作强加资料。

## 验收标准

- [x] AC1（R1、R2）：使用无匹配、名称／别名命中、手动选角／POV／规划指定和可用关联验证四档。关闭追踪后常驻或显式引用仍可用；「永不加入」在任何分支都不出现在 AI 档案及派生名单。
- [x] AC2（R2、R3）：逐一隐藏四种共享字段、旧文本字段和角色背景／世界观正文／组织简介／职业规则等内建字段；同类另一条目的内建字段不受影响。第 20 章末变化仍能由作者查到；第 5／20／21 章的模型请求、AI 预览及工具回显只包含目标时点的允许字段。
- [x] AC3（R4）：九种设定类型可参与标记、提及和热力图；切换追踪、大小写和排除短语后不复用旧结果，不误删同名其他条目或同一条目的其他位置；含 emoji 的原文可精确跳转，四类来源权限不变。
- [x] AC4（R5）：迁移和旧格式导入保留原有主角／常驻、仅名单、世界观注入和原追踪范围；新条目及首次显式选择采用新策略。新格式往返不丢字段规则和链接，旧效果与导入复用不能覆盖作者后设的限制。
- [x] AC5（R1、R3、R5）：捕获写作／分析／非章节生成／Agent 及设定派生检索的实际出站输入；以隐藏档案、标签和值为反例，且可用内容仍发送。跨作品、只读与过期保存／预览没有副作用。
- [x] AC6（R6）：旧聊天工具结果及摘要含之后隐藏的字段，收紧后普通聊天、摘要及续跑均不重发；历史可读。以受控并发验证「先保存再发送」与「先发出再保存」两个顺序，下一轮旧任务安全重建或不发送，不重复执行已完成的副作用。
- [x] AC7（R2）：A→B、B→C 只有 A 直接入选时仅带入 B；B 独立入选时才可从 B 展开；单独入选 B 不反向带入 A。设 B 为「永不加入」后，别名、关系和字段摘要均不回显 B，也不经 B 带入 C。跨作品关联原子拒绝。

## 不在本期

不做英语复数、正则或语义追踪、跨书或场景关联、模型级字段策略、通用聊天附件编辑器。不会搜索或抹除作者直接写在正文、聊天、知识库资料里的字句，也不承诺从不可区分的自由文本、已产出的分析／记忆、外部服务或供应商历史中撤回信息。产品保证针对应用控制的结构化设定出口及应用可控的旧请求上下文，不是对作者数据的加密或人工访问控制。
