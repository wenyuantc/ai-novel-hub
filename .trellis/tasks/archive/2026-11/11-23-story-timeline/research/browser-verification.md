# 浏览器验收（2026-11-25）

使用本机 Chrome 158.0.8127.37 的独立浏览器上下文。后端启动在回环地址，使用从空库迁移到 0075 的临时 SQLite。前端通过 Vite 连接该后端。为桌面 1280×900 与模拟窄屏 375×812 分别创建一套四章样书、同书作者、编辑者和查看者。样稿和模型 HTTP 替身均在本机。以下耗时为秒，四舍五入至一位。

| 验收 | 本地命令及耗时 | 观察结果 |
| --- | --- | --- |
| R1 历法边界 | `backend/.venv/bin/python api-proof.py`，0.9s | 雾月 20 日合法、21 日返回 400。缩月预览指出受影响章节，强行保存返回 409，原月长仍为 20。过期修订返回 409。每页两条时雾月二十、雪月一日、未标两条分处连续三页。 |
| R1–R3 桌面、窄屏与 R5 权限 | `node ui.cjs desktop`，14.3s；`node ui.cjs mobile`，12.0s | 两个视口均通过界面设置星历、雾月 20 天、雪月 15 天，预览后确认保存。在时间线填写章默认和场景覆盖，刷新可见单独指定，清除覆盖、再刷新可见沿用本章。故事顺序先第三章“出发”，章节顺序先第一章“归来”。未标时间单列，页面无横向溢出。点击“入城”场景，编辑器打开原 ID 并显示“林远进了城。”，其故事日期菜单显示沿用初十。查看者能阅读全文时间线，界面无保存入口；编辑者能保存日期。未捕获页面异常。 |
| R2 跨章移动 | `node move.cjs desktop`，7.7s；`node move.cjs mobile`，7.7s；`node explicit.cjs mobile`，5.9s | 两个视口的预览均显示移动前沿用“归来”初十、移动后沿用“营地”十二，确认后同一场景 ID 的实际有效日期为十二。在窄屏编辑器将场景单独设为初八，再移回“归来”，前后预览及保存结果均为单独指定初八。 |
| R4 比对及问题详情 | `backend/.venv/bin/python compare.py`，3.3s；`node issue.cjs`，5.1s | 第一章“归来”写唯一佩剑在初十熔毁，第三章写持剑出发。替身读取实际出站的“故事日序”，按固定规则答复。初三出发得到零项，改十二出发后得到一项。桌面与窄屏的问题详情均显示两处原文、对应的初十和十二以及“沿用本章”。把十二改回初三后，旧证据出现“日期或场景归属已变化”。此项验证出站、落库、展示链路，模型判断能力仍待真实模型试读。 |
| R4 检查运行中改日期 | `backend/.venv/bin/python race.py`，5.5s | 本地替身延迟比对响应 4 秒。观察到出站后，把第三章初三改为十三，再等后台任务完成。任务返回“比对结果未保存”提示。原问题更新时间、修订不变，仍需复查，无“未复现”标记。 |

上述命令最终退出码均为 0。一次开发中验收遇到旧服务进程报告内部错误，重新加载修订号实现后，比对与竞态两项均重跑通过。浏览器测试采用当前源码和设备视口模拟。分页边界另用 HTTP 检查，UI 代理独立验收超过 30 项的界面翻页。

本机临时脚本、日志和 9 张截图在 `/tmp/story-timeline-browser.pUlK90`，截图子目录为 `run/screenshots`，文件名包含视口和操作名。所有操作仅涉及隔离样书。

## AI 生成作品历法（2026-11-26）

使用同一台 Chrome、新建空书和已标注日期的既有样书，模型地址指向隔离的本地 HTTP 替身。实际出站消息包含作品信息、已保存的历法和作者在界面输入的要求。下列脚本的最终退出码均为 0。

| 场景与命令 | 验收结果 |
| --- | --- |
| 桌面空书，`node ai-ui.cjs fresh`，4.5 秒 | 「添加月份」旁的「AI 生成历法」打开表单。填写要求后，建议区显示纪年和“星落月 · 23 天”。点「保留原输入」返回原有手填内容。再次生成并采用后可继续改纪年。采用与预览阶段读取数据库均为原历法和原修订，确认保存后刷新，得到手改后的纪年及建议月份。 |
| 375px 既有历法，`node ai-ui.cjs existing`，4.1 秒 | 模型先返回非法结构，接口返回 400，弹窗显示错误，手填纪年、已存历法和修订均保留。再次生成成功，预览无横向溢出。正式保存后，两个旧月份的 ID、名称和天数保留，新月有独立 ID；刷新后重新打开弹窗仍可见新月。首次运行在等待保存按钮时超时，页内文本已有该按钮，原因未确定；完整原样流程复测通过。 |
| 关闭慢请求，`node ai-cancel.cjs`，6.2 秒 | 模型端收到请求后将返回延迟 2 秒。用户关闭生成弹窗，延迟结束后，手填纪年和已存历法仍保持原值；重新打开时没有上次的要求或过期建议。 |
| 权限与出站，`node ai-roles.cjs`，4.1 秒，以及 `backend/.venv/bin/python ai-api.py`，0.4 秒 | 查看者无历法编辑或生成入口，调用生成接口返回 403。编辑者没有个人模型，也未获作者模型授权，仍可手工添加月份，「生成草稿」按钮禁用。操作期间本地模型收到的请求数保持不变。作者直接生成建议能保留已有月 ID；生成后作品历法和修订保持原值。 |
