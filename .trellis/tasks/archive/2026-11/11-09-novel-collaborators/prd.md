# 作品与系列设定协作

## 目标

作者可把单本作品邀请给站内用户，被邀请人接受后以查看者或编辑者身份访问。系列共享设定有独立的「设定协作者」，不因此获得成员书的访问权。所有权、管理员 RBAC 和用户私有资源的归属保持独立。

本稿是设计审查后的 V1 方案；详细接口、并发协议、数据迁移和异常行为以 `design.md` 为准。

## 范围与业务规则

### R1 邀请和成员管理

- 作品作者通过准确用户名邀请查看者或编辑者；系列作者可单独邀请设定协作者。不能邀请作者本人，管理员不能代替作者邀请。
- 接受前不授予访问权。作者可撤销邀请或授权、修改作品成员角色及模型授权；拒绝或撤销后允许重新邀请，但每轮邀请必须有新的不可复用身份。
- 接受/拒绝以邀请身份和预期版本为准；过期操作不能作用于新一轮邀请或修改后的邀请内容。
- 不存在和已禁用的用户名返回同一安全提示；不提供模糊搜索或用户目录。
- 每份作品邀请的「允许使用我的模型配置」默认为关闭。开启代表允许在本方案规定的场景使用作者 API 密钥及其外部服务额度，并在界面明确说明；系列邀请不包含此授权。

### R2 权限和资源边界

| 能力 | 作者 | 查看者 | 编辑者 | 管理员 |
| --- | --- | --- | --- | --- |
| 阅读作品、正文、设定、规划、版本、提及等项目资料 | ✓ | ✓ | ✓ | 按现有 `projects.read` |
| TXT / Markdown / EPUB 作品导出 | ✓ | ✓ | ✓ | 沿用现有作者限制 |
| 人工修改作品、章节、场景、项目设定、规划、知识库、笔记及分析结果 | ✓ | — | ✓ | 按现有 `projects.edit` |
| 触发 AI、智能体、项目相关任务 | ✓ | — | ✓ | 管理员身份本身不授予 |
| 删除/回收作品 | ✓ | — | — | 按现有 `projects.recycle` |
| 项目备份、协作者管理、阅读进度及本人账户私有资源 | ✓ | — | — | 保持现有严格归属限制 |

- 查看者不能触发 AI，即使该 AI 操作是预览或不直接写正文。编辑者不能访问作者的模型配置、私人风格库、模板、Skill、MCP、聊天或生成日志。
- 同一账号可以同时拥有协作和管理员身份：人工内容能力按各自已有授权求并集，管理员写权限不扩大 AI、备份、日志等作者专属能力；纯查看者的普通内容写入和 AI 请求为 403，无访问权为 404，既有作者专属接口可继续返回 404。
- 服务端按具体动作校验权限。客户端控制按钮和副作用只改善体验，不能代替服务端鉴权。

### R3 书架、生命周期与撤权

- 书架显示待处理邀请和已接受的共享作品，并标注角色。共享作品不计入被邀请人的作品数量配额。
- 作品撤权后不再出现在该用户的共享书架，也不能通过协作授权访问；若该账号另有管理员权限，仅保留该管理员权限原本允许的操作。降级到纯查看者后仍可读取，但不能再编辑或发起 AI。
- 作品处于删除中或回收站时，对协作者不可见。作者恢复作品后，未被另行撤销的协作关系恢复；已中断的旧任务不自动恢复。彻底删除后关系随作品删除，审计记录保留。
- 撤权、角色或模型授权收紧提交后，后续授权检查和持锁提交必须使用最新状态。进行中的任务在下一次受控检查、发送或持锁写入时停止；正在订阅的流尽快返回权限失效事件并关闭。
- 已发送给客户端或外部模型的内容无法撤回；不得承诺已发送请求不会计费。已提交的合法结果不因后续撤权而回滚。
- 协作者阅读不写作者的阅读进度；V1 不保存协作者独立阅读进度。

### R4 AI、任务与费用

- 用户显式选择的文本/图片模型必须属于该用户；未指定时优先使用其本人同类型默认配置。本人该类型没有配置且作者已授权时，才可回退作者默认配置；已配置但无效时明确报错，不静默转用作者配置。
- 项目共享向量索引采用一个作品级模型空间。编辑者可以维护知识库；未开启作者模型授权时，协作者上传使用关键词索引、检索退回关键词，不调用作者向量模型，也不覆盖作者已有向量。授权开启后，协作者触发共享索引或检索可以使用作者的向量模型；这是作品共享索引的明确例外，界面需提示其费用来源。
- 协作者触发及其自动衍生的任务都归触发者，并使用其任务并发额度；不能把子任务偷偷改记给作者。真正由作者独立发起的任务仍归作者。
- 外部服务根据实际使用的 API 密钥计费：使用作者配置时费用由作者账户承担；内部任务并发归触发者。可取得的用量记录按真实触发者记录，提供方未返回的数据保持未知，不虚构为零或承诺外部账单转移。
- 聊天、个人任务输出和 AI 生成记录属于实际触发者；项目其他成员和仅凭管理员人工内容权限的账号不能查看。协作授权被撤销后，即使仍有管理员人工读取权，也不能继续访问该协作关系下的任务输出或私人日志。

### R5 系列设定

- 系列设定协作者可读取系列共享设定、创建和编辑条目；编辑共享基础会按现有系列规则传播到已绑定书籍，不包含该书私有演变或正文。
- V1 中，设定协作者只可删除**未被任何成员书采用**的共享条目。已绑定时返回安全冲突，由系列作者处理，避免无书籍权限的用户删除本书投影。
- 加入/移出成员书、系列重命名和删除仅系列作者可执行。提升、采用、取消采用、移动及对应影响预览需要系列操作权限与所有受影响作品的编辑权限；仅凭其中一项不足以执行。
- 未获单书权限时，不返回该书标题、书内设定 ID 或依赖细节；系列级汇总数量可见。系列协作者的授权和作品协作者授权互不替代。

### R6 审计与兼容

- 邀请、接受、拒绝、角色或模型授权变更、撤销均记录实际操作者、目标、时间、结果、作用范围和安全的变更摘要；成功记录与业务同事务，失败记录使用安全的独立失败路径。
- 不记录密钥、模型提示词或正文。作品、系列或用户被删除后，审计快照仍可核对。
- 单书备份不携带协作授权或他人的私有生成日志；系统级备份继续遵循既有权限。旧数据升级、单书导入、回滚与降级不得悄悄丢失或暴露协作信息。

## 不做

- 实时多人共写、光标同步、在线状态和自动冲突合并。
- 站外邀请、模糊用户名搜索、作品所有权转移或管理员代邀。
- 用户个人阅读进度、多套共享向量索引和外部供应商账单结算。

## 验收标准

- [ ] 查看者接受后能读作品和导出三种格式；无法通过带作品 ID 或只有章节/场景/任务 ID 的入口写入或触发 AI，也不能下载项目备份。
- [ ] 编辑者可进行作品内容创作、知识库维护和 AI 操作，但不能回收作品、取消作者任务、覆盖作者阅读进度或管理成员。
- [ ] 重复邀请、自邀、过期邀请响应、并发接受/撤销和重新邀请均符合身份与版本约束；不存在和禁用账号的响应一致。
- [ ] 撤权或降级与写入并发时，以共同锁的提交顺序为准；撤权先提交则旧协作写入不能提交。运行中任务、索引、模型出站及订阅都按最新授权失败关闭；独立管理员人工能力维持原规则。
- [ ] 文本/图片模型按本人优先、仅无配置时授权回退；作者向量配置未授权时不会被协作者调用或产生费用，共享索引不会被协作者的不同模型覆盖。
- [ ] 自动分析、批量生成和知识库索引的任务及已采集用量归真实触发者；私人聊天、任务输出和生成日志不被其他成员或管理员人工管理旁路读取。
- [ ] 系列设定协作者能创建、编辑及删除未绑定条目；删除已绑定条目安全失败，传播仍只影响共享基础，不泄露无权访问书籍的信息。
- [ ] 系列/书籍双重权限、管理员与协作者身份重叠、软删除/恢复、单书备份/导入和历史生成记录兼容均覆盖。
- [ ] SQLite 与独立 PostgreSQL 的迁移及关键竞争测试通过；后端 `ruff` / 全量 `pytest`、前端 `lint` / `test` / `build` 通过，不能将 PostgreSQL 跳过视为已验证并发。

## 现有依据

- `backend/app/services/project_service.py`、`chapter_service.py`：严格作者入口及管理员人工旁路。
- `backend/app/services/series_service.py`：系列锁顺序、书内投影及删除预检。
- `backend/app/services/{ai_dispatch,kb_index_service,task_service,generation_log_service}.py`：AI 出站、索引任务、任务输出和日志。
- `backend/app/services/project_transfer/registry.py`：单书备份注册表与导入映射。
