# 全书搜索与批量修订验收记录

2026-11-18，在本地功能分支使用隔离作品验收。浏览器运行正式前端构建，连接 FastAPI 和经 Alembic 迁移的临时 SQLite 数据库。另用独立 PostgreSQL 16.15 实例核对并发事务。所有章节、人名、账号和批次均为测试数据。

以上在桌面 Chrome 157 中执行，同时检查了未捕获的页面异常。窄屏使用浏览器视口模拟。

## 数据库与备份

- SQLite 测试在第二章实际写入后注入异常，新事务读回的正文、章节版本与批次记录均回滚。另验同号同名章节删除、数字 ID 复用、多个冲突章、修订号改后改回、富文档与标记恢复、现有删章流程。
- PostgreSQL 16.15 升级到 `0060`。两个独立连接池执行同一请求及不同编辑者同时提交，数据库统计中可观察到实际锁等待。重复申请返回同一批，竞争申请只有一个整批成功。正常撤销时两章版本一起推进。某章后续保存后，撤销返回冲突，两章均保留。带批次历史的降级被拒绝，数据库保留 `0060`、2 条批次与 4 条场景明细。验证后已清理临时容器。
- 作品备份 v14 验证选择／跳过版本历史、旧备份、导入后撤销、过期及已删除的目标、同名同号双删除和损坏历史。导入不迁移原用户或去重凭据。
