# 类型化设定字段与按章回溯

## 目标与来源

父任务：`11-05-custom-setting-fields-categories`。承担父 R1、R2、R4、R5、R6，以及字段相关 R7、R8，让作者复用四类字段并在正确章节读取和使用有效值。

用户已确认新增单行、下拉、引用也全部支持按章回溯；本任务不能用静态字段缩减范围。2026-11-05 用户在最终摘要后回复“开始”，已批准实施。

## 已知事实

现有字段 ID 与事件直接关联；文本值受到 resolver、schema、上下文和卡片的共同假定。现有 career 是人物职业挂接，组织只有 membership；独立条目字段需要不同身份。源码证据及兼容路径见父任务 `research/typed-field-timeline.md`、`research/persistence-and-writers.md`，原合同见 `.trellis/spec/backend/setting-progressions.md`。

## 需求

| 编号 | 要求 |
| --- | --- |
| F1 | 作品内定义多行文本、单行文本、单选下拉、单目标引用字段，配置适用的角色／世界观子类型／组织／职业，提供相应编辑和只读展示。 |
| F2 | 四类字段均支持起始值及已有／计划章、章初／章末变化；多行追加／替换，其他类型替换及显式清空。 |
| F3 | 保留旧字段和事件身份；旧字段可继续维护并显式关联合适的共享文本定义，不按同名自动合并，不因新模板创建覆盖旧值。 |
| F4 | 共享定义、下拉选项和引用目标有稳定身份；改名不改历史关联，停用保留历史；类型变更、适用类型缩减和删除不能隐式损失值或事件。 |
| F5 | 当前和指定章节展示及现有选择范围内的生成／重写／分析／规划参考使用同一有效投影；不递归带入引用目标的正文或未来资料。 |
| F6 | 旧 API／旧备份／旧卡片保持兼容，新完整备份保留全部配置与历史；卡片为最新快照，包外引用需显式映射，未解决时整笔拒绝导入。 |
| F7 | 归属、人工只读、项目写屏障及并发保护一致；跨项目引用和不适用字段不能保存，失败回滚并保留草稿。 |
| F8 | 提供有界的共享条目目录和批量字段时点查询，供后续分类复用，不由前端逐项调用 effective 接口。 |

字段和目标的显示名仍是当前身份元数据；历史回溯保证字段值和引用目标身份，不新增名称历史。

## 验收标准

- [x] F-AC1：每种设定类型都可配置适用字段；错误子类型、跨作品目标、其他字段的选项被拒绝。
- [x] F-AC2：四字段在第 20 章章末改变，第 5／20 章章初为旧值，第 21 章为新值；计划章与章初变化同样可验证。

- [x] F-AC4：旧字段 ID、起始文本和事件不变，改名或显式关联定义后仍能回溯；相同标签不自动合并。
- [x] F-AC5：组织和职业定义字段保存不会新增人物成员／职业挂接；人物状态及原挂接历史继续正确。

- [x] F-AC8：0034 升级保留旧数据，新 v4 完整备份往返到新作品后有效值、章锚、选项及引用正确；导入 v1–v3 不补造历史。
- [x] F-AC9：卡片 v1–v3 可导入，v4 类型化快照往返；包外引用未映射时预览明确指出并拒绝提交，不按同名误绑。
