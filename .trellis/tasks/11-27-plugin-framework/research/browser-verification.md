# 功能插件浏览器验收

2026-11-27，在 macOS 上使用 Google Chrome 158.0.8127.37 和 Playwright，通过回环地址访问 Vite 与 FastAPI。后端使用临时 SQLite 数据库、测试管理员和普通作者。仅在临时前端副本和后端应用入口登记 `sample` 插件，贡献作品页、作品导航和 `GET /api/v1/plugins/sample/info`。两位用户使用独立浏览器上下文和真实登录 Cookie。

| 检查 | 观测 |
| --- | --- |
| 管理员查看列表 | 显示示例插件名称、简介、版本 `1.0` 和开关。首次打开时默认停用。 |
| 停用时直接访问 | 普通作者直接打开 `/projects/:pid/features/sample`，出现「该功能插件未启用，请联系管理员。」；作品导航没有示例入口，插件接口和管理员列表接口均返回 403。 |
| 启用 | 管理员点击开关后 PATCH 返回 200；作者随后访问插件接口得到 200。作者停留在原插件页面，26.646 秒后作品导航出现示例入口，页面显示「示例插件作品页」。 |
| 停用 | 弹窗说明将关闭入口、取消任务并保留数据。点击「保持启用」后开关仍处于启用状态；再次打开并确认停用，PATCH 返回 200，作者随后访问插件接口得到 403。24.092 秒后导航入口消失，原页面显示未启用提示。 |
| 移动与主题 | 管理员页面在 375 × 812 的 Chrome 视口中分别渲染浅色和深色。两次测得文档宽与视口宽均为 375px，开关宽 69px。截图检查确认标题、刷新按钮、名称、简介、版本和开关均可见；停用确认也在该尺寸完成。 |

计时从管理接口响应到作者浏览器的实际导航和页面均更新。期间作者页持续打开，通过正常的公开配置轮询获得变化，未手动刷新或切换作者页面。两个会话均无未捕获的页面异常。

另用同一测试管理员的两个独立登录会话打开同一版本的列表。第一个会话启用成功（200）；第二个会话按旧版本启用收到 409，界面显示「状态已被其他管理员修改，请核对最新状态。」并自动重新读取列表，开关恢复为已启用。使用刷新后的开关确认停用成功（200）。
