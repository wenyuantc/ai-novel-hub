# C2 双进程 HTTP 验收

在空的临时目录运行一次 Alembic 迁移，然后启动两个独立的 uvicorn 进程，共用 SQLite 主库和配对的租约文件。两个进程使用同一份新生成的部署配置。注册、登录、建书、建章、提交分析、配额查询和设置修改均使用应用的 HTTP 接口。

模型端接收 OpenAI 兼容 SDK 发出的 HTTP 流请求，用正文里的章标记对照任务。每个请求立即取得响应头，正文由同一个事件一次全部放行。观察者对 SQLite 仅有只读权限，只在模型收到请求时读取任务对应的执行者 PID。服务端的调用记录可以分别证明真实并行、同作品串行和实际调用次数。

从仓库根目录复跑。两条命令分别采用全站上限 2 / 用户上限 6，以及全站上限 6 / 用户上限 2。以下变量指向仓库内本演练文件。

```bash
probe=.trellis/tasks/11-20-mp-scheduling-constraints/research/sqlite_http_processes.py
PYTHONPATH=backend backend/.venv/bin/python "$probe" --backend backend --limit global
PYTHONPATH=backend backend/.venv/bin/python "$probe" --backend backend --limit user
```

从提交 `a16eb2a` 导出 `backend/`，沿用同一个项目 Python 3.12.10 环境，将 `PYTHONPATH` 和 `--backend` 指到导出的源码。全站上限 2 时，两个执行者 PID 为 72700、73341。真实模型同时处理 4 项，X、Y 两本书各有两个同键任务重叠。两端配额页各显示 2，观察者实际收到的总数为 4。两边的详情接口也都将这 4 项显示为运行中。

在 A 提交关闭注册、关闭 MCP、将每分钟限额从 2 提到 3 后，B 的首次注册返回 201 并签发 Cookie。插件列表返回 200，刷新工具连接了本机 MCP 服务一次，最终返回 400。公开配置仍返回两个开关为真。B 的开放接口在同一分钟内已用 2 次，5.303 秒后仍返回 429。

## 采样方式

每轮在 A 提交 X1、在 B 提交 Y1，等本机模型服务各收到一次后，再交替提交 X2、Y2、X3、Z1。所有在场的模型调用这时仍在等待正文。全部入队后继续等待 5.25 秒，给两个引擎各一次默认调度周期的机会。对同一个稳定状态，在两个服务上读取同一位作者的配额和 6 个任务的状态与位次，然后放行全部正文。每个后续请求的正文各自延迟 0.25 秒。用独立连接观察模型进入和完成顺序，六个任务最终都要通过应用接口返回成功。

设置变更在 A 保存，B 的首次注册、插件列表、刷新和公开配置同时发出。MCP 监听端口统计 TCP 连接。限流使用真正的平台 API Key，先让 B 在同一 UTC 分钟返回 200、200、429。A 调高限额后，B 连续探测开放接口，记录最后一次旧响应与首次放行的时间，随后再次调用要恢复 429。这个间隔包含 HTTP 往返，不依赖另一个进程的内存或管理员的重新加载接口。

## 0067 全站上限

PID 76383 和 77391 各执行了 3 项真实章节分析。总峰值为 2，各作品峰值为 1。首批是分别落在两进程的 X1 和 Y1。其余四项在两端都显示排队，位次依次为 0、1、2、3。配额页同时显示 2，六项全部成功并还清名额后同时显示 0。放行后的模型请求顺序是 Y2、X2、Z1、X3，X 与 Y 各自按入队顺序完成。每项只产生一次模型请求。

关闭设置后，B 的首次注册、插件列表、刷新工具均返回 403。注册未签发 Cookie，MCP 端收到 0 条 TCP 连接，两个公开开关均为假。四个响应在 A 收到保存成功后的 0.102 秒内全部返回。调整开放接口限额后，B 最后一次按旧限额返回 429 在 3.558 秒，第三次请求在 3.643 秒得到 200，第四次在同一分钟内仍返回 429。

## 0067 用户上限

将全站上限设为 6、同一作者的上限设为 2，另起空库和两个服务（PID 80514、80754）。每个服务各执行 3 项，仍只有首批 2 项同时到达模型，各作品峰值为 1。六项均只调用一次并成功；两个配额页和排队位次与全站上限轮相同。X1、X2、X3 以及 Y1、Y2 分别按入队顺序发出并完成。

三个受保护入口均返回 403，无新 Cookie、无 MCP TCP 连接，公开配置的两个开关均关闭。四个响应在保存后 0.044 秒内全部返回。B 的开放接口最后一次旧限额响应在 4.313 秒，第一次新限额响应在 4.431 秒，同一分钟第四次返回 429。两轮脚本退出码均为 0。
