# 写作统计与码字目标

## 目标

落实 [TODOS 第 26 项](../../../TODOS.md#26-写作统计与码字目标)。作者进入作品的连载工作台，可以回答三个问题：今天自己写了多少字、离本期目标还差多少、现有定稿够发几天。

## 需求

| 编号 | 作者看到的行为 |
| --- | --- |
| R1 写作量 | 按作品和北京时间自然日分别显示手写字数、AI 字数。以服务端成功保存的读者正文为准。断网草稿在成功同步当天入账，自动保存与点击保存使用同一口径。 |
| R2 码字目标 | 每人每本书分别设置一个日目标或周目标，可修改、关闭。仅本人的手写字数推进目标。无目标时仍可查看写作量。周一开始新的一周。 |
| R3 连续天数 | 当天有手写入账即算一个写作日。今天尚未动笔时沿用截至昨天的连续天数；昨天也空缺则显示 0。AI 单独产出不续天数。 |
| R4 趋势与存稿 | 切换作品、选择日期范围可比较手写和 AI 的每日趋势。当前作品的目标进度与连载工作台已有的存稿可支撑天数同屏展示，清楚标明「字」「章」「天」。 |
| R5 数据边界 | 每位参与者只看本人在当前有权访问作品中的统计。计量启用之前标为「尚未开始统计」；已有章节、导入备份和旧版本不推算为当天写作量。 |

## 计字口径

- 沿用章节的非空白字符口径，汉字和标点各算一字。以相邻两次已保存读者正文为依据，累加本次新写入的部分。原样保存、单纯删除、调整格式不加字，已经记下的写作量保留。两处独立修改之间的原文保留。
- 在正文编辑器内输入或粘贴并保存，按手写入口计。产品无法识别剪贴板文字的原作者。站内 AI 自动写入或经作者采纳的改动列入 AI 栏。AI 预览、失败、单独的作者备注与场景资料不入账。
- 拆并或移动场景、恢复旧版本、批量替换及撤销属于整理已有内容。个人目标与连载工作台的共用日更章数分别设置。单书导入建立新作品，首版拟让新书从零累计个人统计。

## 验收

| 编号 | 可复现的例子与预期 |
| --- | --- |
| A1 · R1/R2 | 日目标 3,000。同日手写 2,000 字并让站内 AI 新增 5,000 字。工作台显示手写 2,000、AI 5,000、进度 2,000 / 3,000、还差 1,000。 |
| A2 · R1 | 把一段 100 个「甲」改成 100 个「乙」并保存，手写增加 100。随后删除 20 字、变更排版、重新保存，均不再增加。版本恢复不把旧稿记成新产出。 |
| A3 · R1 | AI 给出 5,000 字候选，只采纳其中 2,000 个新字进入正文，AI 增加 2,000，手写增加 0。放弃预览记 0。保存回执丢失后核对或重试，总数不变。本人在两章分别新增 40、60 字同时保存，合计 100。 |
| A4 · R2/R3 | 周目标 5,000，周一、周二分别手写 800、1,200，周三只用 AI。周三进度 2,000 / 5,000，连续 2 天；到周四仍未动笔，连续为 0。下周一清零本周进度。 |
| A5 · R4 | 日更 2 章，10 章定稿未发，同屏显示存稿可支撑 5 天和 A1 的目标进度。改为周码字目标或切换趋势日期，存稿仍为 5 天。切换作品后显示该书的数据。 |
| A6 · R5 | 甲乙合写同一本书，乙的手写或 AI 任务只进入乙的两栏。撤权后不能继续查看这本书的统计。旧作首次打开显示计量起点，启用后无写作的完整日期显示 0。 |

首版范围限于作品内的个人正文字数、目标与趋势。全站排行、提醒、写作时长及 AI 费用各有不同用途，本项不包含这些功能。
