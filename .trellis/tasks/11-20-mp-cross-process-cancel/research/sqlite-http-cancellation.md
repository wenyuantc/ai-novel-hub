# 真实双进程 HTTP 取消与删除演练

本机启动两个独立 uvicorn 进程，共享一套临时 SQLite 数据库和应用配置。通过真实 HTTP 接口注册作者、登录管理员、建作品、建章和提交单章生成。每个场景使用独立作品，观察者以只读方式访问 SQLite。

模型端使用只监听回环地址的 TCP 服务，接受原 OpenAI SDK 的流式请求。服务先发送响应头和两段正文，再保持连接，不发结束帧。看到第二段正文已由执行端写入数据库后，按任务 UUID 查询登记的执行者 PID，用 SIGSTOP 暂停本演练的该子进程，再向另一个实际 PID 发出取消或删除请求。在接收端提交意图或返回后，记录作品、任务和章节占用状态，用 SIGCONT 放行原进程。暂停窗口短于 30 秒租约。管理员重复受理时让同一对端请求两次，以便原进程仍处于停点时核对操作号。

观察者在模型端直接等 TCP EOF 或连接重置。它能证明 SDK 端关闭了这一次连接。第三方服务可能已收到和处理请求，断连不会撤回外部效果。演练在数据库另外核对章节占用、生成日志、C2 名额和管理员成功审计。脚本在收齐现场数据后才发结束帧清理仍然打开的旧连接，三个场景的模型实际调用数分别计数。

## 0067 对照

2026-11-23，SQLite 3.47.1。执行端 PID 33503，接收端 PID 33679。所有场景均只有一次真实模型请求。

| 场景 | 原执行者仍暂停时 | 恢复后观测 |
| --- | --- | --- |
| 本人取消 | 接收端已经返回 200，任务显示 cancelled、章节已回到 draft、claim 已清除。模型连接仍开着。 | 原进程恢复后继续观测 7 秒，名额仍为 1，无取消生成日志，模型端未看到 SDK 主动断开。 |
| 管理员重复取消 | 两次 202 指向同一个操作号；任务保持 running、章节仍被占用、管理员意图待处理。 | 原进程关闭模型连接，产生一条 cancelled 生成日志、一次成功审计，名额归零。 |
| 删除作品 | 接收端已经返回 204，作品已软删除，任务 cancelled、章节 claim 清除。模型连接仍开着。 | 继续观测 7 秒，仍占一个名额、没有取消生成日志，模型连接仍在。 |

使用加入持久工作查询的最终脚本再跑 0067，PID 42348 与 42737 调换管理员场景的执行与受理方向。结果相同，本人取消和删除两项失败，管理员一项通过。旧版没有执行工作记录表，脚本在该观测字段标记 null。

## 0068 实现

首轮在执行端 PID 37529、接收端 PID 37814 上通过全部三个场景。最终脚本又用新库和另一对进程独立复验，从同一条只读 SQL 同时核对任务、章节、作品、本人意图和原执行体记录。下表记录第二轮的实际观察。

| 场景 | 执行 PID → 受理 PID | 暂停时 | 请求结果与数据库观测 |
| --- | --- | --- | --- |
| 本人取消 | 43248 → 43700 | 原任务 running，章节带原 claim。本人意图为 1，执行工作为 1，HTTP 尚未返回，模型连接仍在。 | 原进程恢复后返回 200。已取消、章节回到 draft，执行工作为 0。 |
| 管理员重复取消 | 43700 → 43248 | 原任务 running，执行工作为 1。两次 HTTP 受理均在原执行者恢复之前完成，管理意图仍待处理。 | 两个 202 同为操作号 `70fffc78-ab3e-4918-b370-42e15b48a624`；一条成功审计。原执行者恢复后任务取消。 |
| 作品删除 | 43248 → 43700 | 删除 token 与本人取消意图都已提交；作品尚未软删，任务 running、执行工作为 1、模型仍连接，DELETE 尚未返回。 | 原进程恢复后 DELETE 返回 204。收到响应后的第一次查询显示作品已软删、原执行工作为 0、章节 claim 已归还。 |

两轮均由模型端观察到 SDK 主动关闭全部三个连接。每个场景恰好一条真实生成调用和一条 cancelled 生成日志，最终并发名额为零。最终脚本退出 0。演练覆盖 AC1、AC3 的单章及重复受理路径、AC6 的运行中任务路径；批量任务、回执丢失、清理失败、SQLite 归还回执迟到和 PostgreSQL 锁竞争分别由相应定向测试验收。

在最终代码上用新库复跑，执行与受理进程为 PID 3262 和 3360。本人取消返回 200，管理员两次 202 均取得操作号 `8bcec3a4-408d-4d07-8255-f9a1b7e45199`，删除返回 204。受控模型端观察到三次连接分别由原进程关闭。每个场景只调用模型一次，结束时各占用零个名额。脚本退出 0。
