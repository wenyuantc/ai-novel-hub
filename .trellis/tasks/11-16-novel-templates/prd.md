# 个人小说模板

## 目标

承接父任务 R13.2 / D13.1，让作者把配置及选定设定／大纲保存为可复用的创作起点，创建正文为空的新作品。

父任务：`../11-16-pen-names-templates-thumbnails/prd.md`。2026-11-16 用户已确认配置＋可选设定和大纲、新书正文为空，并批准完整方案实施。

## 现状

新建作品当前只填写立项资料和风格：`frontend/src/components/shelf/CreateProjectModal.tsx:24`；创建入口校验作品额度：`backend/app/services/project_service.py:525`。

完整备份包含正文与历史，不等同于模板。现有设定卡和大纲导入的选择范围、引用语义和内部事务不能直接组合成原子模板建书；具体证据见父任务 `research/template-design-evidence.md`。

## 需求

- NT1：从本人活跃作品保存个人模板，填写名称和说明，并预览所选内容；个人模板库提供查询、预览、改名／说明、删除及以新快照替换内容。
- NT2：可保存常用立项配置、默认写作风格、字段／选项和分类配置；可选择角色、世界观、组织、职业及大纲／细纲。正文、章节、场景、历史与运行态不属于模板。
- NT3：实体使用保存时当前档案值，在新书建立独立初始设定；不复制旧剧情演变或旧时间线身份。关联两端均入选的关系／成员信息可保留，随关系保存所需类型定义与端点方向；未保留关联在预览明确说明。
- NT4：有硬引用依赖时先显示需要补充的条目、选项或阶段，作者确认后才纳入；不能静默增加未选择的设定，也不能生成断开的引用。
- NT5：保存完成后模板独立于来源作品。源作品改动、回收或删除不改变已保存快照；模板修改不影响已经创建的新书。
- NT6：模板包含所选设定的当前缩略图快照。系列采用条目恢复为本书独立内容，不继承系列成员或共享档案绑定。
- NT7：复用只创建新作品。填写新书名并选择本人的笔名；不会自动沿用来源笔名。配置、设定和大纲写入成功后进入新书概览，使用既有向导或细纲建章继续创作。
- NT8：新书正文为空、总字数为零，不带原书章节／场景、聊天、任务、历史、阅读／向导进度、协作者、访问密钥、模型凭据和授权。
- NT9：保存和复用遵守本人资源权限、当前作品额度；失败整体回滚，不留下模板半成品、半本作品或孤立依赖。重复提交和超时重试不意外生成多本作品。
- NT10：模板内容有版本保护。提交旧预览或覆盖旧修订时提示冲突，保留用户选择并允许重新预览，不能静默用另一版内容建书。删除模板后不得复用身份，旧页面请求不能命中新模板。

## 验收标准

| 编号 | 场景与结果 |
| --- | --- |
| NT-AC1 | 从含正文的作品保存配置、部分设定与大纲，新书保留所选内容，正文为空、字数为零。 |
| NT-AC2 | 仅配置、含四类设定、仅部分大纲、带图、同名实体等场景均有稳定身份；自定义关系类型和方向正确，无源ID或按名字误连，类型冲突整体拒绝。 |
| NT-AC3 | 自定义引用、组织父级、职业／阶段等依赖在预览可见并需确认；取消依赖时不能偷偷带入或留下悬空引用。 |
| NT-AC4 | 当前档案值成为新书初始值，图和字段可编辑，旧剧情事件及历史不被复制。 |
| NT-AC5 | 来源作品变化或删除后模板仍可用；模板替换或删除不改变已建作品；新书笔名由创建者选择。 |
| NT-AC6 | 他人的模板／源作品请求失败；协作者和管理员不能借内容权限进入他人模板库。 |
| NT-AC7 | 配额不足、损坏快照、缺依赖、图片异常和事务中途失败整体回滚，数据库无部分作品或资料。 |
| NT-AC8 | 同一创建意图重试返回同一新书，旧预览／旧版本不能静默创建；并发不超配额。删除最后模板后新建，旧ID／revision请求不得命中新对象。 |
| NT-AC9 | 新书可继续按既有大纲生成章节、编辑设定、备份恢复；单书备份不把个人模板库一并导出。 |
| NT-AC10 | 桌面和 375px 完成保存、选择、预览、建书、冲突重试；账号切换／撤权不显示旧私有模板。 |

## 依赖与边界

依赖笔名和缩略图子任务已通过检查。模板格式独立于作品备份、设定卡和大纲导入格式；复用相容的底层无提交原语，不改变这些入口的既有提交契约。

不含整书正文克隆、模板应用到既有作品、在线联动模板、公开模板市场、跨用户模板分享、模板独立文件导入导出或任意图形化模板内容编辑器。需要改内容时从更新后的作品重新保存快照。
