# 阅读页朗读实施计划

按下列顺序实施。每一步的结果都可以单独验证，声音与高亮同步后再做实机听验。

### 1. 让普通章节能在本机读出来

- [ ] 在阅读页接入本机中文声音筛选与播放控制。用户点击后从第一段起逐句播放，提供暂停、继续、停止和调速。接入既有阅读设置，加载老设置时验证默认语速。
- [ ] 在 `frontend/src/utils/reader.ts` 附近建立纯文本段落范围，沿用现有普通阅读排版。用两段同文、中间空行、含 emoji 的长段验证，只有正在发声的段落被标亮。
- [ ] 用可控制开始、结束、错误事件的语音替身测试状态转换。覆盖先空后有的声音列表、只有在线中文或本机外语、语音接口不存在、播放中出错、连续点击和暂停后改速。没有合格声音时 `speak` 调用次数须为零。

### 2. 让富文本、提及与搜索共用段落位置

- [ ] 将同一段落坐标接入 `RichReaderContent`、阅读页的 `MentionPreview` 渲染入口和 `SearchHitContent`，覆盖普通、提及和搜索三种视图的纯文本及富文本。切换提及显示时应保持播放位置。
- [ ] 在现有渲染测试中加入粗体列表、标题、引用、跨行搜索、仅换行命中以及前面有表情符号的重复段落。断言读到第二处时只标亮第二处，同时搜索位置、实体点击和列表语义正确。

### 3. 处理离页、失权与设备差异

- [ ] 将语音取消与 `ReaderView`、`ReaderSession` 生命周期及正文指纹关联。测试停止后立刻重播、暂停后切章、旧章结束事件迟到、登出、阅读器发现撤权和同章内容更新。旧回调不得重新发声或标记新章。
- [ ] 回归作者与只读协作者。两者都可本机听稿；只读账号全程不产生进度写入。检查工具栏键盘操作、窄屏按钮、浅色／护眼／深色下的高亮和搜索命中。
- [ ] 用安装本机中文声音的设备听完一章，听辨调速、暂停、继续和章末停止。在无本机中文声音的环境核对安装提示。记录操作系统、浏览器、声音和实际听到的结果；仅有模拟回调的环境单独记录。

### 4. 回归与交付

从仓库根目录运行。首条覆盖已有相关用例；新建的播放状态和段落测试一并加入定向运行。

```bash
npm --prefix frontend run build
npm --prefix frontend test
```
