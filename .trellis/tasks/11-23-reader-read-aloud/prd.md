## 读者操作与验收

| 操作 | 应看到或听到的结果 |
| --- | --- |
| 打开有正文的章节，再点「朗读」 | 打开页面时保持安静。点击后从本章第一个有文字的段落顺序朗读，跳过空白行。章末自动停止并清除朗读高亮。 |
| 听两段文字相同的正文 | 声音开始读第二段时，高亮移到第二段。任一时刻至多一段带有朗读标记。 |
| 暂停、继续、停止 | 暂停时声音停止，段落标记保留。继续时从暂停处接着读；如需兼容按短句恢复的设备，可重读当前短句。停止后清除标记，再点朗读从章首开始。 |
| 朗读前或播放中调整语速 | 默认 1 倍。建议提供 0.75、1、1.25、1.5、2 倍；播放中变更从下一短句生效，暂停时变更不会自行开播。 |
| 从提及或全书搜索打开纯文本或富文本章 | 朗读顺序与正文一致。列表、引用、强调、实体点击和命中焦点可照常使用，搜索标记与朗读段落可同时辨认。目录、分析、提示和作者备注均排除在朗读内容之外。 |
| 切章、离开阅读页、退出账号或阅读器确认已失去访问权限 | 立即停止旧正文，后来到达的语音事件也不会播出下一段。原有读权限即可使用朗读，阅读进度沿用已有写入权限。 |
| 打开空章，或在缺少可用语音的设备上阅读 | 空章无法开始朗读。浏览器不支持时提示更换支持朗读的浏览器；只有在线声音、只有外语声音或没有声音时，提示在系统设置中安装中文语音。用户仍可阅读和翻章。 |

## 语音来源与首版范围

用户已于 2026-11-23 确认，只用本机中文声音。每次朗读都要明确选中设备上的中文声音。普通朗读在设备上处理稿件；主动使用 AI 自动配音时，按下文约定发送本章正文。系统后来提供可用声音时，允许用户重新点击播放。

首版以当前章听稿为单位。跨章连播、音频导出、逐字高亮和跨设备续听另行规划。普通阅读的位置和播放位置分别处理。

## 角色配音与情绪（2026-11-25）

读者希望闭着眼也能分辨角色，并能听到同一角色在高兴、生气、害怕、难过或低声说话时的变化。保留本机中文声音限制。在章节内识别旁白、对白和明确的说话提示；归属不明的对白允许手动指定。可给角色选择本机音色、试听，也可逐条纠正角色和情绪。角色音色按本机账号与作品记忆，台词纠正仅应用于同一章节正文版本。设备音色不足时仍可调节韵律；情绪表现受本机声音能力影响。

## AI 自动配音（2026-11-25）

读者已选择使用项目支持的已配置文本模型。进入阅读页、打开配音设置、试听和朗读均不触发文本模型调用。具备作品 AI 权限的读者主动点击「AI 自动配音」后，所选模型可以读取本章已保存的公开给读者的正文，在上下文中判断每处对白的说话人、情绪，并为角色从当前设备提供的本机中文声音中挑选音色。界面在发送前说明正文去向。

结果应用于发起分析的账号、作品和章节版本，优先级为手动设置、AI 建议、本机规则。读者可直接试听或纠正；刷新不重复发送。失权、切章、正文变化、模型失败或返回无效结果时，不用旧结果覆盖当前设置。仅有阅读权限时继续可用本机朗读。
