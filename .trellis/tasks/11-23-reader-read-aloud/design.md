# 阅读页朗读设计

## 正文与段落位置

沿用 `readerApi.chapter` 返回的已鉴权快照。朗读的唯一文字来源是 `chapter.content`。`blocks` 为空值时按自然换行分段，有读者格式时按 `ReaderBlock.start/end` 取原文。标题块、每个列表项和引用各占一段。页面额外展示的章名、提及弹窗和分析文字不进入语音队列。涉及的入口是 `frontend/src/pages/ReaderPage.tsx`、`frontend/src/api/reader.ts` 和 `frontend/src/utils/reader.ts`。

朗读与显示共用按文档顺序排列的原文范围，以 Unicode 码点的左闭右开区间标识一段。纯文本现有的 `splitParagraphs` 会丢掉空行并去除首尾空白，需在清理显示文字前记录原始区间。提及和搜索依赖完整正文坐标，换行与段间空格需能按原样渲染，包括仅命中换行的情况。相同文字出现两次时各有独立位置。

普通正文在段落元素上显示朗读标记。富文本在现有段落、标题、引用或单个列表项上标记，保留现有行内标记。提及态沿用 `MentionPreview.renderText` 和 `MentionText`，搜索态沿用 `SearchHitContent` 的指纹校验与定位。纯文本有跨行命中或提及时，按原始范围分片，保留换行和原有点击行为。朗读使用独立的段落样式，不占用 `data-mention-focus`、不抢键盘焦点；手动滚动时可以继续检查别处的文字。

## 本机语音与播放状态

- 使用浏览器 Web Speech API。初次调用 `getVoices()` 并监听 `voiceschanged`，播放前再检查。只选语言标签匹配中文且 `localService === true` 的声音，每条 `SpeechSynthesisUtterance` 都显式指定该声音。列表暂为空允许刷新重试；声音失效时停止并提示，不能留空让系统默认选择。浏览器对本机及远程声音的区分见 [Web Speech API 语音定义](https://webaudio.github.io/web-speech-api/#speechsynthesisvoice)。
- 以短句为播放单位，每次只提交一条，读完才取下一条。同一段内部各短句共享段落范围。超长无标点段也按可控长度分片，拼接后应还原原文，切分不得拆开代理对。当前短句实际开始时才更新段落高亮，无需依赖逐字回调。
- 读者点击开始后进入等待发声，开始事件到达后显示播放中。原生暂停可靠时使用暂停和继续；若实机验证需要兼容，则暂停时取消当前短句并保存索引，继续时最多重读这一短句。新语速用于下一次提交，已提交的短句读完再切换。结束或出错时清除朗读标记，出错后允许手动重试。浏览器接口的队列与暂停语义见 [Web Speech API 播放控制](https://webaudio.github.io/web-speech-api/#speechsynthesis)。
- 为每次播放保存独立标识及当前短句索引。停止、重复开始、正文指纹变化、权限失效、切章、离页或卸载时，先令旧回调失效，再取消本页持有的语音。取消不会重置引擎的暂停状态，需在清空本次队列后恢复引擎可用状态。忽略上一次播放迟到的开始、结束及错误回调。

## 页面与数据边界

入口位于阅读页工具栏，播放控制提供暂停、继续、停止和语速；窄屏可收拢语速选项以留出正文空间。语速作为阅读偏好保存在已有 `ainovel.reader` 设置中；老设置缺少该字段、取值非法或存储不可用时取 1 倍。段落位置、正文和播放队列仅保存在当前阅读会话内。

朗读复用 `ReaderSession` 的身份和授权检查，以及以章节 ID 为键的 `ReaderView`。播放前及衔接下一句前核对会话和正文快照。朗读动作本身不提交阅读进度，真实滚动继续走现有权限检查。本方案只涉及前端，无需新接口、数据库迁移、音频文件或 AI 配置；撤回功能时移除入口和播放逻辑即可，旧客户端可忽略额外的语速偏好。
