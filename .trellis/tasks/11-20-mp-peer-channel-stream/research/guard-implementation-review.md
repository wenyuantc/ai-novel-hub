# C4 跨进程协作者帧授权复核

2026-11-24。检查范围从 A 选择原始发布来源与当前合法后继开始，到 B 在自己的数据库租约内将帧实际交给 ASGI 为止。

## 实际发送结果

`backend/tests/test_c4_guard_review.py` 的八个场景在默认 SQLite 与专用 PostgreSQL 的独立 schema 各自通过。SQLite 用时 21.56 秒，PostgreSQL 用时 50.86 秒。两轮均使用 `public_pair` 建立两个独立应用和真实 TCP 连接。数据库由 `isolated_worker_database` 选择，PostgreSQL 轮次对所有场景启用了独立 schema；本组没有 SQLite WAL 参数分支。

| 场景 | B 实际发出的结果 |
| --- | --- |
| 角色向导已有在途增量，随后由同一轮次保存、推进作品历史代次并结束 | 保留原增量，拼合正文与完整模型响应一致，收到 `done` |
| 相同窗口，第三方在保存之后又修改可见性版本和历史代次 | 只发固定权限错误，保留在 A 的增量没有进入客户响应 |
| 大纲向导已写入完成收据，Task 仍为 `running`，作品历史代次没有变化 | 观测到 B 已在锁外请求同帧重核，放行 A 的 `done` 后正常收到完整正文与终态 |
| 单章富文档待审核提案仍是 `pending` | 收到 `paused` 和该任务的原 UUID |
| 同一富文档 `paused` 已由 A 签发，两跳之间仅将提案状态改为 `discarded`，Task 行不变 | B 拒绝旧提案，响应未携带审核凭据 |
| 批量生成正在第一章，只替换章节行占用键，Task 断点和执行键保持不变 | 已经在途的该章增量被 B 拒绝 |
| 终态结果引用同一协作者的另一条任务，持久原件带身份凭据 | B 从原件重算结果，保留可公开的 effect，响应没有私有凭据 |
| A 签发相同终态后，只更换被引用任务的 UUID | B 重算投影发现已变化，返回固定权限错误 |

前六个场景经生产 HTTP 订阅入口读取浏览器会看到的 SSE。最后两个场景在真实内部连接上调用签发入口和 B 的正式 ASGI 帧发送器，单独观察 `view` 来源，否则已经结束的任务会直接走 B 本地持久回放。

## 实现对照

- **绑定与锁**　A 从数据库重建 HTTP 订阅捕获的账号、令牌代次、作品所有者、删除代次、任务 UUID、入队时间、成员邀请与修订。B 用原绑定开启自己的物理帧事务，在该事务内核对账号、作品、协作成员、模型配置所属者、任务和当前来源。等待另一端的 ACK、重核或未提交终态发生在事务之外。
- **排队、领取与持久视图**　排队位次和领取帧有独立的公开字段约束。排队快照、迟到的排队快照、结束后回放按相应规则核对持久任务视图。带私人身份提示的效果只能从持久原件重新投影；已公开效果会移除这些提示，不能再次充当原件。
- **运行与终态**　A 仍由 `verify_stream_frame` 检查真实领取、发布来源或可信终态。A 读取本次验证实际选中的发布 guard，将其可见性和模型选择摘要及分支条件绑定到已认证的帧。B 核对同一连接上的当前未确认帧，比较身份、执行与任务状态，再按当前分支复核。源端与接入端各使用本地活跃 worker 检查。
- **批量、分析、实体与智能体**　批量分为章节占用、逐章分析和章间发布。单独分析对照未决凭据及采纳提案来源，逐章分析对照原引用和收据行。实体任务比较原来源分组；智能体核对当前会话、原邀请和历史代次，提案和已执行变更另外锁定原变更行并从数据库生成公开对象。运行中引用的文本和共享向量模型均对照冻结选择、本次成员授权和当前配置。
- **后继与缓存**　大纲自身保存与设定向导自身换戳分别通过专门的时序测试。A 缓存的已发布来源只能按同一订阅、原数据摘要和相同序号重验。固定一次重核的实现已移除，原帧的总截止时间仍约束等待。

## 验证边界

本组没有逐类驱动实体任务、逐章分析、成功但未发布的收据、智能体工具或进程强杀。上述相关结论来自代码对照。这些类别的运行结果、账号和模型授权竞态以及完整回归以各专项记录为准。自由格式正文包含完整、带私人效果的 JSON 时，活动发布帧与作者转发路径的两次投影需由其实现者另验；本组原件复算测试覆盖持久回放。
